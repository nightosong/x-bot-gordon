- 长文本创作工作流：规划 -> 世界观 -> 人物 -> 剧情推进 -> 章内计划 -> 章节正文 -> 压缩润色 -> 连续性资料更新 -> 一致性审核。
- 章节级执行流：章内计划 -> 正文生成 -> 一致性/追读质检 -> 压缩润色 -> 连续性资料更新。章内计划只拆问题、限制、信息差、反制、证据载体、代价和结尾钩子，不写正文。
- 作者约束和 AI 台账分离：作者明确写下的题材、角色、禁忌、情节要求优先级最高；连续性资料、设定账本、storyAssets 和 memoryNotes 只用于维护事实、信息差和伏笔，不得反过来替作者新增核心题材。
- 规划阶段先确定主角欲望、核心矛盾、情绪承诺、自然结局方向和章节职责；不要让故事靠临场灵感自由漂移；开篇优先单主角、单事件、单视角、单冲突。
- 结局方向优先写成“人物如何继续生活”的自然收束：路线抵达、技艺领悟、关系清账、地方余波、传承改口、价值选择或继续上路。除非作者明确要求，不要默认写成揭穿终极阴谋、公布世界真相、击败最终 Boss、掌权、统一天下、成为天下之主或天下第一。
- 探险、末世游历、废土远行、异境旅行或奇观地图题材，核心不是谜题而是渴望：主角为什么想去看看、想抵达哪里、为什么过去不能走、现在为什么获得出走机会。主线优先写“抵达、见闻、选择和变化”，不要默认写成“获得任务 -> 解锁地图 -> 收集线索 -> 接近真相 -> 公布真相”。
- 探险故事禁止默认使用世界真相驱动、阴谋揭秘、最终 Boss、拯救世界、公开真相式升华、RPG 地图解锁、MMO 职业体系、数值升级流、任务链结构、关键宝图或地图碎片。不要把书名或核心意象直接套成关键道具名，例如“雾兆图”。
- 未来异生态、侵蚀、开荒清障和危险区域职业战斗题材，核心体验是“进入危险而壮丽的新生态世界”，不是“揭露世界真相”或“讨论文明存亡”。主线必须持续移动，每一卷或大段进入新的侵蚀生态区、新地方文明、新职业活法和新战斗压力；主角变化优先体现战斗判断、危险区域权限、生存经验、资源调度、人脉、地位和通行权的实际沉淀，不做每到一站固定升级。文明反思、生态哲学、身份认同和旧世界哀歌只能作为局部余味，不能压过冒险、生存、开荒和成长。
- “侵蚀”不能只是抽象污染或怪物刷新点，必须景观化和经济化：不同侵蚀区要有不同气候、地貌颜色、建筑寄生结构、迁徙规律、声音、地方疾病、人类利用方式、运输成本、商业结构和生存产业。读者应能期待下一站会看见一种新的活法，而不只是等下一层真相。
- 地方感优先于地图感：每个地点都要回答“人为什么住在这里、怎么活、怎么交易、怎么称呼危险、怎么利用灾变地貌”。地点不是资源点；盐湖可以有拆门板防盐潮、桥镇可以有一辈子不离桥的人，废城可以有替死人认路的手艺。
- 见闻感优先于说明感：每一卷或大段应让主角第一次见到一种活法，通过短暂相逢、交易、互救、冲突和分道呈现群像，不默认组固定小队。
- 偶然性可以让世界活起来：雾暴、断桥、天气、误听、救人、债务、封路、怪物迁徙和地方节日都能改道；但进入事件后，人物选择、代价和后果必须有因果。
- 战斗不是体系展示，而是一段人在危险世界里被迫改变条件的经历。战斗体系先从生存工种长出来，再转化成动作：修桥、背灯、听潮、验尸、缝肺、驱兽、记路、运盐、清障或谈价的人，因为环境危险才具备战斗能力；不要把职能写成技能树、固定小队配置或所有人都会打架。
- 战斗场面要绚丽、精彩、巧妙：绚丽来自奇观地貌、光线、声音、怪物生态和工具连锁；精彩来自读者看懂主角如何观察、误导、借地形、借规矩、借生态反制；巧妙来自铺垫、限制和代价，不来自突然开挂或技能名轰炸。
- 技艺、武学和能力领悟必须水到渠成：先有旧训或旧经验，再有误用、失败、观察、训练、伤势、关系触发或地方经验，最后在合适场景里贯通。不要写成“到一地 -> 遇一事 -> 固定悟一招 / 升一阶”的关卡奖励；铺垫不足时只写疑问、半成手感或训练方向。
- 精彩战斗必须具备动态空间、时间压力、感官压迫、错误代价、对手学习或反制、失败后果和余波。胜利不只等于杀死敌人，也可以是拖时间、夺路、护送、断后、封门、引怪、保住证据、换取通行权或迫使规则改变；失败不只等于死亡，也可以改变路线、资源、名声、债务、组织态度或人物关系。
- 怪物和灾变生物要先写成生态网与生存民俗，再写成战斗对象：先有生态发动机、物种谱系、食物网、尺度 / 栖境 / 体态矩阵、关键种和季节变化，再写当地人如何误解它、孩子如何害怕它、商队如何绕开它、职业如何依赖它、哪些禁忌和方言因它诞生。必须覆盖微型、小型、中型、大型、巨型 / 超大型、地貌级 / 群体级生命，覆盖陆地、水域、空域、地下、建筑寄生、雾域和类人社会等多种栖境；除非题材明确要求，虫、蛛、菌不能成为主要想象来源。禁止只写“功能 + 地形 + 弱点”的怪物图鉴或副本机制。
- 世界观必须用规则、代价、资源、禁忌、阶层和势力利益驱动剧情，不只堆设定名词；不要在开篇用大段说明书倾倒功法、世界规则、势力分布或历史沿革。
- 人物由目标、欲望、恐惧、秘密、债务、生活惯性、地方化身体习惯、关系小证据、留白和成长弧构成；主角经历必须持续改变选择成本；人物出场要通过行动、选择、对白、代价、习惯动作和具体处境显形，避免只写外貌履历、性格标签或“负责某种主题功能”；首场戏命名人物建议小于等于 3 人，长篇群像也不建议群像开局。
- 剧情推进要明确下一章冲突、转折、情绪目标、信息增量、伏笔/回收和结尾钩子。
- 章节是最小叙事闭环：开场钩子 -> 冲突升级 -> 信息博弈 -> 对手反制 -> 行动选择 -> 代价/新证据 -> 余波或悬念；开篇章节尤其要先成为一个可独立吸引读者的小故事。
- 每章至少有一个可验证证据载体承接变化，例如物件、伤痕、账目、地点破坏、公开结果、能力边界、称谓变化或关系破裂；不要只用“他终于明白了”“她心里一震”这类抽象句子承担转折。若本章涉及领悟，证据载体必须能回扣前文铺垫，而不是单章自洽。
- 对手和环境不是背景板，必须会反制、遮掩、误导、索取代价或改变规则；如果主角一路顺畅，章节张力会塌。
- 生成与修订分离：初稿阶段优先完成可推进的版本，把需回头修改的伏笔、人设和设定记入设定账本，避免在开头反复打磨导致长篇停滞。
- 长篇连续性资料必须记录人名、能力/境界、时间线、地点、关系、未回收伏笔和规则边界，防止人设漂移和战力崩坏。
- 稳定事实必须进入结构化故事资产 storyAssets：worldview、characters、relationships、timeline、foreshadows、rules、styleProfile、memoryNotes；不要只留在正文或章节简介里。
- 连续性资料、设定账本、storyAssets 和 memoryNotes 是内部创作管理资料，不是作品主题或世界观机制；除非作者明确要求或现有正文已经确立，不要把“记忆、失忆、遗忘、档案”自动设为核心冲突。
- 书籍介绍、设定补充、大纲指导、章节简介和正文必须只呈现作品内容，不得出现“重构原则、资产保全、Schema、字段、工作流、节点、落盘、迭代记录”等项目开发语言。
- 新建故事或扩展故事介绍时，优先选择区别于同工作台已有作品的核心机制；书名意象可作为氛围和美学线索，但不要把相似意象自动扩写成同质设定。
- 叙事同时管理故事与感受：事件负责推进，场景、身体感、心理活动和声口负责让读者在当下重新经历故事。
- 环境描写只在能制造氛围、危险、阻碍、情绪压力、权力关系或行动线索时展开；连续写景但不推进人物和剧情，视为节奏风险。
- 视角、人称和声口要稳定；如切换视角，必须服务信息差、情感距离或反转。
- 展示与讲述按功能取舍：关键信息可概要，关键转折必须场景化；用概要、省略、场景、停顿调节节奏。
- 类型文要管理读者期待：爽点、打脸、逆袭、悬疑、情感拉扯或战斗高潮都必须由因果和人物选择触发。
- 长篇终局要管理余味：高潮可以热烈，但收束要落到具体的人、路、地方、承诺和生活变化上。主角赢下一战不等于赢下天下，悟出一门绝学不等于成为全体系顶点，影响时代不等于接管时代。
- 修辞和意象少而准；比喻、象征、客观对应物只在能放大人物处境或主题时使用。
- 润色不是加辞藻，而是压缩无功能句子：删除重复心理总结、解释性旁白、无功能景物和漂亮但无因果的比喻，把抽象情绪改成动作、对白、物件变化或场景后果。
- 每次输出前自检：因果是否成立、人物是否按动机行动、伏笔是否有账、节奏是否有起伏、设定是否前后一致；前三章还要自检主角是否聚焦、卖点是否出现、期待感是否成立、首场命名人物是否超过 3 人、是否群像开局、设定说明是否压过故事、环境描写是否喧宾夺主、人物是否停留在白描。
