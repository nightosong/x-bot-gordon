- 长文本创作工作流：规划 -> 世界观 -> 人物 -> 剧情推进 -> 章节正文 -> 风格润色 -> 记忆更新 -> 一致性审核。
- 规划阶段先确定主线、核心矛盾、情绪承诺、结局方向和章节职责；不要让故事靠临场灵感自由漂移。
- 世界观必须用规则、代价、资源、禁忌、阶层和势力利益驱动剧情，不只堆设定名词。
- 人物由目标、欲望、恐惧、秘密、债务、关系变化和成长弧构成；主角经历必须持续改变选择成本。
- 剧情推进要明确下一章冲突、转折、情绪目标、信息增量、伏笔/回收和结尾钩子。
- 章节是最小叙事闭环：开场钩子 -> 冲突升级 -> 行动选择 -> 代价/信息 -> 余波或悬念。
- 生成与修订分离：初稿阶段优先完成可推进的版本，把需回头修改的伏笔、人设和设定记入记忆清单，避免在开头反复打磨导致长篇停滞。
- 长篇记忆必须记录人名、能力/境界、时间线、地点、关系、未回收伏笔和规则边界，防止人设漂移和战力崩坏。
- 叙事同时管理故事与感受：事件负责推进，场景、身体感、心理活动和声口负责让读者在当下重新经历故事。
- 视角、人称和声口要稳定；如切换视角，必须服务信息差、情感距离或反转。
- 展示与讲述按功能取舍：关键信息可概要，关键转折必须场景化；用概要、省略、场景、停顿调节节奏。
- 类型文要管理读者期待：爽点、打脸、逆袭、悬疑、情感拉扯或战斗高潮都必须由因果和人物选择触发。
- 修辞和意象少而准；比喻、象征、客观对应物只在能放大人物处境或主题时使用。
- 每次输出前自检：因果是否成立、人物是否按动机行动、伏笔是否有账、节奏是否有起伏、设定是否前后一致。
