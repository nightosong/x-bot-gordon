- 章节正文默认控制在 4000-5000 字；如果模型输出能力不足，优先保证场景完整和结尾钩子，不要压缩成提纲。
- 章节优先级 P0：必须保证主角目标清晰且持续推进、本章存在明确冲突或阻碍、结尾发生至少一种变化（信息 / 资源 / 关系 / 位置）；如果字数或规则发生冲突，先保 P0。
- 章节优先级 P1：本章至少完成两项增强目标，包括地方活法或生态机制、信息差或误判、人物关系变化或证据出现；P1 服务 P0，不得抢走主角行动线。
- 章节优先级 P2：世界观补充、氛围描写和生态细节扩展只作为增强项；必须通过人物选择、风险变化、资源代价或关系压力进入正文，不能单独铺陈。
- 章节闭环规则：每一章结尾必须改变至少一项状态，包括地点 / 环境 / 人物关系、资源获得 / 失去 / 交换、误判纠正 / 新情报 / 隐藏揭示、受伤 / 消耗 / 失信 / 被追踪等代价。
- 信息释放规则：每一章最多重点引入 1 个新规则、1 个新生态机制和 1 个新人物关系变化；其余信息降级为背景感知或后续回收，避免生态百科化。
- 最终展示格式：合理划分段落，包括第一段在内，每段开头都必须保留两个全角空格“　　”（U+3000 全角空格 ×2）缩进；这是最终正文展示要求，结构化解析或后续检索前可自动 trim。
- 章节正文开头不要输出章节标题，不要出现“第X章 XXXXX”。
- 如果当前章节属于第一章或前三章，必须优先满足主角聚焦、开篇小故事、核心卖点和追读期待；只在内部自评，不把评分写进正文。
- 第一章首场戏建议只围绕主角和当前冲突展开，命名出场人物小于等于 3 人；不要用群像开局、阵营轮播或多视角切换抢走主角焦点。
- 设定表达规则：世界规则、势力、功法、生态和环境必须通过人物决策、资源交换、环境反应、对白冲突或选择代价表达；正文前半段优先让读者看见主角正在处理的问题。
- 移动表达规则：探险、末世游历、废土远行、异境旅行或奇观地图题材，每次抵达、绕路、停留或返回旧地都必须伴随代价变化、风险变化或关系变化；主角主动靠近未知的理由、身体经验、地方活法和偶然改道要进入行动过程。
- 地图叙事规则：远行和地图变化要写成生存压力塑形，不写成捡到关键地图后的任务链、区域解锁、最终 Boss 路线或公开真相式终局；每个重要地点至少让主角的行动、资源、判断或关系发生改变。
- 怪物生态规则：怪物、异兽和灾变生物先作为生态网和地方生活压力出现，例如食物痕迹、幼体线、季节迁徙、共生物、天敌、材料价格、职业作息、当地习俗、误解、职业禁忌、方言、交易或丧葬；生态细节必须引出行动压力、误判、路线变化或战斗触发。
- 战斗触发规则：战斗必须由资源争夺、路径阻断、误判生态行为、职业规则冲突或生存条件变化之一触发；战斗结果必须改变资源、伤势、位置、关系、名声、追踪状态或后续路线。
- 物种变化规则：写作时避免连续把危险写成虫、蛛、菌或同一种野兽；按当前地点自然露出空中、水中、地下、建筑寄生、植物、矿物、群体或类人生物的不同存在方式。
- 正文不得出现“重构原则、资产保全、Schema、字段、工作流、节点、落盘、迭代记录”等项目开发语言。
- 只输出正文，不要附加创作说明、提纲、分析或 Markdown 标题。
