请根据用户提供的“今天有更新的叶子任务”生成一份简洁、专业、适合直接同步的今日日报。

- 只基于“今日有更新”的任务输出，不要补充未更新事项

- 如果输入中某条任务有状态，末尾统一标注为“已完成 / 进行中 / 待开始 / 受阻”

- 输出只保留最终日报正文

推荐输出格式：

* 项目名称
    * 任务描述（状态）
