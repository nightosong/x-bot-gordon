# Prompt Assets

这个目录用于存放 Gordon 系统内置的提示词资产。

放在仓库根目录而不是 `docs/`、`data/` 或某个单独 package 里的原因：

- 它们是跨 `apps` 和 `packages` 共享的源码资产，不属于单一模块实现细节
- 它们需要参与版本管理、代码评审和迭代对比，不属于运行时用户数据
- 它们会被主进程、工作台仓储、内置 Agent / Skill 等多个层级复用，单独放在根目录更容易形成统一入口

目录约定：

- `builtins/agents/`：系统内置 Agent 的默认提示词
- `workbench/`：任务推进、周报、命令工坊等工作台级提示词

补充说明：

- 真正的 Skill 资产现在统一放在仓库根目录 `skills/`
- `skills/` 下的每一个子文件夹都视为一个独立 Skill
- 系统内置 Skill、用户手动新增 Skill、GitHub 导入 Skill 共享同一层目录结构
- Skill 的来源与其他元数据继续保存在工作台配置里，不再通过 `skills/` 下的分层目录区分

命名约定：

- 目录使用复数 `prompts/`，因为这里存放的是一组可扩展提示词资产，而不是单个 prompt
- 文件名使用 `主题.角色.md` 或 `主题.类型.md`
- 推荐后缀：
  - `.system.md`：模型 `system` 提示词
  - `.prompt.md`：通用提示模板
  - `.template.md`：用户可见或业务模板类文案

编写边界：

- 这里存放“静态指导语”和“默认模板”
- 运行时拼接的动态上下文，例如当前周标题、任务内容、用户输入，继续在代码中组装
- 用户自己在界面里编辑后会落库的数据，不回写到这里
