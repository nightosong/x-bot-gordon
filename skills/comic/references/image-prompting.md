# 漫画出图提示词

## 通用结构

中文小说、中文项目或中文用户需求默认使用中文提示词。除非用户明确要求英文，不要把中文原著素材改写成英文标签串。

出图提示词按以下顺序组织：

1. 作品类型和画风。
2. 画面任务：单张关键画面、漫画页、封面或连续图。
3. 主体角色：身份、外形、服饰、动作、表情。
4. 场景：地点、空间关系、时间、天气、光源。
5. 镜头：景别、构图、视角、运动感。
6. 叙事：这一张图推进什么事件。
7. 一致性：必须保留的素材和视觉规则。
8. 负向限制：文字、水印、logo、乱码、多余边框、错位肢体等。

## 素材视图提示词

素材视图提示词用于长期复用，必须比单张剧情图更强调“原著一致性”和“禁止项”：

- 先写素材身份和来源描述，例如“赵乾坤，金刚骷髅形态”。
- 再写视图任务，例如“三视图，正面、侧面、背面完整全身并排”。
- 写清不可变化的识别点：主体形态、体态比例、材质、颜色、眼神/发光点、伤痕、骨节或服饰结构。
- 写清禁止项，尤其是模型容易擅自补的内容。
- 如果原著是特殊本体形态，例如暗金色金刚骷髅，必须明确“骨骼本体”，并禁止衣服、盔甲、披风、鞋靴、头盔、武器和随机装饰。
- 多人/群像素材要写成“多人角色阵列设定图”或“群像设定图”，逐一列出成员，不要写成同一个人的三视图。
- 角色和坐骑、伙伴、关联对象组成的素材要写成“关系设定图”，重点写比例、站位、互动关系和双方识别点。
- 同一素材的阶段版本要先写“这是同一角色/生物的某阶段”，再写变化，例如重伤、换装、成长、异化，不要只堆英文风格词。

```text
赵乾坤，金刚骷髅形态，角色三视图设定表，正面、侧面、背面三个完整全身立姿并排展示。
主体是暗金色金刚骨骼本体，不穿衣服，不穿盔甲，不披披风，不戴头盔，不拿武器。
头骨轮廓、胸腔骨架、脊柱、四肢骨相、手骨比例和暗金骨质必须一致；眼眶透出红色微光，骨缝有细微红光。
干净浅色背景，便于后续漫画分镜复用。
避免：服装、盔甲、披风、鞋靴、头盔、面具、外骨骼装饰、随机武器、文字标签、水印、半身裁切。
```

```text
五位智慧魔法生物老师，群像阵列设定图，16:9 横图。
同一张图中完整并排展示五位导师：紫色鬼火眼的死灵法师、莲花植物道长、黄铜机械先驱、奇美拉学者、纸符式神长老。
每位导师都要有独立轮廓、材质和身份识别点，不能互相遮挡，不能画成同一个角色的三视图。
统一长篇奇幻漫画风格，背景干净，便于后续分镜复用。
避免：单人三视图、随机增加成员、成员身份替换、文字标签、水印。
```

```text
貞德与蓝龙莎莉，角色关系设定图，16:9 横图。
完整展示金发女性圣骑士貞德与蓝龙莎莉的比例、站位和伙伴关系；貞德银白圣骑士甲、冷峻高贵，蓝龙莎莉优雅但明显小于太古龙。
重点保留双方识别点和体型差，画面用于后续坐骑/伙伴分镜参考，不是单人三视图。
避免：把蓝龙画成普通怪物、把关系图画成单人三视图、半身裁切、文字标签、水印。
```

## 单张图模板

```text
漫画风格，[线条/色彩/质感]。单张关键画面：[角色] 在 [场景] 中 [动作]，[情绪/冲突] 清楚可见。
构图：[景别]，[视角]，[主体位置]，[背景层次]。
光线与色彩：[光源]，[主色]，[气氛]。
一致性：[角色服饰/发型/道具/场景地标] 必须保持。
避免：真实文字、水印、logo、乱码字幕、多余边框、错位肢体。
```

## 漫画页模板

```text
一页完整漫画页，4-6 个清晰分格，阅读顺序从左到右、从上到下。
第 1 格：[建立场景]。
第 2 格：[角色动作]。
第 3 格：[阻力/转折]。
第 4 格：[反应/升级]。
第 5 格：[结果/钩子]。
统一画风：[线条/色彩/网点/上色]。
避免真实文字和乱码，必要对白只保留气泡或留白。
```

## 连续图组模板

连续图应给每张图独立段落：

```text
连续叙事图组，共 N 张，保持同一角色、服饰、场景、光线和色彩。
图 1：[场景和目标]。
图 2：[行动开始]。
图 3：[阻力或变化]。
图 4：[结果或钩子]。
每张图都必须推进动作，不重复同一姿势。
```

## 封面模板

```text
漫画封面海报，[作品气质]。主角位于画面 [位置]，[姿态/表情]，背景呈现 [核心冲突或世界信号]。
保留 [上方/下方/侧边] 标题留白，不生成真实文字。
强轮廓，高识别度，色彩统一，适合项目封面。
避免水印、logo、乱码文字和过多小物件。
```

## 素材三视图模板

人物或角色形态三视图必须按设定表处理，不按海报或近景处理：

```text
角色三视图设定表，16:9 横图，同一角色正面、侧面、背面三个完整全身立姿并排展示。
三个人物等高缩小排版，完整落在同一张横向画布内。
必须从头顶到脚底完整可见，头顶、手肘、衣摆、武器、腿部、脚踝、脚掌、鞋底/足骨都不能碰到画布边缘。
脚底下方保留可见留白或地面接触线；任何一个视图都禁止在膝盖、小腿、脚踝、脚掌、鞋底/足骨处裁切。
如果空间不足，优先缩小角色和增加四周留白，不改成半身、膝上、近景或脚部出画构图。
避免：cropped feet, feet out of frame, legs cut off, half body, bust portrait, close-up, poster composition。
```
