# 漫画出图提示词

## 通用结构

出图提示词按以下顺序组织：

1. 作品类型和画风。
2. 画面任务：单张关键画面、漫画页、封面或连续图。
3. 主体角色：身份、外形、服饰、动作、表情。
4. 场景：地点、空间关系、时间、天气、光源。
5. 镜头：景别、构图、视角、运动感。
6. 叙事：这一张图推进什么事件。
7. 一致性：必须保留的素材和视觉规则。
8. 负向限制：文字、水印、logo、乱码、多余边框、错位肢体等。

## 单张图模板

```text
漫画风格，[线条/色彩/质感]。单张关键画面：[角色] 在 [场景] 中 [动作]，[情绪/冲突] 清楚可见。
构图：[景别]，[视角]，[主体位置]，[背景层次]。
光线与色彩：[光源]，[主色]，[气氛]。
一致性：[角色服饰/发型/道具/场景地标] 必须保持。
避免：真实文字、水印、logo、乱码字幕、多余边框、错位肢体。
```

## 漫画页模板

```text
一页完整漫画页，4-6 个清晰分格，阅读顺序从左到右、从上到下。
第 1 格：[建立场景]。
第 2 格：[角色动作]。
第 3 格：[阻力/转折]。
第 4 格：[反应/升级]。
第 5 格：[结果/钩子]。
统一画风：[线条/色彩/网点/上色]。
避免真实文字和乱码，必要对白只保留气泡或留白。
```

## 连续图组模板

连续图应给每张图独立段落：

```text
连续叙事图组，共 N 张，保持同一角色、服饰、场景、光线和色彩。
图 1：[场景和目标]。
图 2：[行动开始]。
图 3：[阻力或变化]。
图 4：[结果或钩子]。
每张图都必须推进动作，不重复同一姿势。
```

## 封面模板

```text
漫画封面海报，[作品气质]。主角位于画面 [位置]，[姿态/表情]，背景呈现 [核心冲突或世界信号]。
保留 [上方/下方/侧边] 标题留白，不生成真实文字。
强轮廓，高识别度，色彩统一，适合项目封面。
避免水印、logo、乱码文字和过多小物件。
```
