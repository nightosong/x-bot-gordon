# 漫画分镜系统

## 文本到分镜

漫画章节可以有正文，也可以只有简介。正文是辅助输入，最终产物仍是漫画图片。

- `summary`：章节内容简介，写本章故事事件、角色目标、冲突变化和结尾钩子。
- `content`：可选章节正文/故事内容，可粘贴小说正文或剧情草稿。
- `prompt`：分镜与出图提示，写图片数量建议、每张图/每格的画面节点、景别、动作和一致性约束。
- `storyboards`：章节内的可编辑分镜轨道，是单章生成的主体。每条分镜包含 `kind / title / beat / dialogue / camera / prompt / imageIds`，并可以挂一张或多张图片。

拆分章节时，优先输出结构化 JSON：

```json
{
  "storyboards": [
    {
      "index": 1,
      "kind": "dialogue",
      "title": "分镜标题",
      "beat": "画面内容与故事节点",
      "dialogue": "对白/旁白，可为空",
      "camera": "景别、构图、镜头运动",
      "prompt": "可直接用于生成这一张图的生图提示词"
    }
  ]
}
```

`kind` 只能使用 `dialogue / scene / action / transition / emotion / other`。不要输出“修改说明”“保留取舍”“创作建议”来替代分镜。

从文本处理成分镜时，每一章至少要回答：

- 本章发生在哪里。
- 谁进入画面。
- 角色想做什么。
- 阻力是什么。
- 画面如何从起点推进到结尾。
- 哪些素材必须保持一致。
- 最后一张图或最后一格留下什么钩子。

## 原著忠实分镜

从线上小说或已有小说章节拆分漫画分镜时，`storyboards[]` 必须是“原文证据驱动”的画面轨道：

- 只拆当前章节已经发生的事件，不提前使用后文人物、装备、地点或真相。
- 分镜标题、画面内容、对白/旁白、镜头和提示词全部使用中文。
- `beat` 写清本条分镜承接的原文章节事件；不要写“保留”“删除”“优化说明”“本次修改”这类工作说明。
- `dialogue` 只能放原文中已有对白、忠实改写的旁白或“无对白/对白留白”，不要凭空编新台词推进剧情。
- `prompt` 必须包含当前分镜的角色、动作、场景、景别、构图、光线、画风和素材一致性约束；如果引用素材库角色/场景，要写出素材名。
- 原文没有明确外观时，可以用“保持素材库既有形象/待定外观”约束，不要自动添加盔甲、衣服、武器、披风、头盔或复杂装饰。
- 如果章节正文不足或来源不可读，不要生成完整分镜；应输出待补原因和可恢复步骤。

章节级 `prompt` 适合写成：

```text
本章建议拆成 N 张图：1）……；2）……。全章保持……画风，引用素材：……。所有画面只表现第 X 章已出现内容，不添加原文未出现角色/装备/场景。
```

分镜级 `prompt` 适合写成：

```text
中文生图提示词：角色/素材名，动作，场景，景别，构图，光线，情绪，统一画风；禁止项：原文未出现的……
```

## 长章节与 20 条分镜

一章可以拆成 20 条甚至更多分镜。拆分时按故事推进分配画面，而不是平均切文本：

- 对话段：用表情、站位、沉默、视线变化拆成 2-5 条。
- 场景刻画：用建立镜头、环境细节、角色进入、空间压迫拆成 2-4 条。
- 过渡段：用路程、时间变化、道具状态、光线变化拆成 1-3 条。
- 打斗段：用预备、试探、交锋、反制、受击、转折、收束拆成 5-10 条。
- 情绪段：用近景、手部细节、背影、环境回应拆成 1-3 条。

如果用户要求“这一章生成 20 张分镜图”，应先生成 20 条 `storyboards`，再逐条出图；不要一次性把整章压成一张“关键画面”。

## 单张漫画图

适合当前分镜的一幕。提示词必须包含：

- 主体角色和动作。
- 场景空间和时代/题材信号。
- 景别和构图。
- 情绪焦点。
- 光线、色彩和画风。
- 与素材库相关的一致性约束。

## 漫画页分镜

漫画页不是拼贴插画，而是阅读顺序清晰的一页。规划时使用 4-6 格：

1. 建立场景或空间方向。
2. 角色进入行动。
3. 阻力或信息差出现。
4. 反应、转折或动作升级。
5. 结果或钩子。

提示词要明确“分格阅读顺序”，但避免要求真实文字、复杂对白或可读小字。需要文字时只保留标题/对白留白。

## 连续图组

连续图组每张图推进一个动作节点：

- 第 1 张：场景和目标。
- 第 2 张：行动开始。
- 第 3 张：阻力或变化。
- 第 4 张：结果、余波或钩子。

不要让连续图只是同一人物的不同姿势。每张图都要有新增信息：位置变化、关系变化、道具状态变化、光线变化、危险逼近或情绪转折。

## 封面海报

封面海报优先强化识别度：

- 主角或核心组合清楚。
- 背景传达题材和冲突。
- 留出标题区域或上方/下方留白。
- 避免画面塞满小物件。
- 不要求模型生成准确文字。

## 图片归档

章节图片必须写入 `images` 并尽量带 `storyboardId`，不要把 Markdown 图片混进 `content`。成图问题和下一轮修正建议优先补到分镜 `prompt` 或图片自身 `prompt` 中，保持“文本来源”和“漫画产物”分离。
