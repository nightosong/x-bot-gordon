# Creature Ecology Design Reference

`creature-ecology-design` 用于补强怪物、异兽、灾变生物、异星生物、妖兽、魔法生物和非人族群的生态逻辑、种类丰富度与命名质量。它不替代 `monster-system.md`，而是作为前置方法：先设计一个地方的生态网，再从生态网中挑出会进入剧情的怪物。

## 资料提炼

本参考吸收的外部资料原则：

- 世界观设定应从自然环境切入：地形、气候和生态互相决定，生物应表现出对栖息环境的适应；政经结构则回答资源、权力和人如何活在框架里。
- 族群设计不能只写外形，还要写物理特征、地理分布、风俗惯习和物质文化；特殊力量或魔法要有原理、普及程度和技术用途。
- 真实感来自世界与情节、主题、人物弧线的交织；世界不只是背景，而要制造冲突、塑造人物选择，并通过历史、文化、政府和语言显出厚度。
- 生物设计应从生态位开始：它吃什么、住哪里、在什么压力下演化出哪些特征；幻想元素可以加入，但仍要有环境适应、起源和限制。
- 怪物与人物冲突前，先明确它想要什么、如何与世界互动；读者不必看到全部设定，但作者必须知道它为何存在。

## 核心原则

不要先设计“怪物能力”。先设计一个生态系统（生物与环境、资源、能量、迁徙、竞争和共生构成的整体），再设计其中的物种。

低级怪物设计最常见的问题不是“不合理”，而是想象力偷懒：把所有危险都写成虫、蛛、菌、会扑咬的兽，或用“一个功能 + 一个弱点”凑出图鉴。真正的生态应像自然史，而不是敌人素材库：它有微型基底、小型群居物、中型捕食者、大型迁徙者、超大型地貌级生命，也有陆地、水域、空域、地下、建筑寄生、雾域和类人社会。

### 低级化失败诊断

如果生成结果出现下列症状，必须推翻重做，而不是局部改名：

- 把怪物当战斗单位设计，先想攻击方式、弱点和出场关卡，再倒填生态理由。
- 物种集中在虫、蛛、菌、蛾、虱、蠹或普通野兽，缺少鸟、鱼、鹿、猿、鳗、龟、魟、鲸、植物、矿物、雾域群体、建筑寄生体和类人异变社会。
- 只有小型和中型威胁，没有微型能量入口、大型迁徙者、巨型或地貌级关键种。
- 只在陆地遭遇，缺少水域、空域、地下、树冠、建筑、雾域和人类社会边界。
- 每个物种互不相关，看不出谁吃谁、谁被谁影响、谁死亡后养活谁。
- 命名只追求酷，批量使用同一后缀，听不出是守井人、桥工、船夫、药铺、官署、猎人还是孩子在叫。
- 怪物没有改变人的生活：没有职业禁忌、交易价格、建筑习惯、路歌、丧葬、童年恐惧和错误传闻。

重做时先退回生态网：非生物压力 -> 能量入口 -> 物种谱系 -> 尺度 / 栖境 / 体态矩阵 -> 食物网 -> 人类接口 -> 命名 -> 战斗。任何跳过前三步直接列怪物名的输出，都视为未完成。

一个可信的怪物生态至少有四层：

| 层级 | 作用 | 写作问题 |
|---|---|---|
| 非生物基础 | 地形、气候、水、盐、热、光、雾、矿物、旧设施 | 这个地方最稀缺、最充足、最反常的资源是什么 |
| 能量入口 | 植物、菌毯、藻类、雾滤生物、矿热细菌、旧能源泄漏 | 谁把光、热、雾、尸体或矿物变成可食资源 |
| 食物网 | 牧食者、滤食者、清道者、小型捕食者、寄生者、顶级捕食者 | 谁吃谁，谁依赖谁，谁死亡后养活谁 |
| 人类接口 | 采集、驯养、禁猎、药用、路权、税、仪式、恐惧、误解 | 人类靠它活、因它死、拿它做生意或讲故事 |

如果某个物种只有“攻击方式”和“弱点”，它还不是生态。它至少要能回答：

- 它从哪里获得能量。
- 它如何繁殖和保护幼体。
- 它什么时候迁徙、休眠、换壳、散孢或发情。
- 它怕什么环境，为什么不是到处泛滥。
- 它与至少三个其他物种有什么关系：食物、天敌、竞争、寄生、共生、清道、传粉或筑巢。
- 它改变了人类哪种具体生活：路、房、衣、食、药、价、税、葬、名、歌、禁忌。

## 形态与尺度矩阵

每个核心生态区在列代表物种前，必须先过一遍“尺度 / 栖境 / 体态”三重检查。这个矩阵用于避免所有怪物都长成虫、蛛、菌或统一的怪兽。

### 尺度层

| 尺度 | 用途 | 写作提醒 |
|---|---|---|
| 微型 | 藻、孢尘、寄生点、盐晶生命、矿热微生物 | 解释能量入口、疾病、气味、水味和材料来源 |
| 小型 | 鸟、鱼、鼠、蛙、甲壳、软体、藤果、小型群居生物 | 做预兆、季节、食物、交易和日常恐惧 |
| 中型 | 鹿、犬、猿、鳗、鹭、蜥、拟人危险体 | 适合章节级遭遇、追逃、误判和猎人职业 |
| 大型 | 迁徙兽、湖中滤食者、树冠巨禽、地下热源生物 | 改变路线、桥梁、村落边界和战斗空间 |
| 巨型 / 超大型 | 湖岛级、鲸级、列车级、山脊级生命 | 用作卷级奇观、迁徙季、宗教和地貌改变 |
| 地貌级 / 群体级 | 菌毯、珊瑚城、树网、声雾群落、城市寄生体 | 像天气或地形一样存在，不一定能被杀死 |

### 栖境层

| 栖境 | 必须考虑的生命形式 |
|---|---|
| 陆地 | 奔跑、伏击、迁徙、筑巢、掘洞、尸体循环 |
| 水域 / 海域 | 鱼、鳗、滤食巨物、浮囊、潮汐共生、盐淡水边界 |
| 空域 / 树冠 | 鸟、翼膜、漂浮囊、风生植物、追光或避雾迁徙 |
| 地下 / 裂缝 | 热源生物、盲行者、矿尘滤食者、地震预兆 |
| 建筑寄生 | 桥、墙、车厢、灯塔、井、档案楼里的共生与侵蚀 |
| 植物冠层 / 林网 | 树、藤、鹿、猿、鸟、寄生花、透明叶膜 |
| 雾域 / 声域 | 气囊、声纹、低频生物、方向误导和群体信号 |
| 类人社会 | 异变人、非人文明、旧械共生者、能交易或守禁忌的族群 |

### 体态层

一个区域的代表物种不要集中在单一体态。可混合：

- 哺乳型 / 鹿型 / 犬型 / 猿型。
- 鸟型 / 翼膜型 / 浮囊型。
- 鱼型 / 鳗型 / 贝类 / 软体 / 水母型。
- 爬行型 / 两栖型 / 甲壳型。
- 植物型 / 树型 / 藤型 / 花型。
- 矿物型 / 玻璃型 / 盐晶型 / 铁锈型。
- 气雾型 / 声纹型 / 电磁型。
- 群体型 / 珊瑚型 / 城市寄生型 / 复合共生型。
- 类人型 / 智性族群 / 失形社会。

强制约束：除非作者明确要写虫灾、蛛巢或菌变题材，否则一个核心生态区中，虫、蛛、菌、虱、蛾、虻、蠹等节肢 / 昆虫 / 真菌形态合计不应超过代表物种的三成；全书层面也不能让它们成为主要想象来源。若已经超标，必须替换为鸟、鱼、兽、软体、植物、矿物、气雾、类人或地貌级生命，并说明它们在食物网中的位置。

## 生态网设计流程

### 1. 先定生态压力

每个地区先定 2-4 个生态压力，不要只写“这里危险”。

| 压力 | 可派生的生物逻辑 |
|---|---|
| 缺水 | 储水器官、夜行、盐腺、抢水迁徙、尸体保水、巢穴封蜡 |
| 盐分过高 | 排盐壳、盐生菌、食盐幼体、淡水恐惧、盐壳贸易 |
| 光线异常 | 逐光、避光、反光伪装、镜面诱捕、靠影子导航 |
| 声音失真 | 拟声、低频沟通、禁喊真名、职业口令、听地职业 |
| 地面不稳 | 轻足、贴地、飞膜、听裂、桥梁寄生、路线季节性 |
| 雾中能量 | 雾滤、孢子繁殖、嗅雾、雾寒休眠、雾潮迁徙 |
| 旧技术残留 | 吃铁锈、趋磁、寄生电缆、旧械共生、污染突变 |

### 2. 再定能量入口

每个核心地貌至少要有一个“生态发动机”（让整个食物网运转的能量来源）。

- 玻璃雨林：矿化树、反光叶、雨中藻膜、玻璃树孔里的水虫。
- 北盐湖：盐藻、盐壳菌、倒星潮带来的微型滤食物。
- 赤潮裂原：红菌毯、地下热风、地缝矿尘。
- 旧铁河：铁轨低潮、锈粉、旧车厢里的热源和灯油残渣。
- 石坞 / 灯墙：废灶余温、井水藻、墙脚霉、灯油烟尘。

没有生态发动机，就不要急着设计大型怪物。大型怪物必须有稳定食物来源或周期性迁徙理由。

### 3. 建立物种谱系

不要只列“九种怪物”。先建立谱系（共同起源或共同生态压力下的生物群），再列代表物种。

```json
{
  "clade": {
    "name": "",
    "origin": "",
    "sharedTraits": [],
    "habitats": [],
    "commonPressure": "",
    "species": [
      {
        "role": "producer | grazer | scavenger | parasite | predator | engineer | keystone | anomaly",
        "localName": "",
        "officialName": "",
        "niche": "",
        "relations": [],
        "humanUse": "",
        "storyUse": ""
      }
    ]
  }
}
```

谱系比单体怪物更有真实感。比如“盐湖生物”不该只有一头湖上巨物，还应有倒星藻、白线鱼、盐骨贝、倒星鹭、盲潮母、驮星幼体线、夜渡人和猎壳人的职业冲突。主线可能只重点写一种，但背景里必须看得出完整生态。

### 4. 填满生态位

每个重要地区建议至少补齐 8 类生态位，其中 2-3 类进入高张力剧情，其余作为生活痕迹和背景压力。

| 生态位 | 功能 | 常见剧情用途 |
|---|---|---|
| 基底生产者 | 把光、热、雾、矿物、尸体转成食物 | 解释为什么这里能养活大型生物 |
| 清道者 / 分解者 | 处理尸体、废料、旧设施 | 疾病、禁葬、尸体争夺、废墟异味 |
| 小型群居物 | 量大、传播快、被许多物种吃 | 预兆、季节、灾前征候 |
| 牧食 / 滤食者 | 吃菌毯、藻、矿尘、雾 | 迁徙、猎捕、驯养、路被堵 |
| 中型捕食者 | 捕猎小兽或幼体 | 伏击、夜路危险、职业猎人 |
| 寄生 / 拟态者 | 依附身体、语言、建筑或记忆 | 恐惧、误认、伦理和医救 |
| 生态工程者 | 改河、蛀桥、筑巢、结晶、造林 | 地形变化、路线改变、村落禁忌 |
| 关键种 / 顶级异常 | 它变化会牵动整个地区 | 卷级事件、迁徙季、灾难或仪式 |

不要把所有物种都写成“会杀人”。可信生态需要无害、可食、可驯、可厌、可卖、可误会、可敬畏的生物。每个重要地区还应至少出现 1 个空域或高处生命、1 个水域 / 潮湿边界生命、1 个陆地或地下中大型生命，以及 1 个巨型、超大型、地貌级或群体级关键存在；城市 / 建筑型地区可用墙、桥、井、车厢或档案楼寄生生态替代自然栖境。

### 5. 为每个物种设计关系

每个物种至少补五条关系：

- 吃谁。
- 被谁吃。
- 与谁竞争。
- 与谁共生或被谁寄生。
- 死后或迁徙后养活谁。
- 人类如何插入这条关系。

示例结构：

```json
{
  "species": "驮星",
  "relations": [
    "幼体沿白线鱼所在的淡水暗线取水",
    "成体背壳附着盐骨贝，倒星鹭会啄食壳缝浮盐",
    "盲潮母在退潮夜滤食随驮星迁徙而来的幼鱼",
    "倒星潮退后，尸壳和盐骨养出新的藻膜",
    "猎壳人破坏迁徙线后，白线鱼断流，夜渡绳会被盐潮腐蚀"
  ]
}
```

### 6. 设计季节和扰动

生态不是静态设定。至少给每个地区一个周期：

- 雾潮季：孢子、拟声、趋光生物活跃。
- 退潮夜：旧路露出，滤食者和猎人同时出动。
- 换壳期：大型生物虚弱，药价下降，禁猎更严格。
- 产幼期：危险不一定来自成体，而来自人类误入幼体线。
- 灾后腐烂期：清道者暴涨，疾病和黑市材料增加。

周期必须改变路线、物价、职业作息和战斗方式。

## 命名系统

命名差通常不是字不好听，而是没有使用者、来源和语境。一个重要物种至少要有 3-5 个名字：

| 名称 | 使用者 | 来源 |
|---|---|---|
| 俗名 | 本地居民、孩子、老人 | 声音、外形、灾害、禁忌、传说 |
| 行话 | 船夫、桥工、猎人、药铺、商队 | 危险信号、材料价值、处理方法 |
| 官名 | 门籍署、军队、档案馆 | 管理、登记、赏金、税收 |
| 学名 / 谱系名 | 学者、守档人、医者 | 生态位、结构、亲缘、栖息地 |
| 避名 / 反称 | 祭祀、丧葬、禁区居民 | 不能直呼、祈求绕开、安抚恐惧 |
| 商品名 | 黑市、药铺、商人 | 提价、避讳、欺骗外人 |

命名时禁止批量套固定后缀，例如所有东西都叫“X兽、X虫、X者”。可以混用：

- 声音：潮鸣、啮桥、三更敲、哑铃。
- 痕迹：盐脊、灰窝、倒天、断灯、空鞋印。
- 行为：随灯、回名、贴梁、驮星、偷热。
- 材料：盐骨、灰丝、玻璃衣、铁鳞、红毯。
- 禁忌：不喊名、夜里不吹、第二影、空灯位。
- 官方编号：灯墙甲类、桥患乙种、赤潮迁徙体。
- 学名：桥肺潮生群、悬窗折光群、铁河低频趋热体。

好名字应该让读者知道“谁这么叫它”。同一名字不必全书通用；称呼变化本身能暴露人物职业、地区、阶层和立场。

## 深生态设计层

生态设计的目标不是“看起来专业”，而是让怪物、异兽、灾变生物或异星生命像真的长期活在当地。

深生态设计优先回答：

- 能量从哪里进入这个系统。
- 哪些生命负责把能量固定下来。
- 哪些生命负责搬运、滤食、分解、寄生、捕猎、筑巢和改造环境。
- 季节、灾变、迁徙、繁殖如何改变当地人的行动。
- 人类如何误解生态，又如何从错误经验中发展出有效手艺。

如果一个生态只列出“十种怪物”，没有能量入口、幼体、尸体去向、天敌、共生和人类职业，它仍然是图鉴，不是生态。

## 能量入口扩展

奇幻 / 科幻生态可以使用真实生态逻辑，也可以设置异常能量入口，但每种入口都要产生后果。

| 能量入口 | 生态后果 | 人类后果 |
|---|---|---|
| 阳光 | 植物、藻类、叶冠生物、日照迁徙 | 农业、晒场、遮光禁忌 |
| 地热 | 地下菌毯、热泉滤食者、矿物壳生命 | 温泉聚落、热井税、夜间迁徙 |
| 潮汐 | 滩涂滤食、潮池繁殖、迁徙窗口 | 渔汛、潮历、错潮死亡 |
| 尸体 | 清道者、骨林、腐殖链、寄生物 | 葬礼禁忌、尸体黑市、瘟疫恐惧 |
| 盐 / 矿物 | 盐壳生命、晶化甲壳、矿尘滤食 | 采盐、矿税、皮肤病、工具腐蚀 |
| 雾 / 气溶胶 | 悬浮捕食、声波定位、凝水植物 | 听雾人、灯号、真名禁忌 |
| 魔力 / 灵气 | 灵脉生产者、法器寄生、异化动物 | 宗门资源、禁地、灵材价格 |
| 旧能源 | 机械寄生、辐射变异、电磁趋性 | 回收工、禁区、假冒零件 |
| 记忆 / 情绪 | 心智寄生、梦境群落、情绪牧场 | 祭仪、心理税、失忆行业 |

异常入口越奇特，越要补底层稳定性：它如何周期性出现，谁最先利用，谁因此富起来，谁因此生病或被驱逐。

## 生态位扩展

每个核心地区尽量覆盖下列生态位，不必全部正面登场，但应在痕迹、价格、职业和民俗里存在。

### 基底生产者

负责把能量变成可被其他生命使用的物质。

可能形态：

- 盐湖藻毯。
- 热井菌膜。
- 会聚雾的藤。
- 吃矿尘的苔。
- 吸收月光的贝床。
- 寄生旧电缆的根系。

写作作用：

- 决定当地颜色、气味和基础资源。
- 决定人类聚落为什么存在。
- 决定季节性饥荒或迁徙。

### 分解者 / 清道者

负责处理尸体、粪便、废物和战场残骸。

写作作用：

- 让死亡有生态后果。
- 让葬礼、战场清理、尸体买卖和瘟疫防控变得具体。
- 制造“尸体不能留在这里”的时间压力。

### 小型群居物

小型生命最容易让世界有日常感。

作用：

- 孩子捕捉、赌天气、当宠物或当玩具。
- 商人用来验货、测毒、报潮。
- 猎人根据它们的逃散方向判断大型捕食者。
- 厨房、灯油、粮仓、旧书和衣物都可能被它们改变。

### 牧食 / 滤食者

负责把基底资源转成可见肉体。

作用：

- 形成牧场、渔场、迁徙路线和税源。
- 吸引捕食者。
- 决定人类饮食、皮革、骨器和药材。

### 捕食者

捕食者不应只负责战斗。

作用：

- 控制牧食者数量。
- 改变人类路线和作息。
- 让孩子、老人、牲畜、夜路、雨季有不同风险。
- 形成猎人职业和禁猎规则。

### 寄生 / 拟态者

寄生和拟态最适合制造认知恐惧。

作用：

- 让人怀疑亲人、牲畜、货物、声音或影子。
- 产生检疫、验身、封名、隔离、火烧、净化等制度。
- 形成误杀、歧视、隐瞒病情和黑市治疗。

### 生态工程者

它们改变环境本身。

可能行为：

- 筑坝、筑巢、挖洞、结晶、吐丝、搬骨、种植、腐蚀建筑。
- 改变河道、桥梁承重、地面硬度、空气湿度和植物分布。

作用：

- 让地图被生命塑形。
- 让人类建筑、道路、职业和禁忌随之改变。

### 关键种

关键种不一定最强，但一旦消失，整个系统会改变。

作用：

- 维持食物网平衡。
- 影响季节迁徙。
- 让某个职业、节日、税种或宗教存在。
- 成为组织争夺或保护对象。

## 生命周期

每个重要物种至少考虑生命周期，而不是只有成年体。

生命周期问题：

- 幼体在哪里出生。
- 谁护崽，谁吃幼体。
- 成长期需要什么资源。
- 成熟标志是什么。
- 繁殖季如何改变行为。
- 老年或死亡后会发生什么。

生命周期能制造章节：

- 主角遇到的不是怪物发狂，而是误入育幼期。
- 人类猎杀成年体后，幼体失控泛滥。
- 某种珍贵材料只有蜕壳期才有。
- 老年巨兽临死前迁徙，沿途改变城镇经济。
- 寄生物幼体无害，成体才危险，因此检疫出现伦理争议。

## 季节、扰动与灾年

生态不能全年同一种状态。

可设计的周期：

- 春季产卵。
- 夏季腐殖暴涨。
- 秋季迁徙。
- 冬季休眠。
- 雾季失向。
- 雨季封路。
- 枯水期暴露古巢。
- 月潮期大型滤食者靠岸。

可设计的扰动：

- 战争导致尸体增加，清道者暴涨。
- 过度捕猎导致小型害兽泛滥。
- 组织修坝改变水位，旧渔村破产。
- 外来物种随商路进入。
- 魔力泄漏改变繁殖周期。
- 气候异常让迁徙路线穿过城市。

生态扰动最适合把世界观变成剧情压力。不要只说“生态失衡”，要写谁涨价、谁失业、谁感染、谁趁机征税。

## 人类职业接口

生态必须长出职业。

| 职业 | 生态来源 | 剧情用途 |
|---|---|---|
| 听潮人 | 判断潮汐和巨兽迁徙 | 带路、误判、泄密 |
| 骨洗工 | 清理大型尸体 | 发现证据、感染风险 |
| 灯油匠 | 利用趋光小虫提油 | 资源争夺、夜路安全 |
| 验巢师 | 判断巢穴是否活跃 | 过路许可、组织腐败 |
| 缝肺医 | 处理雾域寄生 | 时间压力、道德选择 |
| 盐皮猎 | 猎取盐壳甲片 | 黑市、债务、职业病 |
| 迁徙记路人 | 记录季节路线 | 地图失真、旧路回收 |
| 禁名祭司 | 管理与声纹怪相关的名字 | 宗教、恐惧、身份 |

职业接口让生态进入社会：有许可证、行规、黑话、学徒、事故、赔偿、禁忌和阶层。

## 物种关系写法

每个物种至少连接三个关系：

- 吃谁。
- 被谁吃。
- 与谁竞争。
- 与谁共生。
- 寄生谁或被谁寄生。
- 死后养活谁。
- 哪个职业利用它。
- 哪个组织控制它的材料。
- 哪种民俗误解它。

关系越多，怪物越不容易变成一次性敌人。

## 生态与叙事功能

生态信息必须能转化为章节功能。

| 生态信息 | 章节功能 |
|---|---|
| 迁徙路线 | 主角必须改路或抢时间 |
| 繁殖季 | 禁区临时变危险 |
| 清道者 | 尸体证据会消失 |
| 共生物 | 反制大型怪物的线索 |
| 天敌缺席 | 说明某种更大灾害发生 |
| 材料涨价 | 暴露组织操盘或战争预兆 |
| 小动物异常 | 提前提示天气、怪物或污染 |
| 食物短缺 | 推动聚落冲突和迁徙 |

如果生态不能改变路线、资源、职业、风俗、战斗或人物判断，就应压缩。

## 生态色谱

不同地区要有不同生态色谱，避免所有地方都变成潮湿、雾、菌、腐烂。

可组合维度：

| 维度 | 示例 |
|---|---|
| 温度 | 炽热、寒冷、温湿、干裂、昼夜温差极大 |
| 颜色 | 盐白、铜绿、锈红、荧蓝、骨黄、墨黑 |
| 声音 | 空鸣、潮响、骨振、低频、翅浪、静默 |
| 运动 | 缓慢、迁徙、震动、漂浮、群聚、周期苏醒 |
| 时间感 | 腐烂、冻结、风化、生长、结晶、蜕变 |
| 情绪 | 庄严、荒凉、诡艳、安静、躁动、压抑 |
| 危险 | 污染、坍塌、诱导、失温、失声、过热 |

同一卷内应轮换色谱，让地图和生态都更容易被记住。

## 审核清单

完成怪物生态后检查：

- 是否有生态发动机，而不是凭空养出大型怪物。
- 是否先做过尺度 / 栖境 / 体态矩阵，是否覆盖微型、小型、中型、大型、巨型 / 超大型或地貌级生命。
- 是否覆盖陆地、水域、空域、地下、建筑寄生、植物冠层、雾域或类人社会中的多种栖境，而不是只有地面怪物。
- 是否存在哺乳、鸟、鱼、软体、植物、矿物、气雾、群体、类人等多种体态，而不是主要依赖虫、蛛、菌。
- 虫、蛛、菌等低成本形态是否超过三成；若超过，是否有明确题材理由，否则判为需要重做。
- 是否有生产者、清道者、小型群居物、牧食者、捕食者、寄生者、生态工程者和关键种。
- 每个重要物种是否至少连接三个其他物种和一个人类职业。
- 物种是否有繁殖、幼体、季节、迁徙、天敌和数量限制。
- 物种能力是否从生态压力长出，而不是为了战斗临时分配。
- 地方是否因这些生物产生物价、禁忌、职业、建筑、饮食、丧葬或方言变化。
- 命名是否多来源，是否能看出使用者和立场。
- 是否保留一些不可完全理解的地方，而不是百科全知。
- 是否只有少数物种进入战斗，其余也能通过痕迹、材料、声音和习俗让世界变厚。
