# Style Controller Reference

`style_controller` 的目标不是贴几个形容词，而是控制读者实际感到的叙事质地。风格只能调整表达方式，不能改写事实、人物动机、时间线或世界规则。

## 控制维度

| 维度 | 需要判断的问题 |
|---|---|
| 叙事距离 | 叙述贴近角色即时感受，还是保留更高处的讲述视角 |
| 视角纪律 | 是否稳定遵守 POV，不随意泄露角色不知道的信息 |
| 句式节奏 | 短句推进、长句铺陈、停顿、留白与段落密度是否匹配场景 |
| 词汇域 | 现代口语、古典词、行业词、网文爽感词是否混杂失控 |
| 情绪温度 | 克制、热烈、幽默、压抑、冷峻等情绪是否服务当前剧情 |
| 类型承诺 | 读者期待的爽点、悬念、情感张力、奇观或推理是否被持续兑现 |
| 信息密度 | 设定、动作、心理、对白、环境的比例是否适合章节目标 |

用于写入 `storyAssets.styleProfile`：

## 类型化调参

### 爽文 / 男频网文

- 每章要有明确推进：危机、反击、收获、身份变化或新钩子。
- 爽点来自压制关系反转，不只是角色说狠话。
- 战力、资源和规则必须可累计，避免上一章获得的能力下一章失效。
- 段落宜短，动作和结果反馈要快，但关键高潮前允许放慢。

### 晋江向情感 / 女性成长

- 情绪转折必须由具体行为触发，不靠旁白宣布“她动心了”。
- 关系推进要看见边界、试探、误解、选择和代价。
- 对白应体现身份、亲疏、权力差和自我保护。
- 外部事件要反过来改变人物关系，避免剧情和感情线分离。

### 轻小说

- 角色声口要鲜明，可用轻快吐槽和反应差制造节奏。
- 设定解释要嵌进冲突、误会、任务或角色互动里。
- 场景切换可以快，但每场必须有一个可感知的状态变化。
- 避免只有概念没有画面，奇观应被角色亲身触碰。

### 武侠 / 江湖

- 重点不是堆古词，而是门派秩序、江湖名声、恩怨债与选择代价。
- 动作描写要让读者看清方位、招式意图、破绽和胜负原因。
- 人物说话可克制，但沉默也要推动关系或威胁。
- 风骨来自价值选择，不来自空泛格言。

### 文学化 / 慢热

- 允许低速，但每段都要增加观察、关系、象征或心理压力。
- 意象应服务人物处境，避免独立成装饰段落。
- 句子可以更长，但信息推进不能停。
- 内心独白要有矛盾和发现，不重复已知情绪。

## 修订流程

1. 先提取当前文本的真实风格，而不是只看用户给的风格标签。
2. 对照目标风格，列出 3-5 个最影响读感的偏差。
3. 只改表达层：节奏、词汇、段落、视角、情绪温度。
4. 检查事实是否被误改，尤其是姓名、地点、能力、时间和关系。
5. 输出时附带可写入 `styleProfile.revisionRules` 的稳定规则。

## 去口水化规则

当用户指出文本“无聊、口水化、AI 味、不够精彩”时，优先判断是否存在下列问题：

| 问题 | 修法 |
|---|---|
| 抽象评价替代场景 | 把“危险、宏大、诡谲、震撼”改成具体物、动作、声音、气味、代价 |
| 设定说明压过任务 | 先写角色要拿什么、怕失去什么，再释放设定 |
| 连续同质句式 | 改用短句推进、动作反馈、停顿和具体判断 |
| 深层主题直说 | 把主题放进账册、价格、资源分配、称谓、路权、禁忌和选择后果 |
| 爽点只有口号 | 让主角付出代价、拆掉压制关系，并获得可见升级 |
| 奇观只有地名 | 绑定资源、怪物、路线变化、人类利用和成长结果 |

修订时不要只替换形容词。应先增加行动压力和状态变化，再压缩说明段。

## 命名质感

命名应服务世界历史和人物认知，不要把所有概念套同一个字头或同一种格式。

可使用的命名来源：

- 地理俗称：来自地貌、气候、路线、危险或资源。
- 职业称呼：来自工种、税制、行会、猎队、军阶或黑市。
- 官称 / 技术名：来自城市制度、旧科技、宗教、契约或学派。
- 禁忌名：来自灾难记忆、族群恐惧或不可直呼的规则。
- 他者称呼：不同族群对同一事物的误称、蔑称、敬称或交易名。

同一事物允许有多个名字，但每个名字必须说明是谁在用、为什么这样叫。避免“雾X、X雾X、灵X、神X”式批量套壳。

## 精准简练

专业写作助手的表达应短、准、可执行：

- 用“把第 12 章的水源冲突提前到过桥前”替代“进一步强化紧张感”。
- 用“怪物靠听灯油滴落定位”替代“怪物具有独特感知能力”。
- 用“这一章赢了灰牌，但失去进药棚的资格”替代“获得成长同时付出代价”。

少用空泛词：`宏大`、`丰富`、`精彩`、`深刻`、`逐渐`、`某种意义上`、`真正`、`命运`。使用时必须紧跟具体证据。

## 常见失败

- 把风格等同于作者名或平台名，结果只套表面词汇。
- 为了“高级”牺牲剧情推进，让章节失去目标。
- 为了“爽”让人物无代价获胜，破坏长期可信度。
- 为了“古风”堆砌生僻词，人物声口反而不稳定。
- 为了“轻松”让所有角色说同一种玩笑话。
