# Style Controller Reference

`style_controller` 的目标不是贴几个形容词，而是控制读者实际感到的叙事质地。风格只能调整表达方式，不能改写事实、人物动机、时间线或世界规则。

## 控制维度

| 维度 | 需要判断的问题 |
|---|---|
| 叙事距离 | 叙述贴近角色即时感受，还是保留更高处的讲述视角 |
| 视角纪律 | 是否稳定遵守 POV，不随意泄露角色不知道的信息 |
| 句式节奏 | 短句推进、长句铺陈、停顿、留白与段落密度是否匹配场景 |
| 词汇域 | 现代口语、古典词、行业词、网文爽感词是否混杂失控 |
| 情绪温度 | 克制、热烈、幽默、压抑、冷峻等情绪是否服务当前剧情 |
| 类型承诺 | 读者期待的爽点、悬念、情感张力、奇观或推理是否被持续兑现 |
| 信息密度 | 设定、动作、心理、对白、环境的比例是否适合章节目标 |

## 风格档案 Schema

用于写入 `storyAssets.styleProfile`：

## 类型化调参

### 爽文 / 男频网文

- 每章要有明确推进：危机、反击、收获、身份变化或新钩子。
- 爽点来自压制关系反转，不只是角色说狠话。
- 战力、资源和规则必须可累计，避免上一章获得的能力下一章失效。
- 段落宜短，动作和结果反馈要快，但关键高潮前允许放慢。

### 晋江向情感 / 女性成长

- 情绪转折必须由具体行为触发，不靠旁白宣布“她动心了”。
- 关系推进要看见边界、试探、误解、选择和代价。
- 对白应体现身份、亲疏、权力差和自我保护。
- 外部事件要反过来改变人物关系，避免剧情和感情线分离。

### 轻小说

- 角色声口要鲜明，可用轻快吐槽和反应差制造节奏。
- 设定解释要嵌进冲突、误会、任务或角色互动里。
- 场景切换可以快，但每场必须有一个可感知的状态变化。
- 避免只有概念没有画面，奇观应被角色亲身触碰。

### 武侠 / 江湖

- 重点不是堆古词，而是门派秩序、江湖名声、恩怨债与选择代价。
- 动作描写要让读者看清方位、招式意图、破绽和胜负原因。
- 人物说话可克制，但沉默也要推动关系或威胁。
- 风骨来自价值选择，不来自空泛格言。

### 文学化 / 慢热

- 允许低速，但每段都要增加观察、关系、象征或心理压力。
- 意象应服务人物处境，避免独立成装饰段落。
- 句子可以更长，但信息推进不能停。
- 内心独白要有矛盾和发现，不重复已知情绪。

## 修订流程

1. 先提取当前文本的真实风格，而不是只看用户给的风格标签。
2. 对照目标风格，列出 3-5 个最影响读感的偏差。
3. 只改表达层：节奏、词汇、段落、视角、情绪温度。
4. 检查事实是否被误改，尤其是姓名、地点、能力、时间和关系。
5. 输出时附带可写入 `styleProfile.revisionRules` 的稳定规则。

## 去口水化规则

当用户指出文本“无聊、口水化、AI 味、不够精彩”时，优先判断是否存在下列问题：

| 问题 | 修法 |
|---|---|
| 抽象评价替代场景 | 把“危险、宏大、诡谲、震撼”改成具体物、动作、声音、气味、代价 |
| 设定说明压过任务 | 先写角色要拿什么、怕失去什么，再释放设定 |
| 连续同质句式 | 改用短句推进、动作反馈、停顿和具体判断 |
| 深层主题直说 | 把主题放进账册、价格、资源分配、称谓、路权、禁忌和选择后果 |
| 爽点只有口号 | 让主角付出代价、拆掉压制关系，并获得可见升级 |
| 奇观只有地名 | 绑定资源、怪物、路线变化、人类利用和成长结果 |

修订时不要只替换形容词。应先增加行动压力和状态变化，再压缩说明段。

## 命名质感

命名应服务世界历史和人物认知，不要把所有概念套同一个字头或同一种格式。

可使用的命名来源：

- 地理俗称：来自地貌、气候、路线、危险或资源。
- 职业称呼：来自工种、税制、行会、猎队、军阶或黑市。
- 官称 / 技术名：来自城市制度、旧科技、宗教、契约或学派。
- 禁忌名：来自灾难记忆、族群恐惧或不可直呼的规则。
- 他者称呼：不同族群对同一事物的误称、蔑称、敬称或交易名。

同一事物允许有多个名字，但每个名字必须说明是谁在用、为什么这样叫。避免“雾X、X雾X、灵X、神X”式批量套壳。

## 精准简练

专业写作助手的表达应短、准、可执行：

- 用“把第 12 章的水源冲突提前到过桥前”替代“进一步强化紧张感”。
- 用“怪物靠听灯油滴落定位”替代“怪物具有独特感知能力”。
- 用“这一章赢了灰牌，但失去进药棚的资格”替代“获得成长同时付出代价”。

少用空泛词：`宏大`、`丰富`、`精彩`、`深刻`、`逐渐`、`某种意义上`、`真正`、`命运`。使用时必须紧跟具体证据。

## 深层风格控制

风格不是“用什么词”，而是读者在阅读时如何感到距离、速度、压力、情绪和可信度。

调风格前先判断五件事：

- **镜头贴近谁**：读者是贴着角色身体、听角色脑内声音，还是站在更高处看故事。
- **信息释放给谁**：读者知道得比角色多、少，还是一样多。
- **句子推动什么**：动作、判断、情绪、设定、氛围、关系，哪一种在当前段落优先。
- **段落承担什么功能**：推进、停顿、转场、压迫、余波、反讽、悬念。
- **类型承诺是什么**：爽感、情感、奇观、推理、恐怖、文学观察、群像史诗，各自期待不同读感。

改稿时不要只把文字“润色得更漂亮”。先判断这一段在章节中的功能，再决定是否需要更短、更冷、更密、更口语、更古典、更快或更克制。

## 叙事距离

叙事距离（读者与角色意识之间的远近）决定文本质地。

| 距离 | 特征 | 适用 |
|---|---|---|
| 极近 | 感官、冲动、碎念、即时判断多，解释少 | 逃生、疼痛、恐惧、羞耻、恋爱触动 |
| 近距 | 跟随角色判断，但句子仍保持清晰 | 大多数章节正文 |
| 中距 | 角色行动与环境并重，少量总结 | 转场、群像、调查、旅行 |
| 远距 | 概括历史、制度、战争、时间跨度 | 序章、卷首、史诗旁白、世界变化 |

常见问题：

- 逃命时叙事太远，像在写战报。
- 制度介绍时叙事太近，角色碎念打断信息。
- 情感场突然远距总结，读者看不见具体行为。
- 群像场频繁贴近每个人，视角失控。

修法：

- 近距场景多写“角色此刻能看见、听见、误判、忍住或不敢说的东西”。
- 远距段落要短，最好把宏观信息落到一个物件、账册、地名变化或人物命运上。
- 切换距离时用动作或场景边界过渡，不要在同一段随意跳。

## 视角纪律

视角不是格式问题，而是信任问题。读者一旦发现叙述知道了角色不该知道的信息，就会出戏。

检查：

- 当前 POV（视角人物）是谁。
- 这名角色能否看见这件事。
- 他是否知道对方真实动机。
- 他是否理解这个制度、方言、技术或怪物行为。
- 他会用什么词称呼眼前事物。

常用修法：

- 把“他很害怕”改成 POV 能看见的证据：手指按错印章、杯沿磕牙、说话变敬称。
- 把“她不知道这是陷阱”改成读者可见的异常：路券太新、守卫不问暗号、摊主提前收摊。
- 把全知解释拆到事后、传闻、账本、对话或下一章发现。
- 让误解成为人物经验的一部分，而不是作者错误。

## 句式节奏

句式节奏要服务场景压力。

| 场景 | 句式策略 |
|---|---|
| 追逃 / 战斗 | 短句、动词、方向、感官反馈、少解释 |
| 情感试探 | 中短句、停顿、未说出口的话、动作插入 |
| 奇观初见 | 先一两个强画面，再扩展尺度和异物逻辑 |
| 制度压迫 | 程序性重复、表格感、称呼变化、等待感 |
| 余波 | 句子可放慢，写清伤口、损耗、沉默和新关系 |
| 史诗转场 | 长短结合，长句铺空间，短句落代价 |

节奏不是永远快。真正有效的快，是读者知道角色正在失去什么；真正有效的慢，是每个停顿都增加压力、信息或情感。

## 段落密度

段落可以按功能分层：

- **动作段**：角色做了什么，空间如何回应。
- **判断段**：角色如何理解局面，哪里可能错。
- **关系段**：谁看见谁的脆弱、隐瞒或退让。
- **设定段**：只释放当前选择所需的信息。
- **感官段**：气味、声音、触感、光线如何改变行动。
- **余波段**：胜负之后，身体、资源、关系和规则如何改变。

AI 味常来自段落功能混乱：一段里同时解释世界、总结情绪、夸奇观、安排动作，结果没有重点。

修订时可把长段拆成：

```text
动作 -> 反馈 -> 判断 -> 代价
```

或：

```text
话语 -> 沉默 -> 小动作 -> 权力变化
```

## 词汇域控制

词汇域（文本中词语来源和质感的范围）必须稳定。

### 现代口语

适合都市、轻小说、爽文、强互动对白。优势是快、近、反应灵敏。风险是削弱古代、奇幻或史诗质感。

控制：

- 现代口语可以用于角色声口，但旁白要看题材。
- 网络词、梗词和过度吐槽要限制在特定角色，不要全员同化。
- 爽文口语要有行动结果支撑，不要只靠“牛”“离谱”“炸裂”。

### 古典 / 武侠词汇

适合江湖、古代、仙侠、历史感。优势是风骨和距离感。风险是堆砌生僻词导致空泛。

控制：

- 古风不等于满篇雅词，关键是称呼、礼法、名声、恩怨和选择代价。
- 动作要清楚，不要为了雅致牺牲方位和胜负原因。
- 角色身份不同，文雅程度不同；镖师、书生、官吏、乞儿不能同一种辞藻。

### 行业 / 制度词

适合科幻、职场、组织、战争、奇幻职业。优势是可信。风险是术语堆积。

控制：

- 首次出现术语时让它伴随动作、代价或误解。
- 技术词要有使用者：官称、行话、俗称、蔑称不能混成一种。
- 术语重复出现时应逐渐承担剧情功能，而不是只做装饰。

### 文学化词汇

适合慢热、心理、旅行、废土、诗性奇观。优势是余韵。风险是主题直说和意象泛滥。

控制：

- 意象必须绑定人物处境，不可独立漂浮。
- 美句之后要有状态变化。
- 抽象词后必须跟具体证据。

## 情绪温度

情绪温度要和章节目标匹配。

| 温度 | 表现 | 风险 |
|---|---|---|
| 冷 | 克制、观察、少解释、留白 | 情绪不够进入 |
| 暖 | 关注关系、小动作、体面和互助 | 失去危险感 |
| 热 | 强冲突、强宣言、强反馈 | 过度煽情 |
| 幽默 | 反应差、误解、轻快节拍 | 破坏严肃场 |
| 压抑 | 呼吸困难、重复、等待、无出口 | 长期疲劳 |
| 庄严 | 慢节奏、仪式、历史感 | 空泛宏大 |

不要让整本书只有一种温度。长篇尤其需要温度切换：高压之后有缓冲，亲密之后有外部代价，幽默之后不取消伤害，庄严之后落回人间生活。

## 类型读感校准

### 男频成长 / 爽感

读者期待：

- 被低估后的反制。
- 资源、能力、身份或名声的可见增长。
- 规则被理解、利用、突破。
- 强敌承认或结构性压制被拆掉。

语言策略：

- 结果反馈要明确。
- 代价可以存在，但不能让收获完全失效。
- 句子要有力量，但少空喊。
- 每章至少有一个状态前后差。

### 女频情感 / 成长

读者期待：

- 关系边界变化。
- 人物自我认知变化。
- 选择的伦理和情绪代价。
- 细节证明关系，而非口头宣布。

语言策略：

- 多写未说出口、保留体面、试探、误会和小证据。
- 外部事件必须改变关系位置。
- 心理描写要有矛盾和发现，不重复“难过 / 心动 / 失望”。

### 悬疑 / 推理

读者期待：

- 信息公平但不直给。
- 每个细节可能有意义。
- 解释能回收旧线索。
- 视角纪律强。

语言策略：

- 形容词少，证据多。
- 不要替角色总结真相。
- 异常细节要具体，误导也要合理。
- 反转后旧文本仍成立。

### 恐怖 / 怪谈

读者期待：

- 不确定性。
- 禁忌被触碰。
- 日常被轻微扭曲。
- 解释不能过早完全闭合。

语言策略：

- 少写怪物全貌，多写规则、痕迹、声音和他人反应。
- 恐惧来自角色必须继续行动。
- 禁忌名、重复动作、错误称呼和空间异常比形容词更有效。

### 奇幻 / 科幻史诗

读者期待：

- 世界尺度。
- 制度、地图、技术或魔法有自洽逻辑。
- 人物选择能推动大结构。

语言策略：

- 宏观段落必须落到具体人、物、路线或价格。
- 设定解释要分批释放。
- 地名和术语要有命名来源。
- 奇观要改变行动，而不只是漂亮。

## 对白风格控制

对白风格来自四个来源：

- 身份：职业、教育、阶层、年龄、地位。
- 关系：亲密、敌对、上下级、交易、旧债。
- 场景压力：时间、危险、旁观者、不可说的秘密。
- 欲望：角色想得到什么，想隐藏什么。

修订对白时检查：

- 每个人是否都在争取某件事。
- 是否有人在避开真话。
- 是否有权力变化，而不是平铺信息。
- 是否所有角色都在说同一种机智话。
- 长句是否被动作、沉默、环境反馈打断。

对白常用压缩法：

- 删除问候式废话。
- 删除双方都知道的信息。
- 把解释改成争夺。
- 把“我很生气”改成称呼变化、语气变化或动作。
- 让沉默承担一部分回答。

## 意象控制

意象可以统一作品气质，但也容易变成 AI 味。

使用原则：

- 同一卷可以有主导意象，但必须有变化。
- 意象要来自地点、职业、身体、物件或制度，不要凭空套。
- 每次重复意象时，意义要变化。
- 意象不能替代行动。

例如“盐”可以第一次是地貌，第二次是商品，第三次是伤口，第四次是债务，第五次是葬礼禁忌。若每次都只是“盐白如命运”，就是空转。

## 修订层级

改稿不要一上来重写全文，按层级处理：

1. **事实层**：姓名、地点、时间、规则是否正确。
2. **目标层**：当前段落是否知道自己在推进什么。
3. **视角层**：是否越界，词汇是否属于 POV。
4. **节奏层**：句子和段落是否匹配场景压力。
5. **词汇层**：是否有口水词、空泛词、混乱词汇域。
6. **余韵层**：是否需要留白、象征、回声或反讽。

如果事实层有问题，不要先美化句子。漂亮的错误会让后续修复更难。

## 风格迁移边界

用户要求“像某个平台 / 某类型 / 某作者”时，只迁移可泛化的写作特征：

- 节奏密度。
- 情绪温度。
- 视角距离。
- 爽点或情感推进方式。
- 对白压缩程度。
- 意象使用方式。
- 章节钩子强度。

不要复制特定作者的独特措辞、段落结构、角色口癖或可识别表达。目标是满足读感，不是模仿文本指纹。

## 快速诊断表

| 用户反馈 | 可能原因 | 优先修法 |
|---|---|---|
| 太平 | 场景没有状态变化 | 补目标、阻力、选择和代价 |
| 太水 | 信息重复、动作无结果 | 删除解释，合并同类段落 |
| 太硬 | 设定词过密，缺少人 | 加角色判断、误解、身体感 |
| 太飘 | 意象没有绑定行动 | 把抽象改成物件、价格、伤口或路线 |
| 不像网文 | 反馈慢，收获不明显 | 强化反制、结果、身份变化和钩子 |
| 不够文学 | 只有事件，没有观察 | 补矛盾、象征、沉默和余波 |
| 不够燃 | 没有压制关系和不可逆选择 | 先建立被低估，再兑现反制 |
| 不够甜 | 关系没有小证据 | 加共享资源、保留体面、默认照顾 |
| 不够恐怖 | 怪物解释太早 | 写规则、痕迹、错误和禁忌 |
| AI 味 | 形容词泛化、句式齐、主题直说 | 具体化、变节奏、把主题放进场景 |

## 常见失败

- 把风格等同于作者名或平台名，结果只套表面词汇。
- 为了“高级”牺牲剧情推进，让章节失去目标。
- 为了“爽”让人物无代价获胜，破坏长期可信度。
- 为了“古风”堆砌生僻词，人物声口反而不稳定。
- 为了“轻松”让所有角色说同一种玩笑话。
- 为了“文笔好”把动词换成形容词，导致动作和状态变化变弱。
- 为了“电影感”只写镜头运动，不写角色判断和代价。
- 为了“节奏快”删掉余波，让战斗、情感和选择没有后果。
