# Combat System Reference

`combat-system` 用于创造符合世界逻辑、叙事目标和读者体验的战斗体系、能力体系、职业 / 工种体系和战力成长方式。它的目标不是制造炫技名词，而是解释这个世界的人为什么必须战斗、靠什么战斗、如何付出代价、如何被反制，以及一场战斗为什么会被读者记住。

战斗不是体系展示，而是一段人在危险世界里被迫改变条件的经历。

## 核心目标

战斗体系必须从生存方式长出来。设计前先回答：

- 这个世界为什么需要战斗：资源、路线、安全区、阶层、信仰、战争、怪物、债务、身份或生存资格。
- 能力从哪里来：身体训练、器械、技术、魔法、契约、生态材料、怪物器官、知识、仪式或社会授权。
- 谁有资格战斗：职业、组织、阶层、学校、军队、猎人、走私者、普通人。
- 战斗消耗什么：体力、寿命、燃料、药物、材料、金钱、许可证、污染值、通行权或同伴信任。
- 什么能克制它：地形、天气、材料、心理、制度、信息差、禁忌、反制装备。
- 战斗改变什么：路线、资源、关系、身份、名声、债务、规则理解、地方秩序或人物价值观。

如果战斗只能写成“更强的人放更大的招”，体系就是空的。

## 设计顺序

1. 确认冲突压力：与怪物争生存空间，还是与人争资源、地位、路线和规则解释权。
2. 确认战斗目标：杀死敌人只是少数情况；更多时候是拖时间、夺路、护送、断后、封门、引走危险、保住证据、换取通行权或撑到环境变化。
3. 确认能力来源：能力必须有来源、训练方式、获取门槛和副作用。
4. 从生存工种推导职能：不要先想职业树，先想这个世界为什么需要修桥、背灯、听潮、验尸、缝肺、驱兽、记路、运盐、清障或谈价的人。
5. 设计工具和材料：武器、护具、药剂、仪器、符号、载具、场地装置如何改变打法。
6. 设计战斗审美：空间如何变化，时间如何压迫，感官如何逼近，奇观如何变成危险。
7. 设计战斗流程：异常、误判、压制、反制、资源不足、选择、代价、结果、余波。
8. 设计失败规则：失败不一定死亡，但必须改变后续世界状态。
9. 设计成长阶梯：新手先学活下来，再学执行任务、破局、承担后果或改变规则。
10. 绑定社会结构：战斗资格如何改变身份、收入、名声、通行权、债务和组织关系。

## 战斗审美

战斗不仅是胜负过程，还必须制造读者体验：

- 压迫感：危险持续逼近，角色没有舒适观察时间。
- 奇观感：地貌、生态、光线、声音、材料或制度让这场战斗只属于这个世界。
- 生死距离感：读者能看懂一步、一次误听、一个迟疑为什么会要命。
- 反转感：胜负来自条件变化，而不是突然变强。
- 空间感：角色位置、退路、遮挡、高低差、承重、边界必须清楚。
- 代价感：胜利消耗资源、伤害关系、暴露秘密或改变后路。
- 人性选择感：角色必须在救人、逃命、守信、保物、保名声、保路线之间取舍。

优秀战斗不来自“技能名字”，而来自地形正在崩塌、火光正在熄灭、呼吸越来越困难、怪物正在学习、规则正在收紧、主角必须放弃某样东西。

## 优先制造的场面条件

### 空间变化

战斗过程中，空间不能只是一块静态平地。优先让环境发生变化：

- 桥断、地陷、门封、墙倒、屋梁承重不足。
- 涨潮、退潮、起雾、风向改、缺氧、温度骤降。
- 光源熄灭、影子变化、声音传播方向改变。
- 水位、盐面、沙层、雪线、火势或毒气边界持续移动。
- 人群、车队、牲畜、仪式队伍或军阵改变路线。

空间变化必须改变战术选择，而不只是装饰背景。

### 时间压力

时间压力会天然制造节奏：

- 灯油快烧完。
- 潮水快上来。
- 雾墙快合拢。
- 怪物即将聚群。
- 列车即将进洞或离站。
- 氧气、药效、契约时限、许可证、封城令快到期。

时间压力应让角色不得不提前选择，不能无限观察和解释。

### 感官压迫

不要只写动作。优先写会影响判断的感官：

- 声音：空响、回声、磨擦、吞咽、骨裂、远处号声。
- 温度：冷到手指失灵、热到金属烫皮。
- 呼吸：缺氧、烟尘、湿气、腥味、盐味、血味。
- 光线：灯火抖动、反光误导、阴影吞人。
- 震动：脚下承重变化、远处巨物移动、墙体回响。
- 重量：湿衣、护具、伤员、背负物拖慢行动。

场面越奇幻，越需要用身体感让它落地。

### 错误代价

真正精彩的战斗不是靠大招，而是一个错误会死人或改变局势：

- 点错灯。
- 听错声音。
- 走错一步。
- 提前开火。
- 忘记封味。
- 没看风向。
- 把地方禁忌当迷信。
- 相信了过期经验。
- 把怪物当作只会本能攻击的东西。

错误最好来自人物性格、经验局限、地方误解、资源短缺或对手诱导。

### 怪物和敌人的学习性

对手不能只是机制单位。它们必须会观察、记住、绕开、诱骗、利用人的习惯：

- 怪物记住火光、声音、气味、药粉或陷阱位置。
- 敌人识别主角的善意、迟疑、骄傲、旧伤或资源短板。
- 组织利用制度、债务、通行证、价码或舆论让主角不能随便开打。
- 同一招第二次使用必须更难，甚至产生反噬。

如果对手永远只按固定规则扑上来，战斗会变成游戏关卡。

## 战斗情绪曲线

战斗应有情绪结构，而不是“发现敌人 -> 打 -> 赢”。

推荐曲线：

```text
短暂安全感
↓
异常信号
↓
误判或低估
↓
局势失控
↓
资源不足
↓
出现不可逆代价
↓
看见破局条件
↓
带代价的选择
↓
险胜 / 失败 / 交换条件
↓
余波
```

每一段都要改变信息、空间、资源、关系或心理承受力。不要把战斗写成动作列表。

## 战斗不是为了赢，而是为了改变条件

高级战斗的目标通常不是杀死敌人，而是改变后续条件：

- 拖时间，撑到潮退、门开、援手到达或契约失效。
- 抢桥、抢船、抢门、抢灯、抢证据。
- 护送伤员、货物、证人、幼体或消息。
- 断后、封路、引怪、分割敌人。
- 逼对方公开报价、承认身份、暴露弱点或消耗许可证。
- 点亮灯塔、熄灭误导光源、撕毁契约、夺回通行权。
- 用一次失败换取路线、情报、地方信任或人物觉醒。

设计战斗时，先写清楚“这场战斗结束后，什么条件被改变了”。

## 失败规则

战斗失败不一定等于死亡。失败必须改变后续世界状态，例如：

- 丢失关键物、货物、证据、灯油、药物或通行凭证。
- 被迫绕路，错过潮汐、车队、节日、封城前窗口。
- 伤势、感染、污染、契约反噬或能力边界被暴露。
- 债务增加，名声崩塌，被某地拒绝进入。
- 同伴或短暂同行者失去信任。
- 被组织标记、通缉、勒索或纳入账册。
- 暴露路线，引发怪物迁徙或地方封锁。
- 救下一个人，却失去另一个选择。

失败应成为后续剧情发动机，而不是被下一章清零。

## 能力来源

| 来源 | 适用表达 | 代价与限制 |
|---|---|---|
| 身体训练 | 武术、军训、猎术、跑酷、耐寒、潜水 | 年龄、伤病、疲劳、训练时间 |
| 器械技术 | 枪械、旧械、机甲、工具臂、无人机 | 维护、能源、弹药、专利、噪声 |
| 环境材料 | 矿石、药草、异晶、盐、骨粉、孢子 | 产地限制、污染、依赖、走私 |
| 仪式 / 契约 | 神术、誓约、符咒、血契、名契 | 禁忌、违约惩罚、见证人、时限 |
| 怪物生态 | 器官移植、骨甲、毒囊、感官模拟 | 排异、伦理、材料稀缺、怪物反制 |
| 知识 / 信息 | 计算、预判、路线经验、弱点档案、语言 | 情报滞后、误导、记录被毁 |
| 社会授权 | 执照、军衔、牌照、权限、法印 | 被撤销、滥用追责、阶层排斥 |
| 异化 / 改造 | 机械飞升、寄生、血脉、基因、魔化 | 人格变化、寿命、污染、失控 |

能力来源可以混合，但每条能力都要有可见训练、材料、仪式或制度痕迹。

## 职能不是职业树

职能首先是生存工种，其次才是战斗定位。一个人负责修桥、运盐、听潮、验尸、背灯、记路、缝肺、驱兽、打捞或谈价，只是因为环境危险，他才具备战斗能力。

不要把职能写成固定小队模板，也不要默认每个重要角色都必须会打架。缺失某种工种应带来真实困难，而不是用主角万能补齐。

| 生存工种 / 职能 | 叙事作用 |
|---|---|
| 前探 / 认路 | 发现路线、陷阱、怪物巢、伏击和可用退路 |
| 守路 / 护运 | 保住桥、门、伤员、物资和撤退条件 |
| 破障 / 重击 | 处理硬壳、装甲、屏障、巨型目标和封闭空间 |
| 诱导 / 控场 | 改变地形、视线、声音、气味和敌方走位 |
| 医救 / 修复 | 保住战后余波，让代价延续而非即时清零 |
| 工程 / 清障 | 架桥、爆破、封门、设陷、修械、改路 |
| 远击 / 压制 | 改变距离秩序，制造暴露、压制和时间窗口 |
| 谈判 / 交易 | 在战斗前后改变价码，避免、推迟或诱发冲突 |
| 记录 / 判读 | 识别弱点、复盘误判、更新怪物和敌方经验 |
| 异常承载 | 承担高风险能力、污染、契约或禁术后果 |

## 战斗深参考层

战斗体系的核心不是谁强，而是“世界为什么迫使人用这种方式解决冲突”。

深战斗设计优先回答：

- 战斗发生前，双方分别想保住什么。
- 战斗现场有哪些空间、时间、资源和感官限制。
- 每种能力为什么在这个世界中出现。
- 敌人如何理解、误解或反制主角。
- 胜利后哪一种条件被改变。
- 失败后人物还能怎样活下去，但必须付出什么。

如果一场战斗只证明“主角更厉害”，它很快会疲劳。有效战斗应证明主角更会观察、更敢取舍、更理解地方规则，或更愿意承担当场代价。

## 战斗目标类型

杀死敌人只是少数目标。更常见的目标包括：

| 目标 | 场面压力 | 胜利标准 |
|---|---|---|
| 夺路 | 退路、桥、门、车、船 | 打开通道或抢到时间 |
| 护送 | 伤员、孩子、证据、货物 | 目标物抵达，不一定击败敌人 |
| 拖延 | 等援手、等潮汐、等药效 | 撑到时间点 |
| 断后 | 让他人撤离 | 自己是否脱身可以不确定 |
| 封锁 | 阻止怪物、火势、消息扩散 | 门、桥、证据、传言被封住 |
| 捕获 | 活捉、审问、证明身份 | 控制而非击杀 |
| 证明 | 让旁观者承认事实 | 证据被看见，规则被迫改变 |
| 交易 | 用战斗换谈判资格 | 对方愿意坐下来 |
| 误导 | 让敌人追错方向 | 认知胜利 |
| 生还 | 不赢，只活下来 | 保住最小资源和下一步 |

目标越具体，战斗越不容易变成互相轰炸。

## 战斗空间设计

空间必须参与战斗。

检查：

- 距离：谁近，谁远，谁必须靠近才有效。
- 高低：谁在上方，谁能坠落，谁能观察。
- 遮挡：柱子、车厢、人群、雾、柜台、废墟。
- 退路：门、窗、桥、船、楼梯、洞口、缆车。
- 承重：桥板、冰层、屋顶、旧梯、兽背。
- 光源：灯油、火把、月光、反光、断电、闪光。
- 声音：回声、噪音、静默、怪物听觉、命令传递。
- 气味：血、盐、药、火、腐烂、封味材料。

同一地点可在战斗中变化：

- 桥断后，远击失去角度。
- 雾起后，视觉强者失去优势，听潮者变重要。
- 灯灭后，趋光怪物转向，黑暗职业获得机会。
- 人群恐慌后，空间从开阔变拥堵。
- 潮上涨后，地面战变成水中拖拽。

## 时间压力设计

战斗要有时钟。

可用时钟：

- 灯油还能烧多久。
- 潮水多久涨到桥面。
- 毒多久发作。
- 城门多久关闭。
- 巡逻多久折返。
- 药效多久消失。
- 怪物群多久聚集。
- 证据多久被清道者吃掉。
- 伤员多久失血。
- 契约多久失效。

时钟越具体，读者越能理解为什么角色必须冒险。

## 感官压迫设计

战斗不是视觉动画。其他感官可以改变判断。

| 感官 | 可制造的问题 |
|---|---|
| 听觉 | 回声误导、命令传不到、怪物听声定位 |
| 嗅觉 | 血味暴露、药味伪装、封味失败 |
| 触觉 | 地面震动、盐壳空洞、湿冷麻痹 |
| 温度 | 失温、烫伤、装备失效、呼吸凝霜 |
| 重量 | 盔甲进水、背负伤者、工具太沉 |
| 光线 | 逆光、反光、影子错位、灯灭 |
| 呼吸 | 毒雾、粉尘、缺氧、恐惧导致喘息 |

感官压力最好和人物经验绑定：港口人听风，矿工听梁，桥工听木，盐民看裂纹，医者闻腐味。

## 对手智能

敌人不能只负责被打。

对手至少会做一类反应：

- 观察主角惯用动作。
- 逼主角重复消耗。
- 攻击主角要保护的对象。
- 改变目标，不追人改追证据。
- 利用地形和人群。
- 利用主角道德底线。
- 放弃短期胜利，换长期追踪。
- 故意暴露弱点，诱导主角误判。

怪物也可以有智能，不一定是语言智能。它可以学习气味、灯光、路线、声音、群体恐慌或人类封门习惯。

## 战斗与社会

战斗会被社会记录和定价。

战后追问：

- 谁赔偿损失。
- 谁负责清理尸体和怪物材料。
- 谁把这场战斗写进报告。
- 民间如何误传。
- 组织如何利用战斗定罪或宣传。
- 伤员如何支付治疗。
- 武器、材料和能力使用是否违法。
- 主角是否因此获得名声、通缉、债务或保护。

战斗如果不进入社会，就只是场面。长篇战斗要不断改变角色在世界中的价格。

## 成长不是升级

成长可以是：

- 知道哪条路不能走。
- 学会等待。
- 学会放弃击杀，改为保住证据。
- 学会让别人完成关键动作。
- 学会承认旧经验失效。
- 学会用地方民俗反制怪物。
- 学会在赢的时候留代价，在输的时候留退路。

能力变强可以存在，但必须和经验、资源、训练、限制和价值变化绑定。

## 战斗失败诊断

| 失败 | 表现 | 修复 |
|---|---|---|
| 目标空泛 | 只说打败敌人 | 改成夺路、护送、拖延、证明或捕获 |
| 空间缺席 | 像站在平地互轰 | 补遮挡、退路、高低差和动态变化 |
| 没时间压力 | 可以慢慢打 | 加潮汐、灯油、伤势、巡逻或证据消失 |
| 敌人低智 | 只会惊讶 | 让敌人学习、绕目标、攻击保护物 |
| 胜利无价 | 赢完清零 | 补伤势、债务、暴露、组织记录和资源消耗 |
| 失败无后果 | 输了下一章不影响 | 改路线、关系、名声、资源或规则理解 |
| 技能轰炸 | 名词多，结果少 | 每个能力都写条件、动作、反馈和代价 |
| 成长虚假 | 突然变强 | 补训练、观察、旧铺垫和价值选择 |

## 成长阶梯

成长不能只靠数字升级。推荐让主角按状态变化成长：

- 活下来：学会观察、逃跑、守住物资和判断危险。
- 能执行：能独立完成侦察、护送、清障、交易或猎杀任务。
- 会协作：理解他人的工种价值，知道何时退、何时换位、何时牺牲资源。
- 能破局：利用地形、制度、怪物习性或敌方心理改变战斗条件。
- 承担后果：战斗胜利带来债务、名声、追捕、污染、组织招揽或怪物记恨。
- 改变规则：主角不只是更强，而是能影响职业标准、战术路线或资源分配。

关键成长节点应落实为人物变化，例如：

- 第一次不敢补刀。
- 第一次主动断后。
- 第一次意识到自己会害死人。
- 第一次为了活命撒谎。
- 第一次救人后被背叛，后来仍选择救。
- 第一次发现规则比怪物更可怕。

## 场面表达

写战斗场面时优先写可感知的限制：

- 空间：距离、高低差、遮挡、退路、承重、天气和光线。
- 时间：时限、倒计时、药效、潮汐、燃料、封锁和援手到达时间。
- 资源：弹药、燃料、体力、药量、可用工具、同行者位置。
- 信息：谁看见了什么，谁误判了什么，谁知道弱点或禁忌。
- 反制：怪物或敌人如何适应、绕开、诱骗、分割、污染或借制度压人。
- 错误：哪一次失误改变了胜负条件。
- 余波：伤势、损耗、证据、债务、名声、路线开放或关闭。

热血来自“知道代价仍选择”，不是口号堆叠；爽点来自“读者看懂局势如何被反转”，不是招式名称增加。

## 命名方法

战斗工种、技法和装备命名应来自功能、材料、组织、训练传统或民间称呼。

- 工种名：守路人、破壳手、听潮斥候、清账医。
- 工具名：折梁枪、盐灯、三扣甲、骨纹测距仪。
- 技法名：压步、换息、封门、借雾、听骨。
- 官方名与俗称并存：军方称“边境清障员”，民间叫“捡命的”。
- 禁忌名或敌称：某类改造者自称“续身者”，城内蔑称“借壳人”。

不要让所有职业、技能、装备都套同一个前缀；保留核心意象，但让不同地区、组织和阶层有自己的命名来源。

## 禁止事项

避免：

- 数值化等级体系。
- 万能主角。
- 无限成长。
- 招式堆叠。
- 战斗只靠爆发。
- 所有人都会打架。
- 统一风格命名。
- 怪物只会扑咬。
- 敌人只负责惊讶。
- 战斗结束没有余波。
- 只靠设定解释胜负。
- 把职能写成固定小队配置。
- 把战斗写成关卡机制或副本流程。

优先：

- 环境。
- 信息差。
- 错误。
- 资源。
- 社会规则。
- 生态变化。
- 人性选择。
- 后续条件改变。

## 审核清单

完成战斗体系或战斗场面后检查：

- 战斗需求是否来自世界压力，而不是作者想要打斗。
- 战斗目标是否清楚，是否避免默认“杀死对方就是胜利”。
- 能力是否有来源、门槛、训练、消耗和副作用。
- 职能是否来自生存工种，是否避免职业树和固定小队感。
- 人怪战斗和人人战斗是否有不同逻辑。
- 是否有空间变化、时间压力、感官压迫和错误代价。
- 对手是否会学习、反制或利用人的习惯。
- 失败是否会改变后续世界状态。
- 成长是否改变身份、资源、地图、关系、价值观或制度位置。
- 战斗名称是否有人文和技术来源，而不是统一模板化造词。
- 每场战斗是否有空间、信息差、反制、代价和余波。
