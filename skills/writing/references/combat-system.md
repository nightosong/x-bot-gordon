# Combat System Reference

`combat-system` 用于创造符合世界逻辑的战斗体系、能力体系、职业体系和战力成长方式。它的目标不是制造炫技名词，而是解释这个世界的人为什么必须战斗、靠什么战斗、如何付出代价、如何被反制。

## 核心目标

战斗体系必须从生存方式长出来。设计前先回答：

- 这个世界为什么需要战斗：资源、路线、安全区、阶层、信仰、战争、怪物、债务或身份。
- 能力从哪里来：身体训练、器械、技术、魔法、契约、生态材料、怪物器官、知识、仪式或社会授权。
- 谁有资格战斗：职业、组织、阶层、学校、军队、猎人、走私者、普通人。
- 战斗消耗什么：体力、寿命、燃料、药物、记忆、材料、金钱、许可证、污染值、同伴信任。
- 什么能克制它：地形、天气、材料、心理、制度、信息差、禁忌、反制装备。

如果战斗只能写成“更强的人放更大的招”，体系就是空的。

## 设计顺序

1. 确认冲突压力：与怪物争生存空间，还是与人争资源、地位、路线和解释权。
2. 确认能力来源：能力必须有来源、训练方式、获取门槛和副作用。
3. 按职能分工：不要只分强弱，先分侦察、守路、破甲、医救、控场、诱导、工程、谈判等功能。
4. 设计工具和材料：武器、护具、药剂、仪器、符号、载具、场地装置如何改变打法。
5. 设计战斗流程：发现、定位、试探、消耗、反制、选择、代价、余波。
6. 设计成长阶梯：新手先学活下来，再学执行任务、协作、破局、承担指挥或改变规则。
7. 绑定社会结构：战斗资格如何改变身份、收入、名声、通行权、债务和组织关系。

## 能力来源

| 来源 | 适用表达 | 代价与限制 |
|---|---|---|
| 身体训练 | 武术、军训、猎术、跑酷、耐寒、潜水 | 年龄、伤病、疲劳、训练时间 |
| 器械技术 | 枪械、旧械、机甲、工具臂、无人机 | 维护、能源、弹药、专利、噪声 |
| 环境材料 | 矿石、药草、异晶、盐、骨粉、孢子 | 产地限制、污染、依赖、走私 |
| 仪式 / 契约 | 神术、誓约、符咒、血契、名契 | 禁忌、违约惩罚、见证人、冷却 |
| 怪物生态 | 器官移植、骨甲、毒囊、感官模拟 | 排异、伦理、材料稀缺、怪物反制 |
| 知识 / 信息 | 计算、预判、地图、弱点档案、语言 | 情报滞后、误导、记录被毁 |
| 社会授权 | 执照、军衔、牌照、权限、法印 | 被撤销、滥用追责、阶层排斥 |
| 异化 / 改造 | 机械飞升、寄生、血脉、基因、魔化 | 人格变化、寿命、污染、失控 |

能力来源可以混合，但每条能力都要有可见训练、材料或制度痕迹。

## 职能分工

| 职能 | 叙事作用 |
|---|---|
| 前探 / 斥候 | 发现路线、陷阱、怪物巢、敌方伏击 |
| 守路 / 盾卫 | 保住退路、桥、门、伤员和物资 |
| 破甲 / 重击 | 处理硬壳、装甲、屏障和巨型目标 |
| 控场 / 引导 | 改变地形、视线、声音、气味和敌方走位 |
| 医救 / 修复 | 保住战后余波，让代价可延续而非即时清零 |
| 工程 / 机关 | 架桥、爆破、封门、设陷、修械 |
| 远击 / 狙击 | 改变距离秩序，制造暴露和压制 |
| 谈判 / 交易 | 在战斗前后改变价码，避免或诱发冲突 |
| 记录 / 判读 | 识别弱点、战后复盘、更新怪物和敌方档案 |
| 异常承载 | 承担高风险能力、污染、契约或禁术后果 |

队伍不必写满所有职能，但缺失的职能必须带来真实困难。

## 成长阶梯

成长不能只靠数字升级。推荐让主角按状态变化成长：

- 活下来：学会观察、逃跑、守住物资和判断危险。
- 能执行：能独立完成侦察、护送、清障、交易或猎杀任务。
- 会协作：理解队友职能，知道何时退、何时换位、何时牺牲资源。
- 能破局：利用地形、制度、怪物习性或敌方心理改变战斗条件。
- 承担后果：战斗胜利带来债务、名声、追捕、污染、组织招揽或怪物记恨。
- 改变规则：主角不只是更强，而是能影响职业标准、战术路线或资源分配。

## 场面表达

写战斗场面时优先写可感知的限制：

- 空间：距离、高低差、遮挡、退路、承重、天气和光线。
- 资源：弹药、燃料、体力、药量、可用工具、队友位置。
- 信息：谁看见了什么，谁误判了什么，谁知道弱点。
- 反制：怪物或敌人如何适应、绕开、诱骗、分割、污染或借制度压人。
- 余波：伤势、损耗、证据、债务、名声、地图开放或关闭。

热血来自“知道代价仍选择”，不是口号堆叠；爽点来自“读者看懂了局势如何被反转”，不是招式名称增加。

## 命名方法

战斗职业、技法和装备命名应来自功能、材料、组织、训练传统或民间称呼。

- 职能名：守路人、破壳手、听潮斥候、清账医。
- 工具名：折梁枪、盐灯、三扣甲、骨纹测距仪。
- 技法名：压步、换息、封门、借雾、听骨。
- 官方名与俗称并存：军方称“边境清障员”，民间叫“捡命的”。
- 禁忌名或敌称：某类改造者自称“续身者”，城内蔑称“借壳人”。

不要让所有职业、技能、装备都套同一个前缀；保留核心意象，但让不同地区、组织和阶层有自己的命名来源。

## 审核清单

完成战斗体系后检查：

- 战斗需求是否来自世界压力，而不是作者想要打斗。
- 能力是否有来源、门槛、训练、消耗和副作用。
- 职能是否清楚，是否避免只按强弱排队。
- 人怪战斗和人人战斗是否有不同逻辑。
- 成长是否改变身份、资源、地图、关系或制度位置。
- 战斗名称是否有人文和技术来源，而不是统一模板化造词。
- 每场战斗是否有空间、信息差、反制、代价和余波。
