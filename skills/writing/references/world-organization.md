# World Organization Reference

`world-organization` 用于设计国家、城邦、宗门、教会、公司、军队、学院、行会、家族、秘密组织和地方治理结构。只要故事的世界观需要大规模权力、制度、国家组织或社会组织支撑，就应读取本参考。

## 核心目标

组织不是名字列表，而是把世界规则落实到人身上的机器。设计组织时必须回答：

- 它凭什么存在：历史、灾难、资源、信仰、技术、血统、契约或暴力。
- 它控制什么：土地、道路、水源、知识、货币、武器、户籍、教育、医疗或神圣解释权。
- 它如何让普通人感受到权力：税、证件、巡查、审判、禁令、配给、仪式、考试、征召、债务。
- 它内部谁得利，谁被牺牲，谁想改变秩序。
- 它能制造哪些章节任务、阻碍、诱惑、交易和反噬。

如果组织不能改变角色行动、资源分配、身份价值、地图可达性或冲突代价，就只是背景名，应压缩。

## 设计维度

| 维度 | 需要回答的问题 |
|---|---|
| 起源与历史 | 组织从什么危机、资源或人物中诞生，旧名和旧制度是什么 |
| 版图与地图 | 控制哪些地区、路线、关隘、港口、矿区、学校、庙宇或据点 |
| 合法性 | 它凭什么让人服从：血统、选举、神谕、武力、技术、粮食、旧账 |
| 权力结构 | 谁发令，谁执行，谁记录，谁审判，谁能例外 |
| 阶层秩序 | 普通人如何上升、跌落、被定价、被排除或被赦免 |
| 经济资源 | 税、粮、盐、药、燃料、矿石、怪物材料、数据、魔力或信用从哪里来 |
| 法律与禁忌 | 哪些行为被允许、交易、默许、罚没、流放或抹名 |
| 军事与安全 | 谁守路、谁征兵、谁侦察、谁处刑，武器和战术来自哪里 |
| 信念与叙事 | 它对外宣称什么，内部真正害怕什么 |
| 内部分裂 | 改良派、保守派、边地派、军方、商团、学派、秘密派系如何互相牵制 |
| 外部关系 | 与邻国、城市、怪物群落、商路、异族或旧世界遗产是什么关系 |
| 章节用途 | 它在本卷制造什么门槛、追捕、审判、交易、背叛或战争 |

## 常见组织类型

| 类型 | 重点 |
|---|---|
| 国家 / 帝国 | 版图、税制、军制、继承、边境、地方自治和合法性危机 |
| 城邦 / 聚落联盟 | 贸易、城墙、水源、议会、商会、民兵和外来者身份 |
| 宗门 / 学院 | 传承、入门门槛、师承谱系、资源配给、试炼和知识垄断 |
| 教会 / 神职体系 | 神学解释权、仪式、赎罪、异端、圣物和民众日常 |
| 公司 / 财团 | 合同、债务、专利、雇佣兵、垄断资源和绩效式压迫 |
| 行会 / 职业组织 | 许可证、师徒、价格、黑市、技术标准和行业禁忌 |
| 军队 / 安全机构 | 指挥链、补给、侦察、纪律、战功、情报和边境压力 |
| 家族 / 氏族 | 血缘、婚姻、继承、旧债、名声、家法和内外亲疏 |
| 秘密组织 | 招募方式、暗号、保护伞、真实目的、叛徒和暴露代价 |
| 怪物 / 非人社会 | 工种、等级、族群记忆、交易方式、禁忌和与人类秩序的误解 |

## 组织与地图

组织必须落在地图上：

- 首都和边地的权力感不同，不能只有同一种口吻。
- 路线、港口、桥、矿区、学校、庙宇、医院和市场都可以成为权力节点。
- 边境不是一条线，而是一组关卡、走私路、巡逻间隔、语言差异和价格变化。
- 组织控制力要有距离衰减：中心靠公文，边地靠代理人，荒野靠交易或恐惧。

写章节前至少确认：当前地点由谁控制，主角需要什么凭证，违规代价是什么，谁能从漏洞中获利。

## 组织与冲突

好的组织能自然制造故事压力：

- 门槛：入城证、考试、印章、血统、通行税、配给名额。
- 价码：治疗、保护、路线、武器、情报、身份变更都要付出代价。
- 反制：主角获得资源后，组织会调账、封路、追捕、定罪或抬价。
- 内斗：不同派系对同一事件有不同利益，主角可以被利用，也可以反向利用。
- 名声：在一个地区的功劳，可能在另一个地区变成罪证。

不要把组织写成单纯作恶的背景板。压迫更有力的方式是让它有可理解的生存逻辑，同时对个体造成真实伤害。

## 命名方法

组织命名应体现历史和人文来源，避免所有组织都套同一个意象字头。

可用来源：

- 地理：河口议会、北岭盐署、七桥城盟。
- 创始人或旧王朝：岑氏柜局、亚铎军团、旧衡院。
- 职能：路券司、灯塔局、清账团、灰衣巡检。
- 资源：赤盐会、银穗仓、鹿角药社。
- 信念或誓约：守昼教、无返军、缄默院。
- 民间俗称：剥牌人、走铃帮、夜账先生。
- 他称与蔑称：王庭自称“巡境厅”，边民称其为“刮路税的”。
- 旧名与新名：政权更替后官方改名，但老人、商人和敌人仍沿用旧称。

同一组织可以有正式名、简称、民间称呼、敌方称呼和内部代号。称呼差异本身可以暴露立场。

## 设计优先级

组织设计时，优先级如下：

```text
普通人如何被它改变
> 它控制什么资源和通道
> 它如何维持合法性
> 它内部如何运转和腐败
> 它如何制造章节选择
> 它的旗帜、口号和外观
```

如果一个组织只剩徽章、制服、口号和首领名字，它只是阵营标签。有效组织必须让读者看见：

- 普通人如何申请、等待、行贿、排队、被登记或被拒绝。
- 主角如何因为它多走一段路、多交一笔钱、多说一句谎或多背一个罪名。
- 组织内部的小人物如何执行制度，也如何钻制度空子。
- 它的权力如何落在账本、印章、路券、课本、粮袋、门牌、尸检单和婚书上。

组织的本质不是“谁统治谁”，而是“谁能定义什么是合法、什么有价、谁能通行、谁可以被牺牲”。

## 权力的可见表面

组织权力不能只靠旁白说明，必须通过可见表面进入场景。

常用表面：

| 表面 | 场景表现 |
|---|---|
| 证件 | 入城证、路引、船票、学籍、工牌、族谱、赦免书 |
| 账册 | 税簿、债契、粮票、工分、药账、尸体编号、功劳簿 |
| 空间 | 城门、关卡、巡检棚、排队窗口、祠堂、审讯室、仓库 |
| 声音 | 钟声、点名、宣读、军靴、广播、祷词、唱名 |
| 身体 | 剃发、刺字、制服、佩牌、跪礼、验血、搜身、体检 |
| 时间 | 宵禁、考试日、配给日、纳税期、征召季、祭日 |
| 语言 | 官话、黑话、敬称、禁称、文书套话、内部缩写 |
| 惩罚 | 罚银、封户、禁路、降等、流放、抹名、公开羞辱 |

写组织场景时，尽量让权力先通过这些表面出现，再解释背后的制度。读者先看到主角被拦、被搜、被定价、被迫改口，才会相信组织真实存在。

## 合法性深挖

组织最有生命力的部分，不是它有多强，而是它为什么能让人服从。

合法性可以来自：

- **安全合法性**：它能挡住怪物、战争、瘟疫或饥荒。
- **资源合法性**：它控制粮食、水、盐、药、燃料、魔力、数据或工作机会。
- **历史合法性**：它继承旧王朝、旧灾难、旧契约或旧功劳。
- **宗教合法性**：它解释神意、赎罪、洁净、来世或禁忌。
- **技术合法性**：它掌握仪器、旧械、算法、药方、交通或测量体系。
- **血统合法性**：它宣称某些家族、种族或继承人天然有权。
- **程序合法性**：它让人相信考试、投票、审判、评审或备案是公平的。
- **恐惧合法性**：它让人相信离开组织会更惨。

更高级的组织设计要写出合法性裂缝：

- 它过去真的救过人，但现在靠旧功劳勒索。
- 它提供安全，却把安全变成垄断商品。
- 它宣称公平考试，但教材和路费只有上层能承担。
- 它说维护传统，但传统的解释权只在少数人手里。
- 它反对暴力，却把暴力外包给边地、佣兵或怪物猎队。

组织越可理解，压迫越有力。不要只写“他们很坏”；要写“他们为什么觉得自己是必要的”，再写个体如何被这种必要性碾过。

## 制度日常化

制度不只在大事件里出现，更应成为日常生活。

可设计的日常影响：

- 孩子从小背组织口号、考试口诀或避讳名。
- 商人说价前先问对方是哪种牌照。
- 婚姻要看户籍、船籍、血统、债务或配给资格。
- 医生先看保险、工分、教籍、军属牌，而不是先看伤口。
- 死者下葬需要编号、缴费、净化或组织盖章。
- 外地人不懂排队顺序、礼节、称呼或手势，立刻暴露身份。
- 老人记得旧制度，因此总在新称呼上犯错。
- 黑市不是制度外空间，而是制度压力的副产品。

组织写得越大，越要补小动作：盖章、递烟、避开巡查眼神、把真名写错一笔、把路券夹进鞋底、把孩子送去当学徒抵税。

## 内部运转

组织不能只有首领和杂兵。成熟组织至少要有四层：

| 层级 | 作用 | 写作重点 |
|---|---|---|
| 决策层 | 制定方向、分配资源、解释合法性 | 他们害怕什么，谁能否决谁 |
| 管理层 | 把命令变成流程、指标和账册 | 他们如何推责、加码、造表 |
| 执行层 | 直接接触民众、路口、战场和窗口 | 他们如何疲惫、腐败、同情或麻木 |
| 被吸纳者 | 学徒、外包、线人、临时工、债户 | 他们为何无法离开组织 |

组织内部冲突比“正邪对立”更能制造长期剧情：

- 中央要稳定，边地要活命。
- 财务要收税，军方要征粮。
- 教义派要纯洁，救济派要救人。
- 老派守旧名，新派改制度。
- 前线知道真相，后方只看报表。
- 执行者同情主角，但害怕失去饭碗。

写内部派系时，不要只列派系名。每一派都要有资源、恐惧、底线、可交易点和不可退让点。

## 经济链与制度账本

组织的权力最终会落进经济链。

每个重要组织都应追问：

- 它的钱从哪里来。
- 它靠什么支付军队、教师、祭司、医生、猎队或官员。
- 它用什么计量价值：银钱、盐、粮、功分、血统、学分、贡献点、债务、数据。
- 谁负责运输和保管资源。
- 谁从制度损耗中获利：仓吏、票贩、代理商、祭品商、保险人、黑市中介。
- 组织最害怕哪一种价格变化。
- 哪种资源短缺会导致它撕下道德外衣。

账本是很好的剧情道具：

- 一页被撕掉的税簿，可以暴露被抹掉的村庄。
- 一张药账，可以证明某个角色早就受伤或被控制。
- 一份运输单，可以说明军队真正要去的不是边境。
- 一张配给表，可以让主角发现某类人一直被低配。
- 一本旧账，可以把私人恩怨变成制度债。

组织越复杂，越要有账册、流程和指标。抽象压迫落到账本上，才会变成章节发动机。

## 边界、代理与腐败

组织的控制力要有距离衰减。

| 区域 | 控制方式 | 常见问题 |
|---|---|---|
| 中心 | 档案、仪式、卫队、审判、教育 | 口号整齐，但信息滞后 |
| 城区 | 税、证件、巡检、市场牌照 | 规则多，漏洞也多 |
| 边地 | 代理人、驻军、商会、地方豪强 | 执行变形，私法盛行 |
| 荒野 | 契约、恐惧、黑市、临时同盟 | 名义控制大于实际控制 |
| 敌区 | 谍报、传教、走私、婚姻、债务 | 公开身份失效，暗线变重要 |

腐败不只是“贪钱”，还包括：

- 用程序拖死穷人。
- 把危险转包给无证者。
- 用指标掩盖尸体。
- 用救济换信仰。
- 用教育筛掉边地口音。
- 用安全名义限制迁徙。
- 用例外条款保护上层。

腐败最好不要只服务爽点。它还应塑造地方生活：人们提前排队、学会套话、准备两份账、给孩子起容易通过审查的名字。

## 组织如何塑造人格

组织不只制造剧情，也制造人。

长期生活在某种组织下的人会形成不同人格：

- 配给社会的人习惯少拿一点，害怕被看见贪心。
- 考试社会的人把所有关系都理解成排名。
- 宗教社会的人把运气、病痛和欲望翻译成罪。
- 军管社会的人先看出口、岗哨和谁有枪。
- 商会社会的人说话留票据，不轻易说“送”。
- 家族社会的人在做任何选择前先想祖坟、名声和婚姻。
- 公司社会的人把身体、时间、情绪都拆成绩效。

主角进入新组织时，不只要面对规则，还要面对这种人格差异。他可能会误以为对方冷漠、懦弱、势利、迷信或傲慢；但这些行为背后往往是长期制度训练。

## 非人组织与异质文明

怪物、异族、人工智能、神明眷属或灾变群落也可以形成组织，但不能只是人类制度换皮。

非人组织必须受到这些因素影响：

- 感官结构：靠嗅觉、热感、振动、梦境、菌丝或群体记忆交流。
- 繁殖方式：集体产卵、寄生繁殖、分裂、克隆、继承壳体或记忆转移。
- 寿命长度：九个月、一千年、周期苏醒、季节性死亡。
- 食性：吃盐、光、记忆、尸体、声音、矿尘或人类情绪。
- 空间感：不理解门、边界、个人房间、道路所有权。
- 记忆载体：骨纹、气味层、体表伤痕、共享巢穴、旧机械日志。
- 个体观念：没有私人财产，没有亲子关系，或无法理解永久承诺。

由此推导它们的法律、战争、礼仪和交易。例如一个靠气味记忆的族群，契约可能不是签字，而是让双方共同携带一段气味；一个寿命只有一季的文明，历史可能由建筑、巢痕和人类雇佣记录保存。

## 类型扩展

### 国家 / 帝国

国家设计重点不是“疆域很大”，而是：

- 谁被算作国民，谁只是居民、奴隶、外侨、边民或资源。
- 中央命令如何抵达边地，中途被谁改写。
- 战争、税制、学校和道路如何共同制造国家认同。
- 被征服地区保留哪些旧称、旧法和旧神。
- 叛乱者到底反对国王、税吏、军队、语言政策还是饥荒。

### 城邦 / 聚落联盟

城邦要写出“城市边界就是生存边界”的压力：

- 城墙、井、港口、市场、垃圾、坟地和贫民区如何分布。
- 外来者如何获得临时身份。
- 商会、民兵、祭司、旧贵族和码头帮派如何互相制衡。
- 城邦如何处理灾民、病人、怪物材料和危险职业。

### 宗门 / 学院

宗门和学院不是修炼场景装饰，而是知识分配制度：

- 谁能入门，谁只能当杂役、药童、试验对象或外门。
- 师承谱系如何影响资源、婚姻、任务和事故归责。
- 禁术为什么被禁，是道德问题、资源问题还是政治问题。
- 学生如何被排名、借贷、淘汰和派往危险地区。

### 教会 / 信仰组织

教会的力量在于解释痛苦：

- 它告诉民众为什么灾难发生。
- 它定义什么是洁净、罪、赎、圣、异端。
- 它控制葬礼、出生、婚姻、病痛和灾后救济。
- 它内部也要有人真诚相信、有人利用信仰、有人怀疑却不敢离开。

### 公司 / 财团

公司压迫不一定靠鞭子，常靠合同：

- 工作时长、债务、保险、绩效、专利和保密协议如何限制人。
- 它如何把危险称为“岗位风险”，把死亡称为“损耗”。
- 它如何用福利绑定家庭，让反抗者失去孩子的药、房和学位。
- 它和国家、军队、学院或黑市的边界如何模糊。

### 行会 / 职业组织

行会最适合把世界规则变成手艺：

- 许可证、师徒、工具、材料、价格、禁忌和事故处理。
- 行会黑话如何隐藏知识。
- 非会员为什么危险，为什么又被迫承担最脏的活。
- 行会如何对待新技术、外地工匠、女性、异族或非人劳工。

## 章节发动机

组织设计完成后，必须能转成章节。

可直接生成的章节压力：

- **门槛章**：主角需要通行证、学籍、路券、牌照或赦免书。
- **排队章**：主角在窗口、审判、考试、配给或入城处消耗时间。
- **错账章**：账册错误导致主角身份、债务、死亡记录或资产异常。
- **代理章**：边地代理人执行变形，主角要选择服从、交易还是揭露。
- **内斗章**：同一组织两派都想利用主角。
- **审判章**：主角不是打败敌人，而是让事实被承认为事实。
- **征召章**：组织把私人身体变成公共资源。
- **赎买章**：组织提供帮助，但要求主角交出秘密、关系或未来自由。
- **改名章**：某个地点、物种或人被组织重新命名，旧身份被擦除。

如果组织不能生成这些章节压力，说明它还停在设定层。

## 常见失败诊断

| 失败 | 表现 | 修复 |
|---|---|---|
| 阵营标签化 | 只有正邪、旗帜和首领 | 补资源、合法性、执行层和日常影响 |
| 统一口径 | 所有成员说同一种话 | 补派系、层级、边地变形和个人利益 |
| 纯恶组织 | 只做坏事，没有生存逻辑 | 补它曾经解决过什么问题，以及现在如何变质 |
| 空泛制度 | 只说“法律森严” | 写证件、账册、排队、审判和惩罚细节 |
| 地图脱钩 | 不知道组织控制哪里 | 标注首都、边地、关卡、代理区和失控区 |
| 经济缺席 | 不知道钱粮从哪里来 | 补税源、运输、加工、损耗和价格恐惧 |
| 首领中心化 | 杀掉首领组织就消失 | 补流程、账本、利益链和继任机制 |
| 没有普通人 | 只有贵族、军官、主角 | 补窗口人员、杂役、债户、学徒、线人和家属 |

## 审核清单

完成组织设计后检查：

- 是否说明组织为什么存在，而不是只写名称和口号。
- 是否绑定地图、资源、法律、军事或日常生活。
- 是否有内部派系和外部关系。
- 是否写出普通人如何被证件、账册、配给、考试、税、审判或仪式改变。
- 是否说明组织的合法性来源，以及合法性如何产生裂缝。
- 是否有执行层、代理人、窗口人员、外包者和无法离开组织的人。
- 是否能看见经济链：谁征收、运输、加工、定价、损耗和获利。
- 是否体现中心、城市、边地、荒野和敌区的控制力差异。
- 非人组织是否由感官、繁殖、寿命、食性、空间感和记忆载体推导，而不是人类制度换皮。
- 是否能制造章节任务、门槛、价码、反制和后果。
- 组织命名是否有历史、地理、职能或文化来源。
- 是否避免把组织写成统一口径的空壳或单纯作恶的标签。
