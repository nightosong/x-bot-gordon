# Scene Specialist Reference

`scene_specialist` 用于处理高张力场景：对白、战斗、追逃、审判、告白、打脸、高潮、反转和章节钩子。场景的价值不在热闹，而在状态发生改变。

## 场景骨架

每个重要场景都应回答：

```json
{
  "scene_goal": "",
  "character_goal": "",
  "obstacle": "",
  "stakes": "",
  "turning_point": "",
  "cost": "",
  "aftermath": "",
  "next_hook": ""
}
```

最低要求：角色带着目标进场，遭遇阻力，做出选择，局势被改变。

## 对白场

对白不是信息朗读。每一轮关键对白至少改变一种状态：

| 状态 | 例子 |
|---|---|
| 信息状态 | 谁知道了秘密，谁被误导 |
| 权力状态 | 谁占上风，谁被迫让步 |
| 情感状态 | 信任、羞耻、愤怒、依赖或疏离改变 |
| 行动状态 | 对话结束后角色必须做什么 |

写法要点：

- 先确定每个角色“想从对话里拿到什么”。
- 让人物绕开真话、试探、遮掩、反击，而不是全员直接说明设定。
- 声口来自身份、教育、亲疏、压力和欲望，不来自口头禅堆叠。
- 长对白之间插入动作、沉默、环境反馈，让权力关系可见。

## 战斗 / 动作场

战斗要写清楚“为什么赢、为什么输、赢了付出什么”。

必须具备：

- 空间：距离、遮挡、退路、高低差、可利用物。
- 能力边界：技能、境界、体力、伤势、冷却、资源。
- 目标差异：杀死、拖延、夺物、救人、试探、逃跑。
- 节拍：试探、压制、误判、反制、代价、结果。
- 余波：伤势、暴露、资源消耗、关系变化或新敌意。

避免：

- 技能名连续轰炸但没有方位和结果。
- 主角临场开挂却没有铺垫、代价或限制。
- 敌人只负责惊讶，不调整策略。
- 胜负结束后世界状态没有任何变化。

### 职能化战斗体系

设计长篇战斗时，先从生存需求和社会分工推导能力，而不是先造一串炫技名。一个成熟战斗体系至少要说明：

- 战斗目的：与怪物争生存空间，还是与人争资源、地位、退路和规则解释权。
- 职能分工：前探、斥候、诱导、控场、守路、破甲、重装、医救、旧械、交易、契约、异化等。
- 能力来源：生态器官、旧技术、训练、资源消耗、契约代价、地貌适应或身体异化。
- 对抗关系：每类能力克制什么，被什么克制，在哪种地形失效。
- 成长方式：主角不是突然更强，而是掌握新地图、新资源、新判断和新代价。

战斗场面应把职能写进动作：前探看路、诱导改线、守路挡撤退、破甲找弱点、医救承担时间压力、旧械受材料和噪声限制。不要让所有角色都用同一种拳脚或光效解决问题。

### 怪物战斗写法

怪物不是只有攻击动作。每次怪物登场，至少写出：

- 一个动物性动作：舔盐、护崽、迁徙、晒骨、围火、藏食、磨角、换巢、争水、清道。
- 一个世界观动作：吞灯、借声、错影、读热、封路、标价、守契、改道、寄生、记名。
- 一个环境关系：它为什么在这里，它吃什么、守什么、怕什么、利用什么地貌。
- 一个战术后果：它改变了路线、光线、声音、视野、时间、退路或资源。

越奇幻的怪物，越要先让它像一种能在当地活下去的生物。

### 奇观探险场

奇观场景不能只负责展示设定。写奇观时优先按这个顺序组织：

```text
远景记忆点 -> 资源诱惑 -> 生态动作 -> 人类利用方式 -> 主角误判或破局 -> 成长收获和代价
```

每处奇观至少改变一种叙事条件：方向感、声音传播、光线安全性、资源分布、怪物行为、交易规则、战斗空间或社会身份。若奇观不改变角色行动，它就只是装饰，应压缩。

## 高潮场

高潮不是最大音量，而是承诺集中兑现。

检查：

- 前文至少埋过关键资源、关系、弱点或选择。
- 升级不是只增加敌人数量，而是增加选择代价。
- 角色必须做不可逆选择，且选择暴露其真正价值。
- 爽点或泪点之后要有后果，不能马上清零。
- 结尾应留下新秩序、新问题或下一阶段钩子。

## 反转 / 打脸

有效反转需要同时满足：

- 反转前读者能接受旧解释。
- 反转后回看，旧线索能成立。
- 反转改变策略、关系或局势，而不只是制造惊讶。
- 被打脸者的失败来自此前的傲慢、误判、信息差或价值缺陷。

打脸场景的爽感来自结构：

```text
压制关系建立 -> 主角被低估 -> 读者知道或期待反制条件 -> 对方继续加码 -> 反制兑现 -> 后果落地
```

## 章节钩子

章节结尾优先留下具体问题：

- 新敌人出现。
- 已知规则被破例。
- 秘密被错误的人听见。
- 奖励附带代价。
- 胜利带来更高层级注意。
- 角色做出无法撤回的承诺。

不要只写“他不知道，更大的危险正在靠近”。钩子应尽量带有可识别的对象、风险或选择。

## 输出偏好

处理场景类任务时，优先输出：

1. 场景目标和状态变化。
2. 分节拍设计。
3. 正文或改写片段。
4. 余波与需要写入 `storyAssets` 的连续性资料。

涉及地图、怪物或战斗升级时，额外输出：

- 地图条件：当前位置、退路、遮挡、高低差、资源点和控制势力。
- 生态条件：怪物行为目的、食物链位置、群体协作或社会规则。
- 职能对抗：双方能力、资源、限制、反制和胜负证据。
