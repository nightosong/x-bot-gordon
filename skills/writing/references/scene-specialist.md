# Scene Specialist Reference

`scene_specialist` 用于处理高张力场景：对白、战斗、追逃、审判、告白、打脸、高潮、反转和章节钩子。场景的价值不在热闹，而在状态发生改变。

## 场景骨架

每个重要场景都应回答：

```json
{
  "scene_goal": "",
  "character_goal": "",
  "obstacle": "",
  "stakes": "",
  "turning_point": "",
  "cost": "",
  "aftermath": "",
  "next_hook": ""
}
```

最低要求：角色带着目标进场，遭遇阻力，做出选择，局势被改变。

## 对白场

对白不是信息朗读。每一轮关键对白至少改变一种状态：

| 状态 | 例子 |
|---|---|
| 信息状态 | 谁知道了秘密，谁被误导 |
| 权力状态 | 谁占上风，谁被迫让步 |
| 情感状态 | 信任、羞耻、愤怒、依赖或疏离改变 |
| 行动状态 | 对话结束后角色必须做什么 |

写法要点：

- 先确定每个角色“想从对话里拿到什么”。
- 让人物绕开真话、试探、遮掩、反击，而不是全员直接说明设定。
- 声口来自身份、教育、亲疏、压力和欲望，不来自口头禅堆叠。
- 长对白之间插入动作、沉默、环境反馈，让权力关系可见。

## 战斗 / 动作场

战斗要写清楚“为什么打、为什么赢、为什么输、赢了付出什么、失败改变了什么”。战斗不是体系展示，而是一段人在危险世界里被迫改变条件的经历。

必须具备：

- 空间：距离、遮挡、退路、高低差、可利用物，以及桥断、地陷、起雾、涨潮、缺氧、光源熄灭等动态变化。
- 时间压力：灯油、潮汐、药效、车次、封锁、援手、契约时限或怪物聚群。
- 感官压迫：声音、温度、呼吸、气味、光线、震动、重量必须影响判断。
- 能力边界：技能、境界、体力、伤势、冷却、资源。
- 目标差异：杀死只是少数情况；更常见的是拖延、夺路、护送、断后、封门、引怪、保住证据或换取通行权。
- 节拍：异常、误判、压制、局势失控、资源不足、反制、代价选择、结果。
- 失败后果：失败不一定死亡，但必须改变路线、资源、名声、债务、组织态度或人物关系。
- 余波：伤势、暴露、资源消耗、关系变化、新敌意、路线开放或关闭。

推荐情绪曲线：

```text
短暂安全感 -> 异常信号 -> 误判或低估 -> 局势失控 -> 资源不足 -> 不可逆代价 -> 看见破局条件 -> 带代价的选择 -> 险胜 / 失败 / 交换条件 -> 余波
```

避免：

- 技能名连续轰炸但没有方位和结果。
- 主角临场开挂却没有铺垫、代价或限制。
- 敌人只负责惊讶，不调整策略。
- 胜负结束后世界状态没有任何变化。
- 静态平地对轰，没有空间变化、时间压力和错误代价。

### 生存工种化战斗体系

设计长篇战斗时，先从生存需求和社会分工推导能力，而不是先造一串炫技名或职业树。一个成熟战斗体系至少要说明：

- 战斗目的：与怪物争生存空间，还是与人争资源、地位、退路和规则解释权。
- 生存工种：修桥、背灯、听潮、验尸、缝肺、驱兽、记路、运盐、清障、谈价等人为什么存在。
- 战斗职能：这些工种如何自然转化为前探、诱导、控场、守路、破障、医救、旧械、交易、契约、异化等战斗位置。
- 能力来源：生态器官、旧技术、训练、资源消耗、契约代价、地貌适应或身体异化。
- 对抗关系：每类能力克制什么，被什么克制，在哪种地形失效。
- 成长方式：主角不是突然更强，而是掌握新地图、新资源、新判断、新代价，并在战斗后改变价值判断。

战斗场面应把工种写进动作：前探看路、诱导改线、守路挡撤退、破障找承重点、医救承担时间压力、旧械受材料和噪声限制、谈价者把冲突拖进社会规则。不要让所有角色都用同一种拳脚或光效解决问题。

### 怪物战斗写法

怪物不是只有攻击动作。每次怪物登场，至少写出：

- 一个生态网信号：食痕、粪迹、幼体线、天敌避让、共生物聚集、季节迁徙、尸壳腐烂或材料价格变化。
- 一个动物性动作：舔盐、护崽、迁徙、晒骨、围火、藏食、磨角、换巢、争水、清道。
- 一个世界观动作：吞灯、借声、错影、读热、封路、标价、守契、改道、寄生、记名。
- 一个环境关系：它为什么在这里，它吃什么、守什么、怕什么、利用什么地貌。
- 一个战术后果：它改变了路线、光线、声音、视野、时间、退路或资源。

越奇幻的怪物，越要先让它像一种能在当地活下去的生物。
越强大的怪物，越要在正文里露出它依赖的底层生态：大型捕食者必须有食物来源，迁徙巨兽必须有季节理由，拟声生物必须有储声环境或共生物。
同一卷的怪物场面不能反复使用虫、蛛、菌或同一种扑咬型野兽；应让不同尺度和栖境轮流登场，例如水下滤食巨物、树冠鸟群、地下热源生命、建筑寄生体、雾域声纹群、类人异变者或地貌级群体生命。

### 奇观探险场

奇观场景不能只负责展示设定。写奇观时优先按这个顺序组织：

```text
主角为什么想靠近 -> 远景记忆点 -> 资源诱惑 -> 生态动作 -> 人类利用方式 -> 主角误判或破局 -> 疑问 / 代价 / 迟到领悟线索
```

每处奇观至少改变一种叙事条件：方向感、声音传播、光线安全性、资源分布、怪物行为、交易规则、战斗空间或社会身份。奇观还要显出地方生活：人为什么留在这里，靠什么避险、交易、记路、命名和传承。若奇观不改变角色行动和当地活法，它就只是装饰，应压缩。

奇观不负责发放成长奖励。主角可以在奇观中获得新判断，但它应来自前文铺垫、旧经验失效、误判代价和地方经验触发；如果铺垫不足，场景只留下半成的手感、一个疑问、一句旧训的新理解或一个以后会回收的动作，不要立刻悟出完整招式。

## 高潮场

高潮不是最大音量，而是承诺集中兑现。

检查：

- 前文至少埋过关键资源、关系、弱点或选择。
- 升级不是只增加敌人数量，而是增加选择代价。
- 角色必须做不可逆选择，且选择暴露其真正价值。
- 若高潮包含技艺领悟，必须能回扣前文旧训、误用、观察、训练、伤势或关系铺垫；不能在高潮里临时发明解决方案。
- 爽点或泪点之后要有后果，不能马上清零。
- 结尾应留下状态变化、余波、新问题或下一阶段钩子；不要把高潮自动写成权力归属或新秩序宣告。

## 反转 / 打脸

有效反转需要同时满足：

- 反转前读者能接受旧解释。
- 反转后回看，旧线索能成立。
- 反转改变策略、关系或局势，而不只是制造惊讶。
- 被打脸者的失败来自此前的傲慢、误判、信息差或价值缺陷。

打脸场景的爽感来自结构：

```text
压制关系建立 -> 主角被低估 -> 读者知道或期待反制条件 -> 对方继续加码 -> 反制兑现 -> 后果落地
```

## 章节钩子

章节结尾优先留下具体问题：

- 新敌人出现。
- 已知规则被破例。
- 秘密被错误的人听见。
- 收获附带代价。
- 胜利带来更高层级注意。
- 角色做出无法撤回的承诺。

不要只写“他不知道，更大的危险正在靠近”。钩子应尽量带有可识别的对象、风险或选择。

## 场景设计优先级

场景设计时，优先级如下：

```text
角色目标
> 阻力
> 选择
> 状态变化
> 代价
> 漂亮描写
```

如果一个场景很热闹，但角色进场和离场时没有任何状态变化，它就是无效场景。状态变化可以很小，但必须存在：

- 信息变化：知道、误会、隐瞒、被误导。
- 关系变化：更信任、更疏远、更羞耻、更依赖。
- 资源变化：获得、失去、欠债、被定价。
- 空间变化：路开了、路封了、退路消失、身份暴露。
- 规则变化：旧经验失效，新禁忌成立。
- 心理变化：第一次害怕、第一次承认、第一次放弃。

场景不是剧情摘要的扩写，而是一组压力条件下的当场选择。

## 场景发动机

设计场景时，可以使用以下发动机：

| 发动机 | 核心问题 | 适用场景 |
|---|---|---|
| 争夺 | 谁想拿到同一件东西 | 打斗、交易、审判、抢路 |
| 隐瞒 | 谁不能让谁知道什么 | 对白、潜入、家庭戏、悬疑 |
| 误判 | 谁根据错误经验行动 | 探险、怪物、跨文化接触 |
| 延迟 | 谁必须拖到某个时间点 | 追逃、救援、守门、谈判 |
| 交换 | 谁用什么换什么 | 黑市、组织、关系修复 |
| 见证 | 谁看见某人无法伪装的一面 | 情感、伙伴、导师、背叛 |
| 反制 | 谁把对方优势变成弱点 | 爽点、打脸、战斗、智斗 |
| 失控 | 什么条件突然变坏 | 灾难、怪物、群众、天气 |

一个场景最好有一个主发动机，辅以一到两个副发动机。发动机太多会散，太少会平。

## 节拍设计

重要场景可以按 7-10 个节拍拆分：

```text
入场状态
-> 明确目标
-> 第一阻力
-> 临时策略
-> 对手反应
-> 情况恶化
-> 发现破局点
-> 代价选择
-> 结果
-> 余波和钩子
```

每个节拍都要回答：

- 角色此刻想要什么。
- 阻力来自谁或什么。
- 读者获得了什么新信息。
- 局势比上一节拍更好还是更坏。
- 哪个细节会在后面回收。

节拍不是公式，而是防止场景原地打转的工具。若连续两个节拍没有新信息、无更高压力、无关系变化，应合并或删除。

## 场景入口

场景入口要尽快给读者三个东西：

- 当前地点。
- 当前目标。
- 当前不对劲之处。

低效入口：

```text
他们来到大厅。大厅很大，很安静，墙上挂着许多画。
```

更有效的入口：

```text
他们进大厅时，所有画像的眼睛都被布蒙着，只有审判席后那一幅露出来。
```

后者同时给出地点、异常、制度感和潜在风险。场景入口不必解释完整背景，但要给读者一个可以抓住的压力点。

## 场景出口

场景出口不能只写“他们离开了”。离场时至少留下一个变化：

- 新任务：必须去哪里、找谁、避开什么。
- 新债务：欠了谁，谁记住了主角。
- 新伤口：身体、名声、关系或资源受损。
- 新误会：角色以为自己懂了，但其实错了。
- 新身份：主角被登记、通缉、承认、驱逐或赦免。
- 新禁忌：以后不能再用某条路、某个名字、某种能力。

好出口让下一场自然发生，而不是靠作者硬切。

## 对白深层设计

对白场的核心不是“说了什么”，而是“谁在用话语争夺什么”。

设计对白前先列：

| 角色 | 想得到 | 想隐藏 | 可用筹码 | 不可说 |
|---|---|---|---|---|
| A |  |  |  |  |
| B |  |  |  |  |

对白常见策略：

- 试探：用小问题测试对方知道多少。
- 转移：回答旁边的问题，避开核心。
- 反问：把压力推回去。
- 降级：把严重问题说成小事。
- 升级：把小错上纲到身份或道德。
- 假诚实：交出一个小秘密，遮住大秘密。
- 借第三方：用“他们都说”隐藏自己的判断。
- 改称呼：从尊称变直呼，或从名字变职务。

对白中的动作不是装饰，应改变权力：

- 倒茶可以是照顾，也可以是中断。
- 关门可以是保护，也可以是威胁。
- 不接对方递来的东西，可能比一句拒绝更强。
- 低头看账册，可能意味着对人的生命不感兴趣。

## 群像场景

群像场景容易散，必须明确“场景主问题”。

处理方式：

- 每个角色只带一个主要意图进场。
- 同一节拍只让 2-3 个角色占前景。
- 其他人通过动作、站位、表情、短句体现立场。
- 让空间承担群像关系：谁坐上席，谁站门边，谁离出口最近，谁被挡在灯外。
- 场景结束时只回收最重要的关系变化，不要给每个人写总结。

群像不是每个人轮流发言。群像是同一个事件让不同人暴露不同利益。

## 审判 / 谈判场

审判和谈判的本质是规则内的战斗。

必须设计：

- 规则：谁有发言权，谁能打断，什么证据有效。
- 观众：旁观者会影响发言策略。
- 筹码：证据、人情、债务、威胁、时间、舆论、身份。
- 底线：每方最不能失去什么。
- 变招：当证据无效、规则被改、证人翻供时怎么办。

节拍示例：

```text
主角提出诉求
-> 对方用程序否定
-> 主角拿出证据
-> 证据被重新解释
-> 旁观者立场动摇
-> 对方提高代价
-> 主角暴露更大筹码
-> 获得有限胜利或付出不可逆代价
```

审判场的爽感不是喊赢，而是让原本不被承认的事实被迫进入记录。

## 追逃场

追逃要写清楚三条线：

- 路线线：从哪里到哪里，中间有哪些岔路、遮挡、高低差、门槛。
- 资源线：体力、灯油、弹药、药效、时间、交通工具、通行证。
- 认知线：谁知道哪条路，谁误判了谁，谁用地方经验反制。

追逃常用升级：

- 退路被封。
- 路线变成单行。
- 交通工具损坏。
- 人群或天气改变速度。
- 追兵不追人，改追目标物。
- 主角必须带上伤者、证据、孩子或怪物材料。
- 近路有禁忌，远路有追兵。

追逃的终点不要永远是“逃掉”。也可以是交换、躲入更危险处、暴露身份、被迫欠债、错过车次或进入敌人规则内。

## 告白 / 决裂场

情感场景要避免只靠直白宣言。真正有效的情感转折来自边界变化。

可见证据：

- 一个角色允许另一个人进入私人空间。
- 某人第一次没有用惯常玩笑遮掩。
- 某人交出一个不该交出的资源。
- 某人替对方承担误会，但不当场邀功。
- 某人说出真相，却保留最伤人的部分。
- 某人没有追问，给对方留了体面。

告白不是一定要说“我喜欢你”。它可以是“我给你留了船票”，或“这条路我没告诉别人”。决裂也不一定是吵架，可以是称呼回到最生疏的版本。

## 揭示场

揭示真相时要避免“角色站着听完说明”。

更好的方式：

- 让真相改变当下行动。
- 让角色需要在没听完前就做选择。
- 让讲述者有偏见、隐瞒或交易目的。
- 让证据与口述互相矛盾。
- 让真相解决一个问题，同时制造更难的问题。

揭示顺序：

```text
旧解释成立
-> 异常细节增多
-> 角色提出错误解释
-> 证据推翻局部
-> 真相露出一部分
-> 行动代价立刻出现
```

不要一次性解释完整世界真相，除非这是终局承诺。长篇更适合层层改变角色理解，而不是一章讲完设定。

## 余波场

余波不是拖慢节奏，而是让结果变得真实。

余波可以写：

- 伤口如何处理，谁不敢碰谁。
- 资源消耗后，下一段路如何变难。
- 胜利后谁沉默，谁开始疏远。
- 组织如何记录这件事，民间如何误传。
- 怪物尸体、战场痕迹、损坏物件如何被处理。
- 主角第一次意识到某个规则再也不能假装不知道。

没有余波，战斗和情感都会变轻。余波不必长，但必须改变后续条件。

## 场景与章节关系

章节不是场景的堆叠，而是一个状态变化链。

章节内多个场景应形成：

```text
问题出现
-> 尝试解决
-> 代价扩大
-> 新策略
-> 结果和钩子
```

每场都要接住上一场的后果：

- 上一场受伤，下一场行动受限。
- 上一场欠债，下一场有人来索取。
- 上一场暴露身份，下一场进入新审查。
- 上一场关系变近，下一场更害怕失去。
- 上一场误判怪物，下一场必须修正策略。

若场景之间可以随意调换顺序，说明因果链不够强。

## 场景失败诊断

| 失败 | 表现 | 修复 |
|---|---|---|
| 没目标 | 人物只是聊天、走路、看景 | 给角色一个想拿到的东西 |
| 没阻力 | 目标太容易达成 | 加规则、人物、资源或时间障碍 |
| 没选择 | 角色只是被动观看 | 让角色必须取舍 |
| 没代价 | 赢了不失去任何东西 | 改变资源、关系、身份或规则 |
| 没余波 | 场景结束后完全清零 | 写伤口、债务、记录、误传或新限制 |
| 设定朗读 | 对白只解释世界 | 改成争夺证据、资格、通行或信任 |
| 动作混乱 | 不知道谁在哪里 | 补方位、距离、遮挡、退路和地形变化 |
| 反转无效 | 只是惊讶，不改局势 | 让反转改变策略、关系或代价 |
| 钩子空泛 | “危险即将来临” | 给出对象、风险、选择或具体异常 |
| 领悟突兀 | 高潮里突然悟招或突破 | 补前文旧训、误用、观察、代价和延迟兑现 |

## 输出偏好

处理场景类任务时，优先输出：

1. 场景目标和状态变化。
2. 分节拍设计。
3. 正文或改写片段。
4. 余波与需要写入 `storyAssets` 的连续性资料。

涉及地图、怪物或战斗升级时，额外输出：

- 地图条件：当前位置、退路、遮挡、高低差、资源点和控制势力。
- 生态条件：怪物行为目的、食物链位置、群体协作或社会规则。
- 职能对抗：双方能力、资源、限制、反制和胜负证据。
