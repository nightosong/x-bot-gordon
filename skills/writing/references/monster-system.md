# Monster System Reference

`monster-system` 用于设计怪物生态、怪物社会、怪物能力和怪物命名。只要故事中存在怪物、异兽、异族、畸变生物、类人敌对族群或非人文明，就应读取本参考。

## 核心目标

怪物体系首先是生态和生存民俗，其次才是敌人列表。设计时必须回答：

- 怪物为什么存在：自然演化、灾变适应、外来物种、神话残留、实验泄漏、维度污染或星球自我防御。
- 它们如何活下去：吃什么，怕什么，在哪里筑巢，如何繁殖、迁徙、护崽、休眠、共生。
- 它们如何组织社会：独居、群居、蜂群、族群、阶级、工种、语言、交易、祭祀或战争。
- 它们和人类争什么：水源、道路、巢地、尸体、药材、矿物、信仰、名字、记忆或繁殖地。
- 人类如何长期活在它们附近：日常习惯、职业禁忌、地方传说、偏方、仪式、交易、方言和错误认知如何被怪物塑形。
- 它们如何改变地图、组织、战斗体系和人物成长。

不要把怪物写成只会嘶吼、扑咬、肌肉大、利爪锋利的敌兵。
不要把怪物写成“一个功能 + 一个地形 + 一个弱点”的副本机制。真正有生命感的怪物会改变人的生活方式，让当地人害怕、敬畏、利用、误解、崇拜、模仿、交易和怀念它。

## 生存民俗优先

设计怪物时先写“一个地方的人如何长期活在这种生物附近”，再写战斗能力。怪物不是图鉴条目，而是地方生活的一部分：

- 地方传说：老人怎么讲它，孩子被怎样吓唬，哪些说法其实是错的。
- 生活经验：住户如何改门窗、灶台、屋顶、渡口、路标、灯火和睡觉方式。
- 职业禁忌：桥工、船夫、档案馆、药铺、商队、猎人、守夜人有哪些不成文规矩。
- 错误认知：人类相信它会读心、报复、带路或认血，但事实可能更简单或更复杂。
- 争议知识：不同地区、行会、官署和猎人对同一生物的判断互相矛盾。
- 情感关系：恐惧、敬畏、崇拜、模仿、利用、怀念、牟利和怜悯可以同时存在。
- 诗意体验：它登场时应有哀伤、荒凉、奇异美感或像天气一样的压迫，而不只是危险参数。

怪物知识必须允许不完整。当地偏方可以有效但原因错误；官方档案可以清楚却漏掉民间经验；某些禁忌可能只是旧灾难留下的心理阴影。战斗场面应利用这些经验、误解和禁忌，而不是用旁白公布标准弱点。

## 生态层级

参考现实动物、植物、真菌、昆虫和人类社会，再加入符合世界观的奇幻变异。

| 层级 | 设计重点 |
|---|---|
| 清道者 | 处理尸体、废料、战场残骸，决定疾病和资源回收 |
| 滤食 / 牧食者 | 依赖水、风、孢子、矿尘、光或雾，影响迁徙和季节 |
| 寄生者 | 依附人类、怪物、建筑、语言或记忆，制造隐蔽恐惧 |
| 共生者 | 与植物、村落、装备、宗教或大型怪物形成互利关系 |
| 领地捕食者 | 有固定猎场、标记、巡逻路线和繁殖期 |
| 迁徙群落 | 跟随气候、灾害、星象、潮汐、商路或尸潮移动 |
| 生态工程者 | 筑巢、改河、挖洞、结晶、造林、改造地形 |
| 顶级异常 | 数量少，改变气候、法律、宗教或整个地区的生存方式 |
| 类人 / 智性族群 | 有语言、工种、等级、交易、禁忌、记忆和政治目的 |
| 群体生命 | 真菌、虫群、珊瑚、蜂巢、城市级意识或共享梦境 |

一个大地图中应有底层、中层、上层和少量异常节点，避免所有怪物都是单体 Boss。

## 设计顺序

1. 确认生态区域：这个怪物属于森林、沼泽、矿洞、海岸、城市废墟、雪原、空域还是地下。
2. 确认生存方式：食物、巢、繁殖、迁徙、天敌、共生对象。
3. 确认地方民俗：人们怎样称呼它、绕开它、利用它、误解它、祭拜它、拿它吓孩子或做生意。
4. 确认职业禁忌：哪些职业因它改变工具、口令、作息、交易价、路线、丧葬或行业黑话。
5. 确认感官和能力：能力必须服务捕食、防御、繁殖、沟通、筑巢或迁徙。
6. 确认社会结构：独居、家庭、族群、等级、工种、领袖、仪式、法律。
7. 确认人类关系：猎杀、交易、崇拜、误解、利用、寄生、共同敌人、怜悯或纪念。
8. 确认战斗逻辑：它如何发现人、接近人、试探人、反制人、撤退或记仇；人类经验中哪些有效、哪些只是传闻。
9. 确认叙事功能：这类怪物在本卷制造什么惊喜、危险、资源、选择、主题反思或地方活法。

## 怪物能力逻辑

能力应从生态需要推导，而不是凭空分配。

- 伏击型捕食者需要伪装、静音、耐心、爆发或诱饵。
- 迁徙型群落需要导航、队形、信号、幼体保护和资源记忆。
- 寄生型怪物需要进入宿主、躲避免疫、改变行为或伪装症状。
- 生态工程者需要改变地形、制造巢材、控制水流、分泌材料或组织工群。
- 类人怪物需要语言、工具、分工、谈判、禁忌、政治和历史记忆。

强大的怪物也应有约束：季节、巢地、繁殖期、材料、温度、盐、声音、光、气味、契约、恐惧、幼体或社会禁令。

## 怪物与人类长期共存

怪物设计完成后，应能自然长出人的习惯，而不是停在功能说明：

- 桥腹虫不只是“蛀空桥”。老桥工会把耳朵贴上桥板听“潮鸣”；被吃空的桥像海螺一样回声，所以他们过桥不穿硬底鞋，也不许人在某些桥段喊话。
- 纸蛾不只是“吃纸”。旧档案馆会在纸页里夹盐叶，久而久之老地图边缘常有盐渍；后来黑市开始伪造盐痕，骗外人相信“有盐渍的图才是真的”。
- 追光兽不只是“追灯”。没人确定它追的是光、热、人还是某种频率；有时灭灯仍会被追上，于是跑线帮会为“该不该熄灯”争论，边地葬礼也可能点小灯，祈愿它替亡人带路。
- 镜雨蛛不只是“反光蛛”。玻璃雨林下雨时树间会出现无数倒挂的天空，很多人误以为那是路或神迹，后来才知道那是蛛网。
- 盐湖生物不只是“湖怪”。当地屋顶挂盐骨，孩子被禁止吹口哨，船夫怕水面上的第二道影子；这些习惯比弱点表更能让读者相信地方存在过。

这些例子不必照抄，但每个重要怪物都应达到同等密度：读者能从一个人的动作、称呼或禁忌里感觉到它在地方上活了很多年。

## 怪物社会

有智性或类人怪物时，必须设计社会意识：

- 它们如何称呼自己，如何称呼人类。
- 它们的幼体、老者、工匠、战士、祭司、商贩或记忆者各做什么。
- 它们如何继承知识：口述、气味、骨刻、梦境、孢子、舞、矿纹、歌。
- 它们是否交易，交易什么，拒绝什么。
- 它们的禁忌是什么：不杀幼体、不踏旧巢、不说真名、不吃某类尸体。
- 它们与人类的冲突是否来自误解、资源竞争、旧仇、疾病或命名权。

类人怪物不能只做人类反派换皮；它们的身体结构、感官、寿命和生态应改变社会逻辑。

## 命名方法

怪物命名要多来源并存，体现不同群体的知识和恐惧。

| 名称类型 | 用法 |
|---|---|
| 民间俗名 | 普通人按外形、声音、灾害或传闻命名，如“敲窗婆”“盐背” |
| 官方名 | 城市、军队或学院登记用名，便于通缉、税收、赏金和档案 |
| 学术名 | 记录分类、亲缘、生态位或发现者，不一定适合正文高频使用 |
| 猎人名 | 根据打法、弱点、危险信号命名，如“断灯兽”“三息客” |
| 地域名 | 不同地区按本地地貌、方言和历史称呼同一物种 |
| 禁忌名 | 某些名字不能直说，只能用避称、反称或祭祀称呼 |
| 自称 | 智性怪物或非人文明对自身族群的称呼 |
| 商品名 | 怪物材料进入贸易后，被商人改名以抬价或避讳 |

命名原则：

- 不要让所有怪物都叫“雾X”“血X”“影X”。同一核心意象最多作为部分文化或地区的命名来源。
- 名字要服务识别：读者听到名字能联想到外形、行为、危险、产地或人类态度。
- 同一怪物可拥有多个名字，称呼差异可以暴露角色职业、地区和立场。
- 类人怪物的自称可以和人类称呼冲突，这种冲突本身能制造主题张力。

## 与剧情的连接

怪物体系应推动故事，而不是只提供战斗对象：

- 怪物迁徙改变路线，迫使主角绕路、交易或进入禁区。
- 怪物材料改变经济，催生猎人、黑市、药铺、军工和禁令。
- 怪物社会改变敌我关系，某些怪物可谈判，某些人类组织更危险。
- 怪物能力改变战斗方式，逼主角学习新职能或付出新代价。
- 怪物命名改变认识过程：从俗名到真名，代表主角理解世界更深。

## 审核清单

完成怪物体系后检查：

- 是否先有生态位，再有战斗能力。
- 是否先有地方生活，再有怪物图鉴；是否避免“功能 + 地形 + 弱点”的副本机制。
- 是否覆盖底层、中层、上层和异常节点，而不是只有 Boss。
- 怪物是否有栖息地、食物、繁殖、迁徙、社会或约束。
- 能力是否服务生存方式，是否有反制方法。
- 是否有人类组织、经济、地图和战斗体系与怪物发生关系。
- 是否产生习俗、偏方、方言、避讳、路歌、黑话、职业禁忌、交易造假或丧葬仪式。
- 是否存在人类误解、争议知识和不完整经验，而不是百科全知。
- 人类对怪物是否有恐惧之外的情感：敬畏、利用、怀念、崇拜、怜悯或牟利。
- 怪物登场是否有诗意、荒凉或奇异美感，而不是只提供攻击动作。
- 怪物命名是否来源多样，避免统一前缀和模板化称呼。
- 智性怪物是否有自己的目的和社会意识。
