# Monster System Reference

`monster-system` 用于设计怪物生态、怪物社会、怪物能力和怪物命名。只要故事中存在怪物、异兽、异族、畸变生物、类人敌对族群或非人文明，就应读取本参考。

如果任务涉及一个地区的完整生态、物种丰富度、食物网或命名体系，必须先读取 `creature-ecology-design.md`。本文件负责把生态网进一步转化为怪物社会、战斗逻辑、人类关系和章节用途。

## 核心目标

怪物体系首先是生态网和生存民俗，其次才是敌人列表。设计时必须先排除低级同质化：不能把危险反复写成虫、蛛、菌、单体野兽或统一后缀的怪物名；必须让读者看见微型、小型、中型、大型、巨型 / 超大型、地貌级 / 群体级生命，以及陆地、水域、空域、地下、建筑寄生、植物冠层、雾域、类人社会等多种栖境。设计时必须回答：

- 怪物为什么存在：自然演化、灾变适应、外来物种、神话残留、实验泄漏、维度污染或星球自我防御。
- 生态发动机是什么：光、热、雾、尸体、矿尘、盐潮、旧技术残留或菌毯如何养活这个地区。
- 它们如何活下去：吃什么，怕什么，在哪里筑巢，如何繁殖、迁徙、护崽、休眠、共生。
- 它们如何组织社会：独居、群居、蜂群、族群、阶级、工种、语言、交易、祭祀或战争。
- 它们和人类争什么：水源、道路、巢地、尸体、药材、矿物、信仰、名字、记忆或繁殖地。
- 人类如何长期活在它们附近：日常习惯、职业禁忌、地方传说、偏方、仪式、交易、方言和错误认知如何被怪物塑形。
- 它们如何改变地图、组织、战斗体系和人物成长。

不要把怪物写成只会嘶吼、扑咬、肌肉大、利爪锋利的敌兵。
不要把怪物写成“一个功能 + 一个地形 + 一个弱点”的副本机制。真正有生命感的怪物会改变人的生活方式，让当地人害怕、敬畏、利用、误解、崇拜、模仿、交易和怀念它。

## 设计优先级

怪物设计的优先级必须固定为：

```text
地方生活感
> 人类关系
> 生态作用
> 剧情压力
> 战斗能力
> 数值强度
```

如果一个怪物能改变人睡觉、修桥、赶路、说话、开价、葬礼、儿童游戏和职业黑话，即使它不强，也已经是成功怪物。反之，如果一个怪物只有攻击方式、等级、属性和弱点，即使设定复杂，也只是敌兵。

设计时先问“人怎么活”，再问“它怎么打”。强怪物不一定好；能让地方改变生活秩序的怪物才有长篇价值。

## 生成收敛原则

本参考用于约束方向，不要求每次生成都写满完整生态论文。除非用户明确要求完整地区生态或全书怪物系统，否则单次生成应优先输出少量可直接进入章节的怪物、痕迹、习俗和行动难题。

- 单个怪物优先保证：生存逻辑、人类关系、地方痕迹、一个强记忆点。
- 单个地区优先保证：一个生态发动机、3-5 个代表生物、1-2 个地方职业、2-3 条民俗禁忌、一种会改变路线或价格的压力。
- 不要让每个怪物都同时承担生态、象征、诗意、战斗、经济、宗教和历史创伤；每个物种选 1-2 个主功能即可。
- 允许留白。未知、误解、争议和未记录，比全知全字段更有生命感。
- 高概念只用于少数关键物种；大量普通小生物才负责让世界可信。

避免“系统设计感”压过“故事感”。如果输出开始像百科、论文或设定表，应主动压缩为可被人物遇见、利用、误解或绕开的具体场景。

## 生存民俗优先

设计怪物时先写“一个地方的人如何长期活在这种生物附近”，再写战斗能力。怪物不是图鉴条目，而是地方生活的一部分：

- 地方传说：老人怎么讲它，孩子被怎样吓唬，哪些说法其实是错的。
- 生活经验：住户如何改门窗、灶台、屋顶、渡口、路标、灯火和睡觉方式。
- 职业禁忌：桥工、船夫、档案馆、药铺、商队、猎人、守夜人有哪些不成文规矩。
- 错误认知：人类相信它会读心、报复、带路或认血，但事实可能更简单或更复杂。
- 争议知识：不同地区、行会、官署和猎人对同一生物的判断互相矛盾。
- 情感关系：恐惧、敬畏、崇拜、模仿、利用、怀念、牟利和怜悯可以同时存在。
- 诗意体验：它登场时应有哀伤、荒凉、奇异美感或像天气一样的压迫，而不只是危险参数。

怪物知识必须允许不完整。当地偏方可以有效但原因错误；官方档案可以清楚却漏掉民间经验；某些禁忌可能只是旧灾难留下的心理阴影。战斗场面应利用这些经验、误解和禁忌，而不是用旁白公布标准弱点。

## 生态网层级

参考现实动物、植物、真菌、昆虫和人类社会，再加入符合世界观的奇幻变异。

| 层级 | 设计重点 |
|---|---|
| 非生物基础 | 地形、气候、水、盐、热、光、雾、矿物、旧设施和灾变残留 |
| 生态发动机 | 植物、菌毯、藻类、雾滤生物、矿热细菌、旧能源泄漏或尸体循环 |
| 清道者 | 处理尸体、废料、战场残骸，决定疾病和资源回收 |
| 滤食 / 牧食者 | 依赖水、风、孢子、矿尘、光或雾，影响迁徙和季节 |
| 寄生者 | 依附人类、怪物、建筑、语言或记忆，制造隐蔽恐惧 |
| 共生者 | 与植物、村落、装备、宗教或大型怪物形成互利关系 |
| 领地捕食者 | 有固定猎场、标记、巡逻路线和繁殖期 |
| 迁徙群落 | 跟随气候、灾害、星象、潮汐、商路或尸潮移动 |
| 生态工程者 | 筑巢、改河、挖洞、结晶、造林、改造地形 |
| 顶级异常 | 数量少，改变气候、法律、宗教或整个地区的生存方式 |
| 类人 / 智性族群 | 有语言、工种、等级、交易、禁忌、记忆和政治目的 |
| 群体生命 | 真菌、虫群、珊瑚、蜂巢、城市级意识或共享梦境 |

一个大地图中应有底层、中层、上层和少量异常节点，避免所有怪物都是单体 Boss。

一个地区至少要先补出 8 类生态位：基底生产者、清道 / 分解者、小型群居物、牧食 / 滤食者、中型捕食者、寄生 / 拟态者、生态工程者、关键种 / 顶级异常。只有 2-3 类需要进入战斗，其余可以通过材料、痕迹、民俗、价格和声音显出存在。

每个地区还必须检查形态丰富度：

- 尺度不得只停在“小怪 + 中怪”。核心地貌至少要有微型基底、小型日常生物、中型遭遇危险、大型迁徙或领地生物、巨型 / 超大型 / 地貌级关键存在中的四类以上。
- 栖境不得只在陆地。按地点选择陆地、水域、空域、地下、建筑寄生、植物冠层、雾域、类人社会中的三类以上。
- 体态不得只靠虫、蛛、菌。哺乳型、鸟型、鱼 / 鳗型、软体 / 贝类、爬行 / 两栖型、植物 / 藤型、矿物 / 玻璃 / 盐晶型、气雾 / 声纹型、群体 / 珊瑚型、类人型都可以进入谱系。
- 除非题材明确是虫灾、蛛巢或菌变，否则虫、蛛、菌等节肢 / 昆虫 / 真菌形态不得超过代表物种三成；超过时必须替换或降级为局部生态背景。

## 生态色谱

不要让所有地区都变成“潮湿 + 雾 + 真菌 + 黑暗 + 拟声”。每个核心地区必须有自己的生态色谱，让读者一听气味、颜色、声音和动作方式就能区分地方。

| 维度 | 可选方向 |
|---|---|
| 温度 | 炽热、寒冷、温湿、干裂、昼夜极差、地下恒温 |
| 颜色 | 盐白、铜绿、锈红、荧蓝、骨黄、煤黑、雪紫、油彩 |
| 声音 | 空鸣、潮响、骨振、低频、金属擦音、静默、群体细响 |
| 运动性 | 缓慢、迁徙、震动、漂浮、倒挂、旋游、贴地疾行 |
| 时间感 | 腐烂、冻结、风化、生长、结晶、剥落、周期性苏醒 |
| 情绪感 | 庄严、荒凉、诡艳、安静、燥热、轻快、疲惫、虔敬 |
| 危险方式 | 污染、坍塌、诱导、失温、缺氧、误认、迷路、被定价 |

同一卷内相邻地区应形成对比。例如盐白寒湖、锈红干谷、荧蓝夜沼、铜绿旧城、空鸣雪原、油彩热渠可以共存；不要让怪物、民俗和地图记忆点都落进同一种阴湿霉烂气质。

当虫、菌、蛛、孢子、寄生、腐烂、潮湿、雾、玻璃、黑暗等意象已经出现过多时，必须主动替换为鸟、鱼、哺乳、软体、矿物、盐晶、热流、声纹、风化、骨质、低温、干裂、发光植物、共生家畜或类人社会。

## 设计顺序

1. 确认生态区域：这个怪物属于森林、沼泽、矿洞、海岸、城市废墟、雪原、空域还是地下。
2. 确认生态发动机：谁把光、热、雾、尸体、矿物或旧能源转成可食资源。
3. 确认物种谱系：先分族群 / 类群，再列代表物种；避免凭空散列九个互不相干的怪物。
4. 确认尺度、栖境和体态矩阵：微型 / 小型 / 中型 / 大型 / 巨型 / 地貌级是否成网，陆地 / 水域 / 空域 / 地下 / 建筑 / 雾域是否足够丰富，虫蛛菌是否过量。
5. 确认生存方式：食物、巢、繁殖、迁徙、天敌、共生对象、数量限制。
6. 确认生态关系：它吃谁，被谁吃，与谁竞争，寄生谁或被谁寄生，死后养活谁，人类如何插入这条关系。
7. 确认地方民俗：人们怎样称呼它、绕开它、利用它、误解它、祭拜它、拿它吓孩子或做生意。
8. 确认职业禁忌：哪些职业因它改变工具、口令、作息、交易价、路线、丧葬或行业黑话。
9. 确认感官和能力：能力必须服务捕食、防御、繁殖、沟通、筑巢或迁徙。
10. 确认社会结构：独居、家庭、族群、等级、工种、领袖、仪式、法律。
11. 确认人类关系：猎杀、交易、崇拜、误解、利用、寄生、共同敌人、怜悯或纪念。
12. 确认战斗逻辑：它如何发现人、接近人、试探人、反制人、撤退或记仇；人类经验中哪些有效、哪些只是传闻。
13. 确认叙事功能：这类怪物在本卷制造什么惊喜、危险、资源、选择、主题反思或地方活法。

## 日常低等级生物

世界可信度主要来自大量低等级日常生物，而不是顶级异常。每个核心地区都应有一些不值得打、但人人知道的小生物：

- 会钻油灯、偷热、啃蜡或吃灰的小兽。
- 被当宠物、信使、天气征兆或儿童赌具的鸟、鱼、蜥、鼠、贝类。
- 能提供便宜材料、日常食物、燃料、染料、药引或假货的普通生物。
- 与旧路、屋檐、井口、桥腹、档案、尸布、盐缸、船底长期共处的低危物种。
- 只有外乡人才会害怕、本地人会随手驱赶或利用的“小麻烦”。

这些生物应让地方更活，而不是抢走主线。它们可以只出现为声音、价格、童谣、玩具、菜谱、店招、脏话、节日摊位或小孩的伤口。

## 怪物深参考层

怪物系统的深度来自“人如何长期与非人生命共处”，而不是来自能力复杂度。

深怪物设计优先回答：

- 它作为生命如何活下去。
- 它如何改变地方生活。
- 人类对它有哪些正确经验、错误解释和利益性谎言。
- 它如何进入职业、价格、节日、童谣、丧葬、建筑和路线。
- 它登场时改变了哪些感官条件。
- 它被打败、避开、误解或利用后，世界状态如何变化。

越强的怪物，越要有生态依赖；越日常的怪物，越要有生活痕迹。

## 怪物与认知误差

人类不应完全理解怪物。

常见认知误差：

- 把相关当因果：熄灯后怪物离开，其实是潮声变了。
- 把个体经验当普遍规则：某猎人用盐驱走过一次，于是全村都信盐有效。
- 把官名当真相：档案说它是疫兽，但本地人知道它只跟尸体处理有关。
- 把商业谎言当禁忌：药铺夸大某器官效果，导致过度猎杀。
- 把恐惧投射成道德：被寄生者被当作“不洁”，而不是病人。
- 把怪物行为拟人化：认为它报复，其实它只是回到繁殖地。

这种误差能制造剧情：主角先用错误经验活下来，后来发现经验有效但解释错误，最终用更准确的理解付出新代价。

## 怪物知识的多版本

同一种怪物至少可以有多套知识：

| 知识版本 | 持有者 | 特点 |
|---|---|---|
| 民间经验 | 居民、老人、孩子 | 有效但解释混乱 |
| 职业行话 | 猎人、船夫、桥工、医者 | 具体、实用、带行业偏见 |
| 官方档案 | 军队、学院、衙门 | 分类清楚，但可能滞后或政治化 |
| 商业话术 | 药铺、黑市、材料商 | 夸大价值，隐藏风险 |
| 宗教解释 | 祭司、教会、禁忌守护者 | 赋予意义，可能压迫个体 |
| 怪物自我理解 | 类人怪物或高智族群 | 与人类命名完全不同 |

多版本知识让怪物更真实。不要在第一次登场就给出百科式真相。

## 怪物登场方式

怪物不必总是直接出现。

可用登场层级：

1. 价格变化：某种材料突然涨价。
2. 动物异常：低级生物逃散、静默或聚集。
3. 地方动作：本地人同时熄灯、改路、封井。
4. 痕迹：食痕、壳、粪、皮、错位脚印、被改造的建筑。
5. 声音 / 气味 / 温度：先压迫感官。
6. 误认：角色以为是人、风、机械或另一个物种。
7. 局部身体：只见触须、影、眼、壳、幼体、巢材。
8. 完整遭遇：怪物进入场景目标。
9. 余波：它离开后，地方规则被改变。

越神秘的怪物，越适合慢慢让世界先反应，再让本体出现。

## 怪物与职业

怪物会催生职业，而职业会反过来改变怪物知识。

| 职业 | 与怪物关系 | 可写冲突 |
|---|---|---|
| 猎人 | 猎杀、驱赶、取材 | 过度捕猎、假经验、伤残 |
| 医者 | 解毒、截肢、寄生处理 | 救人与隔离的伦理冲突 |
| 船夫 | 避开水域怪物 | 航线秘密、票价、误航 |
| 桥工 | 听桥腹、修巢损 | 维护路线还是保护生态 |
| 药铺 | 收购器官材料 | 假货、垄断、价格操纵 |
| 祭司 | 管理禁忌和命名 | 恐惧治理、异端、赎罪 |
| 学者 | 分类、记录、解剖 | 研究伦理、档案误导 |
| 孩子 | 童谣、游戏、恐惧 | 低等级生物进入生活 |

怪物职业接口越多，怪物越能进入社会，而不是只在战斗章节出现。

## 怪物与建筑

长期共处会改变建筑。

可设计：

- 门槛加高，防止低爬生物进屋。
- 窗户不开向某个风口。
- 桥腹留听孔，供桥工判断巢声。
- 屋顶涂反光盐，避开趋光群。
- 城墙不是防人，而是防迁徙兽潮。
- 地下屋每隔三间留一个假门，引开拟态物。
- 学院楼梯故意不对称，防止某种按节奏上楼的东西。
- 死者房间有两道门，一道给人，一道给清道者。

建筑是怪物影响人类最直观的证据。

## 怪物与伦理

怪物不是天然该被杀。

可设计伦理问题：

- 它危险，但也是某地区食物网关键种。
- 它寄生人类，但幼体无害，成体才失控。
- 它吃尸体，令人恐惧，却防止瘟疫。
- 它能被驯养，但驯养过程极残忍。
- 它的器官能救人，过度捕猎会导致生态崩溃。
- 类人怪物无法理解人类财产，但不是恶意偷窃。
- 官方把某族群归为怪物，以便剥夺权利。

伦理问题不要只做议论，应转成具体选择：救一个被寄生者，是否会让整船人被隔离；保护关键种，是否会让村庄继续有人被吃。

## 怪物与美感

怪物不应只有丑陋和危险。

可用美感：

- 庄严：像天气、山、潮汐一样不可争辩。
- 诡艳：颜色美，但意义危险。
- 可怜：强大物种也有幼体、衰老、迁徙失败。
- 滑稽：低级生物造成生活麻烦。
- 神圣：人类把恐惧转成仪式。
- 荒凉：怪物只是灾后生态的幸存者。
- 亲密：某些家庭把低危怪物当宠物或劳动伙伴。

美感能避免怪物只剩敌兵感，也能让读者记住它。

## 怪物失败诊断

| 失败 | 表现 | 修复 |
|---|---|---|
| 战斗单位化 | 只有攻击方式、弱点、等级 | 补生态、职业、民俗和误解 |
| 能力堆叠 | 能力很酷但无生存理由 | 绑定捕食、防御、繁殖、迁徙或交流 |
| 同质化 | 全是虫、菌、蛛、腐烂、雾 | 使用生态色谱，换温度、颜色、声音、栖境 |
| 百科化 | 一登场就解释完整 | 改成多版本知识和逐步揭示 |
| 与人无关 | 怪物只在野外出现 | 补价格、建筑、职业、童谣和禁忌 |
| 打完清零 | 击败后无后果 | 改变路线、生态、组织反应或材料价格 |
| 非人不非人 | 类人怪物像人类换皮 | 由感官、繁殖、寿命、食性推导社会 |

## 怪物能力逻辑

能力应从生态需要推导，而不是凭空分配。

- 伏击型捕食者需要伪装、静音、耐心、爆发或诱饵。
- 迁徙型群落需要导航、队形、信号、幼体保护和资源记忆。
- 寄生型怪物需要进入宿主、躲避免疫、改变行为或伪装症状。
- 生态工程者需要改变地形、制造巢材、控制水流、分泌材料或组织工群。
- 类人怪物需要语言、工具、分工、谈判、禁忌、政治和历史记忆。

强大的怪物也应有约束：季节、巢地、繁殖期、材料、温度、盐、声音、光、气味、契约、恐惧、幼体或社会禁令。

## 怪物与人类长期共存

怪物设计完成后，应能自然长出人的习惯，而不是停在功能说明：

- 桥患不只是“蛀空桥”。老桥工会把耳朵贴上桥板听“潮鸣”；那可能是桥肺苔涨缩、青喉鳗钻梁、空梁鹭离巢和桥下巨物擦桩叠出的声音，所以他们过桥不穿硬底鞋，也不许人在某些桥段喊话。
- 档案盐叶不只是“防蛀偏方”。旧档案馆会在纸页里夹盐叶，久而久之老地图边缘常有盐渍；后来黑市开始伪造盐痕，骗外人相信“有盐渍的图才是真的”。
- 灯后客不只是“追灯怪”。没人确定它追的是光、热、油味、人，还是铁轨低频；有时灭灯仍会被追上，于是跑线帮会为“该不该熄灯”争论，边地葬礼也可能点小灯，祈愿亡人不在雾里回头。
- 玻璃雨林的“倒天”不只是一张怪物网。雨中树冠会出现无数倒挂的天空，可能来自悬窗树、折光鹭巢羽、雨镜母浮囊和透明叶膜共同折射；外乡人误以为那是单一怪物，本地向导更相信鹿不饮水、鹭反飞和猿不敲树这些征候。
- 盐湖生物不只是“湖怪”。当地屋顶挂盐骨，孩子被禁止吹口哨，船夫怕水面上的第二道影子；这些习惯比弱点表更能让读者相信地方存在过。

这些例子不必照抄，但每个重要怪物都应达到同等密度：读者能从一个人的动作、称呼或禁忌里感觉到它在地方上活了很多年。

## 怪物塑造人

下一步必须让怪物改变人的行为和价值观，而不只是改变路线和经济。长期生活在某种生物附近的人，会形成独特人格、礼貌、恐惧、爱情、葬礼、儿童游戏、口头禅和判断方式。

设计时至少追问：

- 它让当地人相信什么，不再相信什么。
- 它让人学会哪种身体反应：轻步、避镜、少喊、先闻、靠墙睡、不过夜承诺。
- 它改变了什么礼貌：不问真名、不碰门梁、不说“回来”、递东西不递影子。
- 它改变了什么价值观：留下名字比尸体重要、守路比杀敌体面、会绕路的人才算聪明。
- 它改变了什么亲密关系：求婚要过桥、葬礼要点灯、孩子满月要认路、离别时不能回头。

例子：

- 长期生活在“借声客”附近的人，不再轻易相信远处呼救。
- 盐湖地区的人避免轻易承诺，因为“第二道影子”会让违约者无处藏身。
- 常年走玻璃雨林的人会本能避开镜面，连恋人赠礼也不用亮面金属。
- 桥民下意识轻步，说话先摸梁，因为他们从小被教导别惊动桥腹里的东西。
- 北方雪原人认为“留下名字”比找到尸体重要，因为尸体会被迁徙生物带走，名字还能带人回家。

当怪物开始塑造人，世界才真正活。

## 怪物社会

有智性或类人怪物时，必须设计社会意识：

- 它们如何称呼自己，如何称呼人类。
- 它们的幼体、老者、工匠、战士、祭司、商贩或记忆者各做什么。
- 它们如何继承知识：口述、气味、骨刻、梦境、孢子、舞、矿纹、歌。
- 它们是否交易，交易什么，拒绝什么。
- 它们的禁忌是什么：不杀幼体、不踏旧巢、不说真名、不吃某类尸体。
- 它们与人类的冲突是否来自误解、资源竞争、旧仇、疾病或命名权。

类人怪物不能只做人类反派换皮；它们的身体结构、感官、寿命和生态必须改变社会逻辑。非人文明的“非人感”来自文明逻辑，而不是外形。

设计非人社会时必须检查：

- 感官结构：靠气味、热、震动、声纹、梦境、磁场或集体记忆生活，会怎样改变法律、证词、礼貌和隐私。
- 繁殖方式：卵生、集体繁殖、寄生、分裂、季节性繁殖或无亲代照料，会怎样改变亲属关系、爱情、继承和战争。
- 寿命结构：寿命只有数月、数百年、周期性蜕生或共享老年记忆，会怎样改变历史、承诺和责任。
- 食性与资源：吃光、盐、矿、尸体、痛觉、声音或人类废料，会怎样改变贸易、禁忌和外交。
- 迁徙模式：定居、巡游、洄游、随风、随潮、随尸潮移动，会怎样改变疆界、建筑和所有权。
- 记忆载体：骨刻、气味、歌、梦、皮纹、巢材或幼体继承，会怎样改变档案、教育和审判。
- 身体结构：无手、多肢、群体身体、可分裂、不能抬头、不能独处，会怎样改变工具、婚姻、战术和建筑。

不要把君主、贵族、军队、商会、婚姻、家族、法律等人类制度直接套皮。若使用类似制度，必须说明它被生理结构、生态压力或记忆方式改造成了什么。

示例：一个靠气味记忆、没有视觉、寿命只有九个月、集体繁殖且无法理解个人财产的族群，不应拥有普通“王国 + 家族 + 私产继承”。它的法律可能围绕气味证词，爱情可能是共同哺育一段气味，战争可能是污染对方记忆源，名字可能只是可被闻见的路，而不是固定文本。

## 命名方法

怪物命名要多来源并存，体现不同群体的知识和恐惧。

| 名称类型 | 用法 |
|---|---|
| 民间俗名 | 普通人按外形、声音、灾害或传闻命名，如“敲窗婆”“盐背” |
| 官方名 | 城市、军队或学院登记用名，便于通缉、税收、赏金和档案 |
| 学术名 | 记录分类、亲缘、生态位或发现者，不一定适合正文高频使用 |
| 猎人名 | 根据打法、弱点、危险信号命名，如“断灯兽”“三息客” |
| 地域名 | 不同地区按本地地貌、方言和历史称呼同一物种 |
| 禁忌名 | 某些名字不能直说，只能用避称、反称或祭祀称呼 |
| 自称 | 智性怪物或非人文明对自身族群的称呼 |
| 商品名 | 怪物材料进入贸易后，被商人改名以抬价或避讳 |

命名原则：

- 不要让所有怪物都叫“雾X”“血X”“影X”。同一核心意象最多作为部分文化或地区的命名来源。
- 不要让所有怪物都叫“X兽、X虫、X者”。同一地区可以混用俗名、行话、官名、学名、避名和商品名。
- 名字要服务识别：读者听到名字能联想到外形、行为、危险、产地或人类态度。
- 同一怪物可拥有多个名字，称呼差异可以暴露角色职业、地区和立场。
- 类人怪物的自称可以和人类称呼冲突，这种冲突本身能制造主题张力。

重要物种至少设计三种称呼：

- 本地俗名：老人、小孩、住户怎么叫。
- 职业行话：桥工、船夫、药铺、猎人、商队怎么叫。
- 官名 / 学名：档案、门籍、医者或守档人怎么登记。

必要时再补禁忌名和商品名。命名时必须标注“谁这么叫、为什么这么叫、这个称呼暴露了什么立场”。

## 与剧情的连接

怪物体系应推动故事，而不是只提供战斗对象：

- 怪物迁徙改变路线，迫使主角绕路、交易或进入禁区。
- 怪物材料改变经济，催生猎人、黑市、药铺、军工和禁令。
- 怪物社会改变敌我关系，某些怪物可谈判，某些人类组织更危险。
- 怪物能力改变战斗方式，逼主角学习新职能或付出新代价。
- 怪物命名改变认识过程：从俗名到真名，代表主角理解世界更深。
- 怪物长期共存改变人格、礼貌、爱情、葬礼、儿童游戏、口头禅和地方价值观。

## 审核清单

完成怪物体系后检查：

- 是否先有生态位，再有战斗能力。
- 是否先有生态发动机和食物网，再有大型怪物。
- 是否先有地方生活，再有怪物图鉴；是否避免“功能 + 地形 + 弱点”的副本机制。
- 是否覆盖底层、中层、上层和异常节点，而不是只有 Boss。
- 是否覆盖微型、小型、中型、大型、巨型 / 超大型、地貌级 / 群体级中的多种尺度，而不是只有小怪和中型敌人。
- 是否覆盖陆地、水域、空域、地下、建筑寄生、树冠、雾域或类人社会中的多种栖境，而不是只有地面遭遇。
- 是否覆盖哺乳、鸟、鱼、软体、植物、矿物、气雾、群体、类人等多种体态；虫、蛛、菌是否被控制在少数形态。
- 是否为不同地区建立了生态色谱，避免所有区域都潮湿、阴暗、真菌化和雾化。
- 是否有足够低等级日常生物，让世界不只靠顶级异常维持新鲜感。
- 是否有足够物种丰富度：生产者、清道者、小型群居物、牧食者、捕食者、寄生者、生态工程者和关键种。
- 怪物是否有栖息地、食物、繁殖、迁徙、社会或约束。
- 每个重要物种是否至少连接三个其他物种和一个人类职业。
- 单个怪物是否遵守最小必要原则，没有为了填满字段而变成设定表。
- 能力是否服务生存方式，是否有反制方法。
- 是否有人类组织、经济、地图和战斗体系与怪物发生关系。
- 是否产生习俗、偏方、方言、避讳、路歌、黑话、职业禁忌、交易造假或丧葬仪式。
- 怪物是否开始塑造人的行为、礼貌、价值观、儿童恐惧、爱情或葬礼。
- 是否存在人类误解、争议知识和不完整经验，而不是百科全知。
- 人类对怪物是否有恐惧之外的情感：敬畏、利用、怀念、崇拜、怜悯或牟利。
- 怪物登场是否有诗意、荒凉或奇异美感，而不是只提供攻击动作。
- 怪物命名是否来源多样，避免统一前缀、统一后缀和模板化称呼。
- 每个重要名字是否能看出使用者、来源和立场。
- 智性怪物是否有自己的目的和社会意识；其社会制度是否由感官、繁殖、寿命、食性、迁徙、记忆和身体结构推导，而不是人类社会换皮。
