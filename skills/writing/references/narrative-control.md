# Narrative Control Reference

`narrative-control` 用于给长篇写作系统加刹车。它不负责扩世界，而负责判断什么该展开、什么该压缩、什么必须回到主角行动。只要任务涉及大纲扩展、世界设定膨胀、章节拖慢、AI 越写越散、怪物 / 地图 / 组织过度抢戏，就应读取本参考。

## 核心目标

故事推进总纲：

```text
所有世界、人物、生态、路线、组织、怪物和规则，
最终都必须持续压迫主角做选择。
```

若一个设定不能改变行动、代价、关系、身份、资源、情绪或价值判断，则它只能作为背景存在，不得长期占据正文。

## 剧情优先级

设计和扩写时，优先级如下：

```text
主角当前选择
> 最近 3-5 章冲突
> 资源 / 路线 / 身份 / 关系 / 代价变化
> 阶段目标与阶段回收
> 后续明确伏笔
> 世界设定完整度
```

长篇世界可以很大，但正文不能被世界完整度牵着走。读者追的是人物如何被世界改变，不是作者把世界库填完。

## 设定裁剪原则

任何设定在扩写前，必须回答：

- 是否影响主角当前阶段的行动。
- 是否影响最近 3-5 章冲突。
- 是否影响资源、路线、身份、关系或代价。
- 是否会在未来明确回收。

若答案都是否，只允许保留一句摘要。

### 允许展开

- 本卷会到达的新地区。
- 本卷主要冲突涉及的组织。
- 近期会改变路线或资源的怪物生态。
- 影响主角身份、通行、伤势、债务或关系的规则。
- 即将在 3-5 章内回收的伏笔。

### 只留摘要

- 很远的国家和历史。
- 当前不会遇到的怪物谱系。
- 暂不影响主角的组织派系。
- 不会进入近期交易和路线的资源。
- 只为显得宏大而存在的设定名词。

### 直接删除或降级

- 重复承担同一功能的地区、怪物、组织或角色。
- 只换名字、不改变剧情的设定。
- 与主角目标无关、也无回收计划的复杂系统。
- 让故事变成设定手册的连续说明段。

## 信息释放原则

正文一次只允许读者真正记住：

- 1 个新规则。
- 1 个新地点。
- 1-2 个关键人物。
- 1 个新危险。
- 1 个核心情绪目标。

超过后，其余内容必须降级为背景感知。背景感知可以用声音、价格、称呼、队伍、墙上告示、路人动作、店招、口头禁忌轻轻带过，不做解释。

## 设定释放触发器

设定不能按百科顺序释放，必须绑定触发器。

| 触发器 | 释放方式 |
|---|---|
| 行动 | 角色要过桥，才解释路券和桥税 |
| 危险 | 怪物靠声音定位，才解释本地人为什么低声 |
| 误判 | 主角按旧经验失败，才释放新地区规则 |
| 交易 | 价格谈不拢，才说明资源稀缺和垄断 |
| 失败 | 尸体被清道者吃掉，才说明证据保存规则 |
| 关系变化 | 某人不帮忙，才解释旧债、家族或制度压力 |
| 惩罚 | 违规被记录，才说明组织真正控制什么 |

读者先看见“为什么现在必须知道”，再接受“这是什么”。

## 叙事压缩原则

连续三章若未发生下列任意变化，必须压缩、合并或跳过过程：

- 地图变化。
- 关系变化。
- 身份变化。
- 资源变化。
- 规则变化。
- 世界状态变化。
- 主题判断变化。

长篇允许留白，不要求完整模拟每天生活。日常片段必须承担关系、气氛、伏笔、代价、恢复或反讽功能。

## 压缩方式

| 问题 | 压缩方法 |
|---|---|
| 连续赶路无变化 | 用一段路程蒙太奇，保留一个新代价 |
| 连续训练无变化 | 只写一次失败、一次修正、一次成果 |
| 连续解释设定 | 改成一次交易、一次犯错、一次惩罚 |
| 连续日常无推进 | 合并为关系小证据或过渡段 |
| 连续小冲突 | 合并成一个更强的选择 |
| 连续新地点 | 删除功能重复地点，只保留记忆锚点最强者 |

压缩不是删质感，而是把没有状态变化的过程折叠，把读者注意力还给真正改变故事的地方。

## 不可逆后果原则

重要冲突后，至少一个条件必须永久改变。

可用不可逆项：

- 地点损毁。
- 路线封闭。
- 势力态度改变。
- 身份暴露。
- 身体残缺。
- 资源断供。
- 名声固化。
- 怪物生态改变。
- 某种关系无法恢复。
- 规则被公开，不能再装作不知道。

不可逆不等于永远悲惨。它的作用是让世界记得人物做过什么。

## 不可逆后果强度

| 强度 | 表现 | 用途 |
|---|---|---|
| 轻度 | 失去小资源、欠小债、被某人记住 | 章节推进 |
| 中度 | 路线关闭、信任下降、价格上涨、轻伤延续 | 小高潮 |
| 重度 | 身份暴露、组织通缉、重伤、关系破裂 | 阶段高潮 |
| 结构性 | 城市规则改变、生态失衡、战争开启、主角价值观转向 | 卷末 / 大高潮 |

不要每章都重度不可逆，否则读者疲劳。关键是持续有痕迹，而不是持续毁灭。

## 人类压力优先原则

长期冲突优先来自：

- 人与人。
- 制度与人。
- 资源与人。
- 关系与人。
- 生存价码与人。

怪物更多负责：

- 放大压力。
- 改变路线。
- 制造环境。
- 扭曲经济。
- 改变地方活法。
- 暴露制度和人性的裂缝。

不要让故事长期退化为：

```text
进入新地区 -> 看见新怪 -> 打新怪 -> 去下个地区
```

更好的结构是：

```text
进入新地区
-> 怪物改变这里的生活和价格
-> 人类组织利用这种风险获利
-> 主角被迫在救人、通行、交易、身份和代价之间选择
-> 战斗只是选择的一部分
```

## 世界构建预算

每个阶段给世界构建设置预算。

### 章节级预算

- 只展开当前场景必要的规则。
- 最多新增 1 个重要名词。
- 新地点只给一个身体记忆点和一个行动门槛。
- 新怪物只给一个行为、一个危险、一个人类应对方式。

### 阶段级预算

- 展开 1 个核心地区。
- 展开 1 个主要组织或制度门槛。
- 展开 1 条核心资源 / 经济链。
- 展开 1-2 类关键怪物或生态压力。
- 展开 2-4 个阶段关键人物。

### 全书级预算

- 可以有大地图和多组织，但只有进入阶段目标时才细化。
- 未到达地区只留名称、方向、传闻和未来功能。
- 未登场组织只留对主角的压力影子。

预算不是限制想象，而是保护读者记忆和主线焦点。

## AI 发散诊断

| 症状 | 判断 | 修复 |
|---|---|---|
| 连续补设定 | 模型在躲避剧情选择 | 回到主角当前目标和最近 3-5 章冲突 |
| 地图越来越大 | 缺少阶段边界 | 只展开本卷抵达区域 |
| 怪物越来越多 | 怪物压过人 | 选 1 个关键生态压力，其余转背景 |
| 组织越来越复杂 | 派系没进入行动 | 只保留能制造门槛、价码、反制的派系 |
| 角色越来越散 | 谱系失控 | 合并功能重复角色 |
| 每章都像中段 | 缺少阶段目标 | 交给 `arc_planner` 设计阶段高潮 |
| 世界很活但故事不动 | 缺少不可逆后果 | 添加资源、路线、身份或关系变化 |

## 章节推进检查

章节规划和正文生成前，回答：

- 本章主角想得到什么。
- 谁或什么阻止他。
- 本章新增信息是否超过信息释放上限。
- 本章设定是否影响最近 3-5 章。
- 本章结尾改变了哪一种状态。
- 本章有没有不可逆后果。
- 若删掉本章，后续是否真的受影响。

如果删掉本章后后续几乎不变，应压缩或合并。

## 阶段推进检查

一卷 / 阶段完成后，检查：

- 阶段目标是否兑现或被推翻。
- 阶段假目标是否被揭示。
- 主角获得了什么，又失去了什么。
- 哪条路线、关系、身份、资源或规则永久改变。
- 是否回收了至少一个前期承诺。
- 是否给下一阶段留下更高层级问题。
- 本阶段新增世界设定是否都服务过行动。

## 输出偏好

处理叙事控制任务时，优先输出：

1. 当前是否发散。
2. 哪些设定保留、压缩、降级、删除。
3. 最近 3-5 章应聚焦的冲突。
4. 需要写入 `state_tracker` 的状态变化。
5. 下一步可执行章节或阶段目标。

不要只说“节奏需要加快”。要指出哪一段可合并、哪个设定只留一句、哪个冲突应提前、哪个后果必须不可逆。

## 审核清单

- 是否把主角当前选择放在世界设定之前。
- 是否限制近期信息释放量。
- 是否避免提前完整建库。
- 是否把设定绑定行动、危险、误判、交易、失败或关系变化。
- 是否连续三章内至少发生一个状态变化。
- 重要冲突后是否有不可逆后果。
- 怪物是否在放大人类压力，而不是替代人类冲突。
- 若删除某段设定，故事是否仍然成立；若成立，应压缩。
