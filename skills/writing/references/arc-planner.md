# Arc Planner Reference

`arc-planner` 用于规划长篇的一卷、一个大阶段、一次远行区段或 8-30 章左右的连续推进。它解决的问题不是“下一章写什么”，而是“这一阶段为什么值得读完，读完后世界和人物发生了什么不可逆改变”。

## 核心目标

长篇不是章节驱动，而是阶段驱动。章节负责局部推进，阶段负责读者满足感。

有效阶段必须具备：

- 一个阶段目标。
- 一个阶段假目标。
- 一个新压力环境。
- 一组关系位移。
- 一个可累计代价。
- 一个阶段回收。
- 一个阶段结尾反转或压力抬升。

如果没有阶段结构，AI 容易把每章都写成“中间章”：一直推进、一直遇险、一直补设定，但没有阶段高潮、阶段收束和读完一卷的满足感。

## 何时使用

出现以下情况时，必须使用 `arc_planner`：

- 用户要求规划一卷、一个篇章、一个阶段、一个大地图区段。
- 目录超过 8-10 章。
- 长篇目标超过 30 章。
- 主角即将进入新地区、新组织、新战斗规则或新关系阶段。
- 当前章节连续推进但缺少阶段高潮。
- 故事已经出现“每章都像中间章”的症状。

## Arc Schema

```json
{
  "arc_goal": "",
  "arc_false_goal": "",
  "arc_new_region": "",
  "arc_pressure": "",
  "arc_relationship_shift": "",
  "arc_cost": "",
  "arc_payoff": "",
  "arc_end_reversal": "",
  "chapter_range": "",
  "state_changes": []
}
```

字段说明：

| 字段 | 作用 |
|---|---|
| `arc_goal` | 主角以为这一阶段要完成的明确目标 |
| `arc_false_goal` | 阶段中后段会被推翻或重新理解的目标 |
| `arc_new_region` | 新地点、新制度、新人群或新生存方式 |
| `arc_pressure` | 持续压迫主角选择的核心压力 |
| `arc_relationship_shift` | 本阶段必须改变的一组关系 |
| `arc_cost` | 阶段累计代价，不是单章小损耗 |
| `arc_payoff` | 阶段承诺的回收和满足感 |
| `arc_end_reversal` | 阶段结尾的身份、路线、规则或目标反转 |
| `chapter_range` | 建议章节范围 |
| `state_changes` | 本阶段必须写入状态机的变化 |

## 阶段设计顺序

1. 确认主角带着什么误解或缺口进入阶段。
2. 确认阶段表面目标。
3. 确认阶段真正压力。
4. 确认新地区 / 新制度 / 新资源如何改变行动方式。
5. 确认本阶段必须推进的关系。
6. 确认本阶段的累计代价。
7. 确认阶段高潮的不可逆选择。
8. 确认阶段收束和下一阶段钩子。

不要先排章节标题。先定阶段发动机，再拆章节。

## 阶段类型

| 阶段类型 | 核心读感 | 常见结构 |
|---|---|---|
| 出走阶段 | 离开旧秩序 | 渴望 -> 阻拦 -> 机会 -> 第一次代价 |
| 入城阶段 | 进入新制度 | 规则误判 -> 门槛 -> 交易 -> 身份变化 |
| 远行阶段 | 地图和关系扩展 | 新活法 -> 路线失败 -> 同行关系 -> 抵达反转 |
| 学习阶段 | 旧经验失效 | 失败 -> 观察 -> 训练 / 交易 -> 新判断 |
| 追逃阶段 | 时间压力 | 暴露 -> 封锁 -> 误导 -> 代价脱身 |
| 调查阶段 | 信息重组 | 旧解释 -> 异常 -> 误判 -> 证据改写 |
| 战争阶段 | 资源和组织冲突 | 征召 -> 补给 -> 前线 -> 失败后果 |
| 回乡阶段 | 旧地重估 | 回到旧地 -> 身份错位 -> 清账 -> 新离开 |
| 终局阶段 | 承诺集中兑现 | 多线合流 -> 不可逆选择 -> 余波生活 |

阶段类型可以混合，但一个阶段最好有一个主读感。

## 阶段节奏骨架

推荐 8-12 个节拍：

```text
阶段入口
-> 表面目标
-> 新规则 / 新地点第一次压迫
-> 第一次小胜或小败
-> 关系位移
-> 假目标显出裂缝
-> 资源或路线被夺走
-> 中段反制 / 误判修正
-> 代价累计
-> 阶段高潮选择
-> 阶段回收
-> 结尾反转 / 下一阶段钩子
```

如果阶段很长，可以拆成三个小段：

- **进入段**：新环境、新门槛、新误判。
- **缠斗段**：资源、关系、规则多次反制。
- **收束段**：阶段承诺兑现，代价不可逆。

## 阶段目标与假目标

阶段目标是主角以为自己要完成的事。阶段假目标是这个目标在推进中被重新解释。

示例：

| 表面目标 | 假目标被推翻 |
|---|---|
| 拿到过桥牌 | 真正问题不是过桥，而是主角被登记为另一个身份 |
| 猎杀怪物 | 真正问题是怪物维持了当地食物网 |
| 救出某人 | 对方不想离开，因为离开会害死更多人 |
| 进入学院 | 学院不是提供知识，而是筛选可被牺牲的人 |
| 找到旧地图 | 地图正确，但世界已经改变，路不再存在 |

假目标不是欺骗读者，而是让主角理解世界更深一层。

## 阶段关系位移

每个阶段至少改变一组关系。

可选关系位移：

- 陌生人 -> 有限交易。
- 有限交易 -> 共同风险。
- 同伴 -> 价值冲突。
- 对手 -> 被迫合作。
- 导师 -> 经验失效。
- 亲人 -> 旧债清算。
- 制度人物 -> 个人困境显露。
- 主角与自我 -> 承认旧误信。

关系位移必须有小证据：共享资源、没拆穿、替对方保留体面、拒绝无代价帮助、在关键处选择不同路。

## 阶段代价

阶段代价要累计，而不是每章清零。

代价类型：

- 身体：伤势、疲劳、感染、异化、残缺。
- 资源：钱、粮、药、票、工具、情报、地图。
- 身份：被登记、通缉、降等、入籍、被误认。
- 关系：信任下降、旧债暴露、承诺无法兑现。
- 路线：封路、错过船期、失去向导、旧路消失。
- 道德：救一人害一群，守规矩害朋友，破规矩引来追责。
- 主题：主角不得不承认自己相信的东西不完整。

阶段结束时，至少一个代价进入 `state_tracker` 的不可逆后果。

## 阶段回收

阶段必须回收承诺。

可回收对象：

- 开头出现的规则。
- 初入地点时看不懂的动作。
- 某个小人物的行话。
- 某种怪物的错误经验。
- 某个关系小证据。
- 某笔债。
- 某条旧路。
- 某个主题象征。

回收要改变状态，不只是解释“原来如此”。例如主角终于理解“为什么桥工不喊名字”，并用这个经验救人或付出代价。

## 阶段结尾

阶段结尾要同时满足：

- 兑现一个承诺。
- 改变一个状态。
- 留下一个更高层级问题。

常见结尾：

- 抵达目标，但目标意义改变。
- 赢得通行，但身份暴露。
- 救出人，但路线关闭。
- 打败怪物，但生态失衡。
- 揭开组织谎言，但自己被组织记录。
- 修复关系，但必须分开。

不要把阶段结尾写成“下一站更危险”。要给出具体的新对象、新风险或新选择。

## 终局阶段的自然收束

终局阶段不是把所有故事都推向“揭穿阴谋、登顶、掌权、统一或成为天下第一”。除非作者明确要求，`arc_planner` 不得把结局默认设计为：

- 主角揭穿覆盖全书的终极阴谋。
- 主角公开世界真相后完成使命。
- 主角击败唯一最终 Boss 后世界恢复正常。
- 主角接管王朝、宗门、组织、城市或天下。
- 主角成为天下第一、万众承认的最高强者或最高裁判者。

终局阶段更适合集中兑现以下承诺：

| 收束类型 | 核心问题 | 可用结构 |
|---|---|---|
| 路线收束 | 主角终于抵达哪里，抵达意义如何改变 | 旧路线合流 -> 关键选择 -> 带余波的离开 / 留下 |
| 技艺收束 | 主角真正理解了什么能力、手艺或武学 | 最后误用 -> 代价修正 -> 以新理解解决具体困局 |
| 关系收束 | 哪些债、亏欠、信任或分歧得到结算 | 重逢 / 对峙 -> 不完美选择 -> 保留体面或分道 |
| 地方收束 | 哪个具体地方因主角行动得以继续生活 | 地方危机集中 -> 守住一件具体事 -> 余波重建 |
| 价值收束 | 主角放下了哪种旧误信 | 旧诱惑重现 -> 拒绝旧路 -> 带代价确认自我 |
| 传承收束 | 主角如何接住或重新解释一份传承 | 旧规矩失效 -> 自己承担后果 -> 传承改口或延续 |

武侠、玄幻、冒险和成长题材可以有大决战，但大决战的意义优先是“守住承诺、夺回行动自由、救下一段路、完成技艺领悟、还清关系债、让一个地方仍能活下去”。主角可以胜过某个强敌，但不需要因此成为全天下最强；可以改变一片江湖，但不需要成为江湖之主。

终局规划时必须输出五个自然收束要素：

1. 主角最终确认或放下的旧误信。
2. 主角保住、失去或改变的一件具体事物。
3. 最重要关系的结算方式。
4. 某个地点、路线、行业、家族或门派的余波状态。
5. 主角之后继续生活、继续上路或安静留下的姿态。

终局仍然需要不可逆选择和读者满足感，但满足感来自“这一路真的改变了人和世界的一角”，而不是来自权力归属或排名宣布。

## 与章节规划的关系

`arc_planner` 不写每章细节，但要给每章功能。

章节功能可以是：

- 入口章。
- 规则误判章。
- 交易章。
- 追逃章。
- 关系试探章。
- 资源短缺章。
- 中段反制章。
- 真相裂缝章。
- 阶段高潮章。
- 余波 / 收束章。

每章只承担 1 个主功能。多个功能堆在一起会导致信息密度爆炸。

## 阶段信息密度

一个阶段最多重点展开：

- 1 个核心新地区。
- 1 个主组织或制度门槛。
- 1 条核心经济链。
- 1-2 个关键怪物 / 生态压力。
- 2-4 个阶段关键人物。
- 1 个主题锚点。

其余内容以背景感知出现。不要把一个阶段写成百科卷。

## 阶段状态机

每个阶段开始前读取 `state_tracker`：

- 时间、天气、路线状态。
- 主角伤势、疲劳、资源、债务、通缉。
- 组织态度和城市警戒。
- 资源价格和黑市变化。
- 怪物迁徙和生态扰动。
- 主题锚点当前状态。

阶段结束后必须输出状态差异：

```json
{
  "arc_state_diff": {
    "routesClosed": [],
    "routesOpened": [],
    "factionAttitudeChanged": [],
    "resourcesChanged": [],
    "relationshipsChanged": [],
    "injuriesOrFatigueChanged": [],
    "themeAnchorsAdvanced": [],
    "irreversibleConsequences": []
  }
}
```

## 长篇节奏轮换

避免连续多个阶段都用同一种读感。

轮换建议：

- 高压追逃后接中转和关系修复。
- 大量设定后接行动和交易。
- 战斗阶段后接余波和制度反制。
- 奇观阶段后接人的选择和经济后果。
- 情感密集阶段后接外部压力。
- 组织斗争后接地图移动或民间生活。

长篇需要呼吸。呼吸不是停滞，而是换一种压力。

## 常见失败诊断

| 失败 | 表现 | 修复 |
|---|---|---|
| 每章都像中间章 | 有推进但没有阶段目标和结算 | 定义 `arc_goal / arc_payoff / arc_end_reversal` |
| 地图游记化 | 一直看新地方 | 给阶段目标和不可逆代价 |
| 怪物副本化 | 新地区只为打新怪 | 补人类制度、经济链和关系位移 |
| 阶段无回收 | 开头承诺不兑现 | 选择 1-2 个规则、关系或伏笔集中回收 |
| 阶段太满 | 新地点、人物、怪物、组织同时展开 | 按阶段信息密度预算裁剪 |
| 结尾空泛 | “更大危险来了” | 给具体新风险、身份变化或路线关闭 |
| 终局机械霸权化 | 结尾自动变成揭穿阴谋、称王、统一或天下第一 | 改成路线、技艺、关系、地方、价值或传承的自然收束 |
| 技艺领悟关卡化 | 每到一地、每打一场或每卷结尾都固定悟招 / 破境 | 改成旧训失效、多章观察、误用代价、延迟兑现和后续验证 |
| 代价清零 | 下一阶段像没发生过 | 写入 `state_tracker` 的不可逆后果 |

## 输出偏好

处理阶段规划时，优先输出：

1. 阶段一句话承诺。
2. `arc_goal / arc_false_goal / arc_pressure`。
3. 章节功能表，而不是过细剧情。
4. 阶段代价与不可逆后果。
5. 需要写入 `state_tracker` 的状态变化。
6. 信息密度裁剪说明。

## 审核清单

- 阶段是否有清晰目标。
- 是否有阶段假目标或认知反转。
- 是否改变至少一组关系。
- 是否存在累计代价。
- 是否回收了前期承诺。
- 是否留下具体下一阶段钩子。
- 是否避免同质章节连续堆叠。
- 是否把新增设定限制在阶段预算内。
- 阶段结尾是否写入世界 / 角色状态机。
- 终局是否避免默认揭阴谋、登顶、掌权或统一，改为自然余波式收束。
