# Character Lineage Reference

`character-lineage` 用于设计故事中的人物谱系和角色档案。它的目标不是做一张名单，也不是把角色压成叙事工具；它要同时保证人物在长篇中有稳定作用，并让读者相信这些人原本就活在这个世界里。

## 核心目标

人物设计时必须回答：

- 这个人从哪里来。
- 他和其他人是什么关系。
- 如果主角没有出现，他原本会怎样生活。
- 他长期活在什么地方、制度、关系、痛苦或希望里。
- 他有哪些习惯、偏见、规避方式、羞耻、怀念、小聪明和不愿被提起的东西。
- 他在故事里出现几次，每次带来什么局面变化、地方质感或情绪重量。
- 他的身份、经历、秘密和结局如何影响主线。
- 他改变了主角的哪种状态：目标、资源、关系、身份、信息差、地图可达性、规则理解或代价。

不要只写“他是谁”。应详略得当地写清身份、重要经历、故事重点、关系变化和结局方向，也要写出他作为一个活人的生活惯性和可感痕迹。

人物不是“设定集合”。人物是长期活在某种地方、某种关系、某种制度、某种痛苦里的人。真正重要的不是档案有多完整，而是读者是否相信：这个人曾经活过。

## 人物存在原则

角色不应只在需要推动剧情时才被激活。即使主角不存在，他也应该：

- 有自己的生活惯性：每天怎么活，靠什么吃饭，为什么还留在那里。
- 有长期习惯：睡觉靠墙、分钱先留船票、讲话前看门、听见木梁响就抬头。
- 有偏见和误解：相信某种地方经验、讨厌某类人、误会某个组织或地貌。
- 有不愿提起的过去：旧战线、旧债、旧名、旧职业、旧失败。
- 有熟悉的地方和人：常去的铺子、欠过的人、害怕碰见的人、保护过的孩子。
- 有害怕失去的东西：一张票、一条船、一口井、一点体面、一个不愿承认的亲人。
- 有正在忍受的问题：病、债、排挤、失眠、旧伤、药价、身份风险或无法离开的理由。

读者应该感觉“这个人原本就活在这里”，而不是“他被剧情临时召唤出来”。

## 人物谱系先于人物表

先按谱系组织人物，再补单人档案。谱系说明一组人物共同承担什么叙事功能。

常见谱系：

| 谱系 | 功能 |
|---|---|
| 血缘 / 前史线 | 解释主角性格来源、旧伤、旧物、原生关系和后置真相 |
| 同行 / 伙伴线 | 测试信任边界、资源交换、救急、误会、背叛和共同成长 |
| 对手 / 压制线 | 建立被低估、被利用、被定价、被误解和反夺价码 |
| 制度 / 权力线 | 把抽象规则变成人、账册、职位、命令、门槛和惩罚 |
| 职业 / 技术线 | 让战斗体系、工艺、医救、斥候、交易、旧械等能力人格化 |
| 地缘 / 阵营线 | 体现不同地区、阶层、族群、城市和组织之间的利益差异 |
| 非人 / 文明线 | 让怪物、异族、神灵、AI 或异星文明拥有工种、等级、禁忌和族群目的 |
| 情感 / 价值线 | 让主角面对爱、亏欠、救赎、尊严、选择和不可回头的承诺 |

每条谱系至少要有：核心人物、叙事必要性、对主角施加的压力、关系推进规则。

谱系是组织长篇人物的骨架，不是替代人物生命感的理由。完成谱系后，每个重要角色还必须补“生活惯性、地方痕迹、关系小证据和留白”，否则容易变成结构完整但没灵魂的编剧型角色。

## 谱系 Schema

```json
{
  "characterLineage": [
    {
      "id": "",
      "lineage": "",
      "coreCharacters": [],
      "storyFunction": "",
      "pressureOnProtagonist": "",
      "relationshipRules": [],
      "firstAppearanceWindow": "",
      "payoffWindow": "",
      "risk": ""
    }
  ]
}
```

如果项目存储结构没有独立 `characterLineage` 字段，可把谱系写入 `storyAssets.relationships / worldview / memoryNotes`，把单人档案写入 `storyAssets.characters`。

## 角色档案 Schema

重要角色建议使用：

```json
{
  "id": "",
  "name": "",
  "aliases": [],
  "namingOrigin": "",
  "addressRules": [],
  "lineage": "",
  "role": "",
  "publicIdentity": "",
  "origin": "",
  "briefHistory": "",
  "importantExperiences": [],
  "goal": "",
  "fear": "",
  "secret": "",
  "debt": "",
  "dailyLife": "",
  "habitualTrace": "",
  "localBodyMemory": "",
  "privatePressure": "",
  "biasOrMisbelief": "",
  "unsaidPast": "",
  "resourceOrLeverage": "",
  "narrativeFunction": "",
  "relationshipState": "",
  "relationships": [],
  "relationshipSmallEvidence": [],
  "blankSpace": "",
  "firstAppearancePlan": "",
  "majorAppearances": [],
  "endingDirection": "",
  "growthArc": "",
  "taboos": [],
  "status": "active | memory | dead | missing | unconfirmed | nonhuman"
}
```

字段解释：

- `origin`：人物来历，必须能影响声口、技能、恐惧或立场。
- `namingOrigin`：姓名来源，说明它与地域、阶层、家族、职业、时代或族群语言的关系。
- `addressRules`：称呼规则，说明谁叫本名、谁叫外号、谁叫官称、谁不能直呼。
- `briefHistory`：简单经历，只写和主线有关的部分。
- `importantExperiences`：重要经历，优先写能回收成冲突或证据的事件。
- `dailyLife`：主角不在时，他日常怎样活，靠什么过日子，为什么没离开。
- `habitualTrace`：能让读者记住他的动作、口头禅、整理方式、躲避方式或小怪癖。
- `localBodyMemory`：地方如何写进身体习惯，例如盐湖人不踩盐裂，桥棚人听梁声会抬头。
- `privatePressure`：他正在忍受的问题，优先写具体压力，不只写抽象痛苦。
- `biasOrMisbelief`：他相信但可能不完全正确的经验、偏见或传闻。
- `unsaidPast`：他不愿主动解释的过去，用于留白和后续拼图。
- `narrativeFunction`：他在故事中负责推动什么，不要写成“重要配角”。
- `relationshipSmallEvidence`：关系变化的细小证据，例如没拆穿、递半块饼、默认留座、替对方保留体面。
- `blankSpace`：暂不解释清楚的矛盾、传闻、旧物或习惯，供后续逐步揭开。
- `majorAppearances`：略写出场节点，每次出场都要有目的。
- `endingDirection`：结局方向，不必剧透细节，但要知道他最终承担什么后果。
- `status`：状态要清楚，避免死者、失散者、记忆人物或非人角色被误当普通在场人物。

## 档案防模板化

`goal / fear / secret / debt` 这类字段用于创作管理，不应直接变成正文里的标签。写角色时要把抽象字段转成行为痕迹：

| 不要停在 | 应转成 |
|---|---|
| 害怕孤独 | 他睡觉时一定靠墙，听见隔壁熄灯会坐起 |
| 曾经逃兵 | 他从不提北线冬天，也不穿发给退兵的旧靴 |
| 想活下去 | 他每次分钱都会先留船票钱 |
| 不信任人 | 他递水袋时拇指始终压着袋口 |
| 怀念旧人 | 他给陌生孩子买同一种酸果，却说自己不爱吃 |

角色卡可以记录“目标、恐惧、秘密”，正文优先写“他如何绕开、遮掩、保存、重复、抗拒和下意识选择”。人的存在感常常藏在动作里，而不是字段里。

## 人物气味与存在感

重要角色至少要有一个读者可记住的“人物气味”。它可以来自：

- 习惯动作：总在磨铜扣、把盐粒排整齐、讲话前先看门。
- 声口节奏：用旧时代词汇、从不说完整句、每句话都像算价。
- 空间选择：永远不坐背对窗的位置、进屋先看出口、过桥不踩中线。
- 物件痕迹：旧手套、破票夹、盐叶、缺齿梳、从不点燃的灯。
- 身体记忆：听见钟声会停步，闻到热铁味会皱眉，雨前会摸旧伤。
- 关系习惯：从不叫人本名，只记欠账；或只给快死的人报真名。

人物气味不等于怪癖堆叠。它必须和来历、地方、职业、创伤、欲望或关系有关。

## 人物与地方绑定

“来自某地”不能只写在履历里，必须变成身体和判断方式：

- 盐湖人走路时从不踩盐裂缝，也不在夜里吹口哨。
- 桥棚人听见木梁响声会下意识抬头，鞋底常年软。
- 灯墙人进屋先看灯油刻度，说话习惯报编号和时辰。
- 荒路人不隔雾喊真名，也不会把背包放在门口正中。
- 旧铁河跑线人不信热血，只信低潮、灯距和车门换气声。

地方绑定要优先体现在声口、走路、吃法、睡法、交易、称呼、避讳和判断上。这样人物会像从地图里长出来，而不是被贴了一个出身标签。

## 角色命名技巧

角色命名应像世界的一部分，而不是随机好听的标签。命名前先确认人物所属文化、地域、阶层、家族、职业、时代和语言习惯。

常用方法：

- 地域来源：边地、港口、山城、学院、旧都、荒村的人名可以有不同音节、字感和称呼习惯。
- 家族来源：姓氏、辈分、继承名、收养名、弃名、婚后名能体现关系和旧账。
- 阶层来源：贵族全名长，平民常用短名，军队和行会常用编号、职称或绰号。
- 职业来源：医师、猎人、巡检、船工、祭司、商人可能拥有行业称呼。
- 历史来源：战后改名、避讳、纪念死者、抹去旧姓，都能带出背景。
- 非人来源：人类给怪物的他称、怪物自称、学者分类名和交易名可以互相冲突。

一个重要角色可拥有多层称呼：

| 称呼 | 作用 |
|---|---|
| 本名 | 最稳定的身份标记，不一定所有人都能直呼 |
| 乳名 / 小名 | 暴露亲密关系、旧时光或被轻视的状态 |
| 外号 | 来自战绩、缺陷、职业、误会或民间传闻 |
| 官称 / 职称 | 体现制度位置，如巡检、司库、祭司、导师 |
| 代号 | 适合秘密组织、军队、实验体、情报线 |
| 禁忌名 | 不能直说的真名、旧名、罪名或被抹去的名字 |
| 敌方称呼 | 暴露偏见、恐惧、蔑视或政治立场 |

称呼会随关系推进变化。陌生人叫官称，伙伴叫短名，旧敌叫旧名，亲人叫乳名，制度人物坚持叫编号，都能比旁白更快说明关系状态。

命名注意：

- 避免同一批角色同声母、同字头、同尾音或同模板，读者会混淆。
- 幻想故事不要堆罕见字；可为每个地区建立命名池，让名字有统一来源但不重复。
- 重要角色名字要易读、可记、有区分度；生僻设定名可留给地名、古物或仪式。
- 角色名字不要全部围绕同一核心意象。世界里的人会按家族、职业、地方、信仰和交易习惯命名。
- 若名字本身承载秘密，先设计公开称呼，再设计真名暴露的时机和后果。

## 角色必要性

一个角色至少应承担一种必要性。必要性可以是剧情功能，也可以是世界真实度、地方感或情绪重量。

剧情功能包括：

- 给主角一个目标。
- 抢走或提供一种资源。
- 暴露一条规则。
- 挑战主角价值观。
- 让主角付出代价。
- 带来一条地图路线。
- 揭示一个秘密的证据载体。
- 推动一种关系变化。
- 让世界观从抽象规则变成具体压力。

非直接剧情功能也可以成立：

- 提供地方感：一个只出现两章的老船工，让读者相信这条河有人活了一辈子。
- 提供生活感：一个每天擦钟的人，让失钟城不只是设定名。
- 提供情绪停顿：一个在边营唱歌的人，让荒凉里有人的余温。
- 提供价值对照：一个不讲大道理却愿意留半盏灯的人。
- 提供世界真实度：一个不重要但有清楚生计、习惯和称呼的人。

若角色既不能推动剧情，也不能让世界更像真实存在过，应合并、删除或改成背景称呼。不要为了“结构精简”删除所有气氛角色；很多短暂人物的价值正在于让世界有人味。

## 出场设计

角色第一次出场不要先写履历。优先让他带着动作、任务、资源、压迫或选择入场。

有效首次出场：

- 他正在做一件能显示身份的事。
- 他掌握主角需要的资源。
- 他制造或解决一个具体障碍。
- 他让主角产生误判。
- 他用一句话或一个动作暴露关系边界。
- 他正在处理自己的生活难题，而主角只是撞进来。
- 他显出一个地方化习惯，让读者立刻知道他属于哪里。

无效首次出场：

- 大段介绍姓名、外貌、身份和履历。
- 只负责解释世界观。
- 只负责赞美或衬托主角。
- 没有带来状态变化、地方质感或人物存在感。

## 关系推进

人物关系必须有阶段，不要跳级。

常见关系阶段：

```text
陌生 -> 试探 -> 交易 -> 有限信任 -> 欠债 -> 冲突 -> 选择 -> 破裂或稳固
```

每次关系推进都要有证据：救过一次、骗过一次、付过一次债、共同承担一次代价、保守过一个秘密、公开反对过一次制度。

关系不能只靠旁白宣布“他们更信任了”。要让读者看到行为变化：称呼改变、距离改变、资源共享、秘密暴露、退路开放、背后不再设防或重新设防。

关系推进不只来自大事件。很多关系变化来自：

- 共同经历无聊时间。
- 共享小资源。
- 目睹脆弱。
- 形成默契。
- 没有揭穿。
- 替对方保留体面。
- 在危险结束后默认给对方留位置。

真正重要的关系，往往不是靠宣言建立，而是靠“对方开始默认你会在”。写关系时优先找这些小证据，再决定是否需要大冲突。

角色不要太知道自己在故事里。一个人帮助主角，可能不是因为他代表善良，而是因为主角像他弟弟；一个人反对主角，可能不是因为价值观对立，而是因为他已经输不起了。动机要落在人性、损失、偏见、债和具体处境里，不要让角色像在承担主题任务。

## 角色经历与结局

角色档案要略写他的故事路径：

- 出身或来历。
- 进入主线的原因。
- 与主角第一次发生关系的节点。
- 中段重要选择或背叛。
- 高潮中承担的代价。
- 结局方向：存活、死亡、失踪、离队、掌权、流放、和解、清账、成为新秩序的一部分。

结局方向要服务主题，不要为了煽情随意牺牲角色。角色死亡必须改变局势、关系或价值判断。

## 留白原则

重要角色不应被一次性完全解释。应保留：

- 没说出口的经历。
- 不确定的传闻。
- 自相矛盾的证词。
- 被误解的过去。
- 不愿解释的习惯。
- 只有物件、动作或称呼暗示的旧关系。

留白不是偷懒，而是让读者逐渐拼出这个人。角色档案可以知道更多，但正文释放要克制；不要在第一次出场就把目标、恐惧、秘密、创伤和结局方向全部说完。

## 人物深参考层

人物设计的目标不是填满档案，而是让角色像主角不在场时也会继续生活。

深人物设计优先回答：

- 他每天醒来第一件事是什么。
- 他靠什么生活，欠谁东西，怕谁敲门。
- 他习惯用什么方式保护自己。
- 他对世界最大的误解是什么。
- 他为什么会出现在主角路线上，而不是作者临时放过来。
- 他在本卷至少改变哪一种状态。

角色不是性格标签，而是一套在特定地方、制度、关系和旧伤中形成的行动模式。

## 欲望、恐惧与误信

每个重要角色至少有三层驱动：

| 层级 | 定义 | 写法 |
|---|---|---|
| 表层目标 | 当前想拿到什么 | 路券、钱、名次、消息、药、机会 |
| 深层欲望 | 为什么非要得到 | 被承认、离开家、保住人、证明自己 |
| 核心误信 | 他对世界的错误理解 | 只有有用才配被爱、欠债永远还不清 |

人物成长不是“变强”或“变成熟”这么简单，而是核心误信被场景反复挑战。

示例：

- 表层目标：拿到过桥牌。
- 深层欲望：离开一直困住他的盐村。
- 核心误信：只要走得足够远，过去就不会追上来。
- 成长挑战：每到新地方，他都发现自己仍在用盐村教给他的方式判断人。

## 行为痕迹

抽象档案必须转成行为痕迹。

| 档案词 | 行为化 |
|---|---|
| 缺安全感 | 睡觉靠墙，进屋先看门栓 |
| 贪财 | 收钱先数破角，零钱分三处藏 |
| 骄傲 | 不问路，宁愿绕远 |
| 自卑 | 介绍自己时先说“我只是” |
| 重情 | 给别人留好退路，却说是顺手 |
| 残忍 | 处罚前先确认旁观者都看见 |
| 温柔 | 不追问对方不想说的事 |
| 迷信 | 过桥前敲三下，嘴上说只是习惯 |

读者相信行为，不相信档案标签。每个核心人物至少要有 3-5 个可反复出现但会变化的行为痕迹。

## 人物与资源

角色必须和资源发生关系。

资源包括：

- 钱、粮、药、盐、水、票、证件。
- 技术、工具、武器、书、地图。
- 名声、血统、学籍、军功、教籍。
- 时间、身体、劳动力、记忆、秘密。
- 怪物材料、旧械零件、魔力、灵脉资格。

问：

- 他拥有什么别人没有的资源。
- 他缺什么，因此必须交易、投靠、撒谎或冒险。
- 他把什么东西看得过高或过低。
- 他愿意用什么换目标。
- 他绝不会卖什么。

资源观能暴露人格。穷人、贵族、猎人、医生、逃犯、祭司对同一袋药的价值判断完全不同。

## 人物与制度

制度人物不能只代表制度，也要被制度困住。

可设计：

- 窗口小吏知道规则荒唐，但他的孩子靠这份工牌读书。
- 巡检同情主角，却害怕巡查记录少一个章。
- 学院教师想救学生，但论文、排名和派系都压在他身上。
- 教士真诚相信救赎，却被迫把救济名额给贵族。
- 公司主管也欠债，只能把压力往下传。

制度人物越有私人困境，制度压迫越真实。不要让所有官员都只是坏，不要让所有底层执行者都突然无代价倒戈。

## 人物与地图

人物知道的地图，是他人生的一部分。

检查：

- 他熟悉哪些路，不熟悉哪些路。
- 他觉得哪里安全，哪里羞耻，哪里不能回去。
- 他走路、说话、穿衣、睡觉是否带着出身地痕迹。
- 他是否拥有别人不知道的近路或旧称。
- 他是否误判了异地规则。

例如：

- 长期地下生活的人讨厌开阔天空。
- 港口人不轻易承诺到达时间。
- 山路长大的人听见石子滚动会立刻停步。
- 城里人以为所有路都有名称，边地人只认风和树。

人物离开故乡后，不应立刻变成无地方痕迹的通用角色。

## 关系弧线

关系推进需要具体台阶。

可用台阶：

1. 互相误判。
2. 有限交易。
3. 共享风险。
4. 交换小秘密。
5. 看见对方失败。
6. 没有利用对方弱点。
7. 为对方保留体面。
8. 因价值观冲突短暂决裂。
9. 在新代价下重新选择。

关系跳级是常见失败：互防角色突然交心，对手突然尊重，导师突然牺牲。修复时不要只加“他们逐渐熟悉”，要补一两个具体小证据。

## 角色出场密度

长篇不怕角色多，怕角色功能重叠。

新增角色前检查：

- 他是否代表一种新资源、新职业、新阶层、新地方或新价值观。
- 他是否能替代已有角色。
- 他是否和主角有独特关系，而不是重复“帮助者 / 解释者”。
- 他是否拥有自己的目标和时间压力。
- 他离场后是否留下后果。

角色可以短暂，但不能无痕。一个只出场一章的人，也可以通过一句行话、一笔债、一条旧路或一个误解让世界变厚。

## 角色死亡与离场

角色死亡不是单纯制造情绪。

死亡或离场应改变：

- 资源归属。
- 关系债务。
- 组织态度。
- 路线可达性。
- 主角价值判断。
- 伏笔账本。
- 某个地方的日常秩序。

如果角色死后什么都不变，这个死亡只是情绪消费。最小修复是补遗物、债务、未完成承诺、组织记录或他人误传。

## 配角独立性

配角要有主角外的人生。

为重要配角补：

- 主角不在时，他要处理什么麻烦。
- 他最常去的三个地方。
- 他和谁有旧债。
- 他对主角的判断是否会改变。
- 他会不会为了自己的目标拒绝主角。
- 他是否有一个不服务主线的小愿望。

配角能拒绝主角，世界才像真的。

## 对手设计

对手不是“阻止主角的人”，而是持有另一套世界解释的人。

有效对手需要：

- 可理解目标。
- 资源优势。
- 对主角弱点的判断。
- 自己的底线和恐惧。
- 能学习、调整、反制。
- 在某些方面说得有道理。

对手失败最好来自他的核心误信，而不是作者让他突然变蠢。

## 导师设计

导师不能只负责送技能。

导师可承担：

- 展示旧世界规则。
- 给主角一个有代价的保护。
- 传递错误经验，后续被主角修正。
- 成为主角未来可能变成的样子。
- 在关键处拒绝帮助，迫使主角独立。

导师最好也有局限：时代过时、旧伤未愈、制度束缚、资源不足、害怕主角重蹈覆辙。

## 人物失败诊断

| 失败 | 表现 | 修复 |
|---|---|---|
| 标签化 | 只有性格词 | 补行为痕迹、资源关系和误信 |
| 工具人 | 只解释设定或送道具 | 给独立目标、代价和拒绝权 |
| 声口同质 | 所有人说话一样 | 按出身、职业、教育、关系调整 |
| 关系跳级 | 突然信任或背叛 | 补小证据、利益变化或压力触发 |
| 无地方感 | 角色像无背景漂浮 | 补身体习惯、口音、路线和禁忌 |
| 无制度压力 | 身份只写头衔 | 补证件、债务、职责、流程和惩罚 |
| 离场无后果 | 死亡或消失不改变世界 | 补遗物、债、记录、路线和情绪余波 |

## 非人角色

怪物、异族、神灵、AI、异星文明或器物人格也需要角色档案。它们不应只是攻击单位。

非人角色额外考虑：

- 族群目的。
- 社会等级或工种。
- 交易方式或交流方式。
- 禁忌和价值观。
- 与人类的误解。
- 它如何推动主角重新理解世界。

## 审核清单

完成人物谱系和角色档案后检查：

- 是否先有谱系，再有角色。
- 每条谱系是否有叙事必要性和关系推进规则。
- 每个重要角色是否有来历、经历、秘密、关系、生活惯性和结局方向。
- 角色是否能改变至少一种故事状态，或提供明确的地方感、生活感、情绪停顿、价值对照或世界真实度。
- 角色是否像主角不在时也会继续生活，而不是只在剧情需要时被激活。
- 抽象字段是否转成了行为痕迹，而不是停在“目标 / 恐惧 / 秘密”的角色卡。
- 是否有可记住的人物气味：习惯动作、声口、物件、空间选择或身体记忆。
- 人物与地方是否绑定到身体习惯、称呼、交易、避讳和判断方式。
- 角色命名是否体现地域、阶层、家族、职业或称呼关系，是否避免同模板堆名。
- 是否有角色只负责解释设定、送道具或夸主角。
- 关系是否跳级，是否缺少“没拆穿、共享小资源、目睹脆弱、替对方保留体面”等小证据。
- 秘密是否过早暴露，重要人物是否缺少留白。
- 死者、失散者、记忆人物和非人角色的 `status` 是否清楚。
- 人物是否和地图、制度、资源、怪物生态或战斗体系发生联系。
