# Story Map Design Reference

`story-map-design` 用于设计故事发生的地点体系。它不只服务宏大奇幻或科幻世界，也适用于短篇里的村镇、宅院、学校、医院、公司、船舱和一条街。只要故事里有人行动、抵达、逃离、相遇、失踪或争夺资源，就需要地图意识。

探险、末世游历、废土远行和奇观地图题材里，地图首先服务主角的渴望与抵达，而不是服务解锁关卡。先问主角为什么想去那里，再问那里的地貌如何改变人的活法。

## 核心目标

设计故事地图时，先回答四个问题：

- 故事发生在什么地方。
- 故事提到哪些地方。
- 这些地方在地理、交通、资源、权力和情感上有什么联系。
- 主角如何沿着这些地方推进剧情、关系和成长。
- 人为什么住在这里，如何利用地貌、规避危险、形成习俗和称呼。

地图不是设定装饰，也不是游戏关卡。人物要在地图上移动，冲突要在地图上发生，资源要在地图上分布，权力要在地图上划界；更重要的是，地方要长出具体的人间生活。

## 地图分层

地图从大到小要有层级关系。按故事尺度选择需要的层级，不必每部作品都写满。

| 层级 | 适用范围 | 设计重点 |
|---|---|---|
| 宇宙 / 星系层 | 太空歌剧、星际殖民、神话宇宙 | 星系位置、航道、文明边界、资源星、禁区 |
| 星球层 | 全球灾变、异星、架空大陆 | 大陆、海洋、气候带、板块、核心灾害源 |
| 洲洋 / 大陆层 | 史诗奇幻、战争、远征 | 国家、山脉、河流、荒原、海路、战略通道 |
| 国家 / 区域层 | 王朝、江湖、废土、现代悬疑 | 城邦、边境、关隘、资源区、势力范围 |
| 城市 / 镇村层 | 都市、悬疑、校园、乡土、短篇 | 街区、机构、公共空间、隐蔽角落、邻里关系 |
| 建筑 / 家宅层 | 密室、家庭、短篇、心理故事 | 房间、门窗、楼层、视线、动线、秘密空间 |
| 场景 / 路线层 | 追逃、战斗、调查、相遇 | 出入口、遮挡、距离、高低差、退路、可利用物 |

短篇也需要地图，只是尺度更小：一个家也有厨房、卧室、门廊、楼梯、储物间和邻居窗户；这些空间决定谁能听见、看见、躲藏、误会或逃走。

## 设计顺序

推荐按这个顺序建立故事地图：

1. 确定故事尺度：星球、大陆、国家、城市、村镇、家宅或单一路线。
2. 确定原点：主角最初的位置，或故事秩序的中心点。
3. 列出核心地点：主角会反复到达、提到、争夺或逃离的地方。
4. 建立层级：大区域包含哪些小区域，小区域包含哪些关键场景。
5. 确认相邻关系：谁在东南西北，上下内外，近远前后。
6. 确认路径成本：路程、时间、危险、门槛、票据、身份、资源消耗。
7. 绑定叙事功能：每个地点负责什么冲突、资源、秘密、关系或成长。
8. 绑定地方活法：谁住在这里，靠什么过日子，怎么交易，怎么命名危险，灾变如何变成日常手艺。
9. 绑定势力和生态：谁控制这里，谁依赖这里，谁被排除在外。
10. 设计地缘关系：地区之间如何互相供养、剥削、封锁、误解或开战。
11. 给章节标注位置：每一章在哪里发生，下一章如何移动。

## 地点档案

每个重要地点至少回答：

- 它属于哪一层地图。
- 它和哪些地点相邻。
- 到达这里需要付出什么成本。
- 这里有什么资源、禁忌、危险、权力和秘密。
- 人为什么住在这里，怎么活，怎么称呼和利用这里的危险。
- 这里让主角获得什么，失去什么，误判什么。
- 这里如何改变人物关系或故事局势。

地点如果不能改变行动、资源、信息、关系或代价，就只是背景名，应压缩。

## 地图与剧情

地图设计完成后，用它铺叙故事：

- 开篇地图要小，压力要近：屋内、村口、街区、船舱、病房、矿道。
- 中段地图要展开，规则要变：新城、新区域、新势力、新生态、新交通成本和新活法。
- 后段地图要回收，前期地点经验要变成解决大问题的工具。
- 终局地图要让世界逻辑集中兑现：路线、资源、势力、地方活法和人物选择一起压到场上。除非作者明确要求，不要把终局默认写成公布世界真相。

地图推进不等于不停换地方。好地图会让同一个地点在不同阶段承担不同意义：第一次是避难处，第二次是交易地，第三次是战场，第四次是清账处。

## 地图与人物

人物要和地图绑定：

- 出身地塑造人物声口、技能、恐惧和偏见。
- 活动范围决定人物知道什么、不知道什么。
- 交通成本决定关系能否维持、救援能否到达、谎言能否成立。
- 势力边界决定人物身份在不同地点的价值变化。
- 回到旧地应触发新的状态，而不是只回忆过去。

写章节前至少确认：当前地点、目标地点、相邻路线、控制势力、出场人物为什么能在这里出现。

## 地图与资源 / 权力

地理关系要能转化为冲突：

- 上游控制水，下游承担污染。
- 城市享受安全，荒野承担死亡。
- 港口控制贸易，内陆承担税和兵役。
- 山口控制通行，村镇承担劫掠。
- 家中某个房间掌握秘密，另一个房间承担沉默。

所谓地缘关系，本质是“谁靠什么地方获利，谁被什么地方困住，谁试图改变路线”。

## 审核清单

完成地图设计后检查：

- 是否有清晰的地图层级，从大到小能对应起来。
- 每个核心地点是否有相邻关系和路径成本。
- 每个地点是否有叙事功能，而不是漂亮地名。
- 资源、怪物、职业、权力是否绑定到具体地点。
- 每个核心地点是否有当地人的生存习惯、称呼、手艺和交易方式。
- 地缘关系是否能转化为任务、价码、冲突或选择。
- 章节移动是否能成立，时间、伤势、天气、追兵和物资是否匹配。
- 正文是否用可感知的路程和地貌写地图，而不是台账语言。
