# Story Map Design Reference

`story-map-design` 用于设计故事发生的地点体系。它不只服务宏大奇幻或科幻世界，也适用于短篇里的村镇、宅院、学校、医院、公司、船舱和一条街。只要故事里有人行动、抵达、逃离、相遇、失踪或争夺资源，就需要地图意识。

探险、末世游历、废土远行和奇观地图题材里，地图首先服务主角的渴望与抵达，而不是服务解锁关卡。先问主角为什么想去那里，再问那里的地貌如何改变人的活法。

## 核心目标

设计故事地图时，先回答四个问题：

- 故事发生在什么地方。
- 故事提到哪些地方。
- 这些地方在地理、交通、资源、权力和情感上有什么联系。
- 主角如何沿着这些地方推进剧情、关系和成长。
- 人为什么住在这里，如何利用地貌、规避危险、形成习俗和称呼。

地图不是设定装饰，也不是游戏关卡。人物要在地图上移动，冲突要在地图上发生，资源要在地图上分布，权力要在地图上划界；更重要的是，地方要长出具体的人间生活。

## 设计优先级

地图设计时，优先级如下：

```text
身体进入感
> 地方活法
> 路线成本
> 资源 / 权力
> 剧情压力
> 地缘结构
> 地名与宏观设定
```

如果一个地方能改变人的走路方式、说话音量、睡觉姿势、交易习惯、恐惧和礼貌，它已经是有效地图。反之，如果一个地方只有地貌标签、资源列表、危险等级和势力归属，即使设定庞大，也只是关卡说明。

地图首先让人物进入，其次让人物生活，再让人物行动。宏观地缘和势力关系必须落回身体经验、地方职业、路线成本和具体选择。

## 最小必要地图原则

不是每个地点都需要完整档案。核心地点优先保证：

- 一个身体进入感。
- 一个地方活法。
- 一个核心冲突。
- 一个路线意义。
- 一个记忆锚点。

允许大量地点只有局部信息、传闻信息或错误信息。地图的真实感来自行动中的确认、误判和留白，不来自字段完整。生成时不要为了填满台账，把每个地点写成百科。

## 地图分层

地图从大到小要有层级关系。按故事尺度选择需要的层级，不必每部作品都写满。

| 层级 | 适用范围 | 设计重点 |
|---|---|---|
| 宇宙 / 星系层 | 太空歌剧、星际殖民、神话宇宙 | 星系位置、航道、文明边界、资源星、禁区 |
| 星球层 | 全球灾变、异星、架空大陆 | 大陆、海洋、气候带、板块、核心灾害源 |
| 洲洋 / 大陆层 | 史诗奇幻、战争、远征 | 国家、山脉、河流、荒原、海路、战略通道 |
| 国家 / 区域层 | 王朝、江湖、废土、现代悬疑 | 城邦、边境、关隘、资源区、势力范围 |
| 城市 / 镇村层 | 都市、悬疑、校园、乡土、短篇 | 街区、机构、公共空间、隐蔽角落、邻里关系 |
| 建筑 / 家宅层 | 密室、家庭、短篇、心理故事 | 房间、门窗、楼层、视线、动线、秘密空间 |
| 场景 / 路线层 | 追逃、战斗、调查、相遇 | 出入口、遮挡、距离、高低差、退路、可利用物 |

短篇也需要地图，只是尺度更小：一个家也有厨房、卧室、门廊、楼梯、储物间和邻居窗户；这些空间决定谁能听见、看见、躲藏、误会或逃走。

## 设计顺序

推荐按这个顺序建立故事地图：

1. 确定故事尺度：星球、大陆、国家、城市、村镇、家宅或单一路线。
2. 确定原点：主角最初的位置，或故事秩序的中心点。
3. 列出核心地点：主角会反复到达、提到、争夺或逃离的地方。
4. 建立层级：大区域包含哪些小区域，小区域包含哪些关键场景。
5. 绑定身体进入感：人刚进入这里时，身体最先感到什么变化。
6. 确认相邻关系：谁在东南西北，上下内外，近远前后。
7. 确认路径成本和不确定性：路程、时间、危险、门槛、票据、身份、资源消耗、封路、绕路、迷路和传闻路线。
8. 绑定节奏功能：地点负责压迫、缓冲、中转、奇观、回声还是规则断裂。
9. 绑定地方活法和经济链：谁住在这里，靠什么过日子，谁运输、加工、定价、冒险和无法离开。
10. 绑定势力和生态：谁控制这里，谁依赖这里，谁被排除在外；如果有怪物或灾变生物，必须绑定生态发动机、物种谱系、食物网、尺度 / 栖境 / 体态矩阵、关键种和人类职业接口。
11. 设计地缘关系：地区之间如何互相供养、剥削、封锁、误解或开战。
12. 给章节标注位置：每一章在哪里发生，下一章如何移动、失败、停留或折返。

## 地方身体感

每个重要地点除了资源和地缘，还应回答：

- 人进入这里后，身体最先感受到什么。
- 温度、湿度、风、气味、噪音、重力、视野和光线如何变化。
- 本地人有哪些身体习惯：步伐、呼吸、穿衣、睡姿、饮食、照明、说话音量。
- 外地人最容易犯什么错误。
- 某些长期感受是否会改变人的性格、语言或心理。

读者记住地图，往往不是因为地名，而是因为身体经验：鞋底结盐、领口灌风、灯火变蓝、夜里不敢大声喊人。

## 地图节奏层

地图不只控制空间，也控制阅读节奏。连续章节不应长期维持同一种地图压力；奇观、高压、复杂势力和密集信息之后，需要让人物恢复成人。

| 地点类型 | 节奏作用 |
|---|---|
| 避难点 | 缓冲压力，恢复关系，允许人物吃饭、睡觉、争吵和沉默 |
| 中转地 | 交换信息、资源、谣言、路引和错误地图 |
| 奇观区 | 提供陌生感和世界扩展，但不能连续滥用 |
| 压迫区 | 强化危险、限制、追捕、失温、缺氧或身份压力 |
| 回声地 | 回收前期伏笔、旧关系、旧伤和被误解的地方经验 |
| 断裂区 | 改变规则和行动方式，让旧经验暂时失效 |

小镇、渡口、路边店、盐屋、中转站、旧营地、废弃教室和临时病房都可以是节奏节点。它们未必推进大阴谋，但能让人物关系和地方生活变得可信。

## 地图不确定性

地图不应永远稳定、可达和清晰。真正的地图感来自“人不确定能否到达”，而不是“下一个地点已经解锁”。

可使用的不确定来源：

- 季节封路、涨水、雪崩、沙暴、瘴气和潮汐。
- 怪物迁徙、灾变扩散、疫病、失温带和临时禁区。
- 势力封锁、税卡、路引、身份审查和战时征用。
- 地图失真、老路废弃、路标错误、假渡口和被改名的村庄。
- 传闻地图、口述路线、只有某类职业知道的近路。
- 绕路、迷路、原地停留、返回旧地、半路改变目标和路线失败。

路线失败本身可以成为剧情：物资被耗尽，关系被磨损，旧地被重新理解，人物不得不承认自己并不了解这个世界。

## 地方经济链

地方活法需要进入资源流动，而不只是写“这里产什么”。

每个重要地区尽量确认：

- 核心资源如何流出。
- 谁掌握运输。
- 谁负责加工。
- 谁承担危险。
- 谁定价、征税或抽成。
- 谁无法离开这里。
- 哪类职业最容易死。
- 哪种资源会导致黑市、婚姻、宗教、债务、帮派或暴力。

例如“盐湖地区靠捕盐生活”还不够。继续追问：谁垄断晒盐台，谁收盐税，坏天气时谁破产，盐价涨时谁饿死，哪类人不准靠近湖，谁靠偷运盐路活下来。

## 地图记忆锚点

核心地点至少要有一种不用地名也能被认出的记忆锚点：

- 独特声音。
- 独特气味。
- 独特颜色。
- 独特动作。
- 独特天气。
- 独特禁忌。
- 独特建筑习惯。
- 独特口头禅。

好的地图锚点不是“北方盐区第三区”，而是“风会把灯吹蓝的渡口”。读者应能通过一句身体感、地方动作或民俗禁忌认出这个地方。

## 地图塑造人格

地图最终要改变人，而不只是限制人。

可从这些方向推导人物：

- 长期走山路的人不轻易承诺，因为他们知道路会变。
- 港口人说话习惯留余地，因为船期、风向和货价都不稳定。
- 雾地居民不轻易喊别人名字，因为远处回声可能不是本人。
- 盐民习惯轻步，因为盐壳下可能是空洞。
- 地下居民害怕开阔天空，因为没有顶棚意味着没有边界。

当地图开始改变礼仪、语言、爱情、时间观念、葬礼、儿童游戏和价值观，地图才真正进入叙事。

## 地图深参考层

地图不只是“地方集合”，而是人物行动的约束系统。深地图设计要同时管理四种尺度：

- **身体尺度**：脚会不会湿，肺会不会疼，眼睛能不能看远，夜里敢不敢点灯。
- **生活尺度**：人怎么取水、买盐、上学、看病、结婚、下葬、交易和躲灾。
- **路线尺度**：谁能走，谁不能走，什么时候走，走错会付出什么代价。
- **权力尺度**：谁控制桥、港口、山口、井、车站、楼梯、户籍和地图。

地图写得好时，读者会相信人物不是在背景上移动，而是在一个会反过来塑造人的世界里求生。

## 进入感设计

每个核心地点的第一次登场，要给读者一个进入动作。

进入动作可以是：

- 跨过门槛。
- 换鞋、罩面、点灯、熄灯。
- 交路费、验票、报籍、搜身。
- 低头穿过梁、弯腰避开风、屏住呼吸。
- 听见声音变化。
- 闻到气味变化。
- 看见本地人做一个外地人不懂的动作。

有效进入不是“这里很危险”，而是：

- 主角刚进盐屋，鞋底就开始发硬。
- 外地人在桥上说话太响，所有桥工同时抬头。
- 渡口的灯不是黄色，而是被风吹成蓝白。
- 市场里没有人喊价，所有价码都用手指在袖口里敲。

进入感越具体，地图越不需要长篇说明。

## 方向感与读者定位

地图复杂时，读者需要稳定定位。

可用锚点：

- 固定方向：上游 / 下游、内城 / 外城、山上 / 山下、桥东 / 桥西。
- 固定声音：钟楼、潮声、矿井低鸣、车站广播、兽群迁徙。
- 固定颜色：盐白、锈红、铜绿、灯蓝、骨黄。
- 固定气味：药味、鱼腥、煤烟、霉纸、铁锈、热石。
- 固定路线：从井到市、从桥到庙、从车站到黑市。
- 固定禁忌：哪里不能喊名，哪里不能回头，哪里不能点火。

长篇地图不必每次报方位，但要让读者逐渐建立“我知道这个世界怎么走”的感觉。方向感来自重复的生活路径，不来自一次性地图说明。

## 聚落类型

不同聚落承担不同叙事功能。

| 聚落 | 生存逻辑 | 常见冲突 |
|---|---|---|
| 河口镇 | 贸易、船税、潮汐、疫病 | 港权、走私、封港、外来者 |
| 山口寨 | 通行、驿站、抢修、守路 | 路权、雪封、劫掠、军队征用 |
| 盐湖村 | 晒盐、采壳、皮肤病、倒影禁忌 | 盐税、黑市、湖怪、破产 |
| 矿井城 | 地下劳动、通风、塌方、粉尘 | 工债、罢工、旧械、失踪 |
| 学院城 | 考试、宿舍、藏书、等级 | 门槛、派系、禁术、学籍 |
| 边境市 | 多语言、关卡、临时身份 | 盘查、叛逃、间谍、双重法律 |
| 废站营地 | 中转、修车、拾荒、旧路 | 补给、误车、假票、袭击 |
| 巨兽背城 | 迁徙、寄生、周期停靠 | 季节、方向、资源争夺、坠落 |

聚落不是“某地有某资源”就结束。必须继续问：谁守门，谁收税，谁在这里一出生就欠债，谁每天看着远方却走不了。

## 路线类型

路线比地点更能制造故事压力。

| 路线 | 特征 | 可制造剧情 |
|---|---|---|
| 官道 | 安全但有税、有证件、有记录 | 身份暴露、追捕、盘查 |
| 商路 | 信息多、价码多、谣言多 | 交易、护送、欺诈、黑市 |
| 旧路 | 便宜、危险、靠口述记忆 | 迷路、传说、旧伏笔 |
| 水路 | 受潮汐、船权、港口控制 | 封港、沉船、检疫 |
| 地下路 | 隐蔽、缺氧、容易失向 | 潜入、塌方、怪物 |
| 朝圣路 | 仪式、禁忌、群体移动 | 信仰冲突、伪装、赎罪 |
| 迁徙路 | 与动物、怪物或季节绑定 | 抢时间、生态扰动 |
| 走私路 | 依靠暗号、关系、贿赂 | 背叛、债务、替罪 |

设计路线时至少确认：谁维护，谁收费，谁知道近路，谁希望这条路消失。

## 地图与信息流

信息也在地图上移动。

检查：

- 消息从哪里出发。
- 通过谁传递：驿站、船夫、商队、寺庙、广播、黑市、鸟群、梦网。
- 传递速度有多快。
- 哪些地方会截断消息。
- 哪些组织会篡改消息。
- 边地人和中心人是否知道同一版本。

很多剧情漏洞来自信息传播过快。远方消息应有成本、延迟、误传和利益加工。一个村庄被屠，首都不应下一页就知道细节，除非世界有明确通信系统及其代价。

## 地图与阶层

同一城市里，不同阶层拥有不同地图。

- 贵族地图：宴会、私门、花园、密道、债务室、观礼台。
- 商人地图：仓库、码头、账房、保险柜、茶楼、票号。
- 工人地图：工棚、井、后门、食堂、工具间、危险近路。
- 孩子地图：墙洞、屋顶、废井、糖铺、不能去的院子。
- 逃亡者地图：阴影、下水道、旧路、没有巡逻的时段。
- 怪物猎人地图：巢迹、水源、风向、尸体腐烂速度。

地图不是客观中立的。人物知道的路，暴露他来自哪里、属于谁、害怕什么。

## 地图与记忆

同一地点在不同阶段要变意义。

可用变化：

- 第一次是避难所，后来变成审判地。
- 第一次是敌区，后来发现那里有人救过主角。
- 第一次是热闹市场，战后只剩价格牌。
- 第一次是禁地，后来成为唯一退路。
- 第一次是童年乐园，后来被组织改名、登记、拆毁。

地图回访要带变化。人物回到旧地时，不只是回忆过去，而是用现在的身份重新理解过去。

## 地图与类型

不同类型的地图重心不同。

### 探险 / 游历

地图重心是抵达、见闻和选择。每个新地点都应让主角第一次见到一种不同活法。

### 悬疑 / 推理

地图重心是视线、动线、证据位置和不可能性。门窗、时间、声音传播、谁能到达哪里尤其重要。

### 战争 / 权谋

地图重心是补给、关隘、地缘、军队移动和信息延迟。不要只写战场，要写粮道、伤兵、桥、天气和传令。

### 都市 / 职场

地图重心是办公室层级、会议室、工位、走廊、厕所、茶水间、楼下便利店和通勤路径。权力常在空间分配里显形。

### 校园 / 学院

地图重心是宿舍、教室、图书馆、禁区、社团室、榜单、食堂和夜间巡查。学生知道的近路和老师知道的制度路不同。

### 家庭 / 宅院

地图重心是房间归属、门是否能锁、谁能听见、谁有钥匙、谁不能上桌、谁住在边角。

## 地图失败诊断

| 失败 | 表现 | 修复 |
|---|---|---|
| 地名堆叠 | 名字很多，但读者不知道差异 | 给每地一个身体感和记忆锚点 |
| 路线像关卡 | A 到 B 到 C 单向解锁 | 加绕路、返回、封路、误路和停留 |
| 宏观过重 | 国家地缘很多，人物身体缺席 | 写鞋、风、灯、气味、声音、口音 |
| 地方无经济 | 只写资源，不写谁获利 | 补运输、加工、定价、税和黑市 |
| 地图无阶层 | 所有人知道同一张地图 | 按职业、年龄、身份拆地图 |
| 回访无变化 | 旧地只触发回忆 | 让旧地承担新功能或新代价 |
| 信息瞬移 | 远方消息无成本抵达 | 补传递路径、延迟、误传和截断 |

## 地图台账 Schema

长篇建议建立结构化 `mapAtlas`。短篇可以缩小字段，但仍保留地点、关系、路线和功能。

`mapAtlas` 是规划台账，不是答题卡。不要因为身体感、经济链、节奏功能和记忆锚点而继续无限扩字段；需要时可压缩进 `features`、`resources`、`risks`、`localLife`、`routes.conflict` 和 `storyFunction`。重点是帮助写作判断，不是追求资料库完整。

## 地点档案

每个重要地点至少回答：

- 它属于哪一层地图。
- 它和哪些地点相邻。
- 到达这里需要付出什么成本。
- 人刚进入这里时，身体最先感到什么。
- 这里承担什么节奏功能：避难、中转、奇观、压迫、回声或断裂。
- 这里有什么资源、禁忌、危险、权力和秘密。
- 人为什么住在这里，怎么活，怎么称呼和利用这里的危险。
- 资源如何流动，谁运输、加工、定价、冒险和被困住。
- 路线是否稳定，是否可能封路、绕路、迷路、折返或被传闻误导。
- 读者不靠地名能否通过一个声音、气味、颜色、动作、天气或禁忌认出它。
- 这里让主角获得什么，失去什么，误判什么。
- 这里如何改变人物关系或故事局势。
- 这里长期塑造了当地人的哪些礼仪、语言、时间观念、恐惧或性格。

地点如果不能改变行动、资源、信息、关系或代价，就只是背景名，应压缩。

## 地图与剧情

地图设计完成后，用它铺叙故事：

- 开篇地图要小，压力要近：屋内、村口、街区、船舱、病房、矿道。
- 中段地图要展开，规则要变：新城、新区域、新势力、新生态、新交通成本和新活法。
- 后段地图要回收，前期地点经验要变成解决大问题的工具。
- 终局地图要让世界逻辑集中兑现：路线、资源、势力、地方活法和人物选择一起压到场上。除非作者明确要求，不要把终局默认写成公布世界真相。

地图推进不等于不停换地方。好地图会让同一个地点在不同阶段承担不同意义：第一次是避难处，第二次是交易地，第三次是战场，第四次是清账处。

地图节奏不等于持续加压。高压和奇观之后要安排可呼吸的空间，让人物有机会吃饭、修鞋、清点伤口、交换谣言、误会对方或恢复一点旧关系。

## 地图与人物

人物要和地图绑定：

- 出身地塑造人物声口、技能、恐惧和偏见。
- 活动范围决定人物知道什么、不知道什么。
- 交通成本决定关系能否维持、救援能否到达、谎言能否成立。
- 势力边界决定人物身份在不同地点的价值变化。
- 长期生活的地貌会改变人的礼仪、爱情、承诺方式、时间观念和心理边界。
- 回到旧地应触发新的状态，而不是只回忆过去。

写章节前至少确认：当前地点、目标地点、相邻路线、控制势力、出场人物为什么能在这里出现。

## 地图与资源 / 权力

地理关系要能转化为冲突：

- 上游控制水，下游承担污染。
- 城市享受安全，荒野承担死亡。
- 港口控制贸易，内陆承担税和兵役。
- 山口控制通行，村镇承担劫掠。
- 家中某个房间掌握秘密，另一个房间承担沉默。

所谓地缘关系，本质是“谁靠什么地方获利，谁被什么地方困住，谁试图改变路线”。

写资源时必须继续追问经济链：谁发现资源，谁承担死亡，谁拥有工具，谁垄断运输，谁收税，谁负责把脏活藏起来，谁被迫把孩子送进这个行业。

## 审核清单

完成地图设计后检查：

- 是否有清晰的地图层级，从大到小能对应起来。
- 每个核心地点是否有相邻关系和路径成本。
- 每个核心地点是否有身体进入感，而不是只有路线成本、资源和风险。
- 是否有节奏功能，避免连续高压、连续奇观或连续复杂势力导致疲劳。
- 是否允许路线失败、绕路、迷路、封路、返回旧地和原地停留。
- 每个地点是否有叙事功能，而不是漂亮地名。
- 资源、怪物生态网、职业、权力是否绑定到具体地点。
- 资源是否形成地方经济链，明确运输、加工、定价、危险承担和无法离开的人。
- 每个核心地点是否有当地人的生存习惯、称呼、手艺和交易方式。
- 每个核心地点是否有记忆锚点，让读者不靠地名也能认出地点。
- 地图是否改变当地人的礼仪、语言、爱情、时间观念、儿童游戏或性格。
- 是否遵守最小必要地图原则，没有为了填满 schema 把地点写成百科。
- 地缘关系是否能转化为任务、价码、冲突或选择。
- 章节移动是否能成立，时间、伤势、天气、追兵和物资是否匹配。
- 正文是否用可感知的路程和地貌写地图，而不是台账语言。
